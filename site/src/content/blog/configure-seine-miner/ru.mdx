Запускайте майнер Blocknet с предсказуемыми настройками. Руководство для seine v0.2.37 объясняет расположение конфигурации, приоритет аргументов и постоянные изменения. Начните с рабочей установки; замену программы описывает [руководство по обновлению](/ru/blog/update-seine-miner/).

## Как seine выбирает настройки?

<Answer>
seine объединяет сохранённые параметры подключения с аргументами запуска. Явные аргументы имеют приоритет над соответствующими значениями файла. Каталог данных определяет читаемый файл. Параметры оборудования и выполнения остаются аргументами запуска: сохраняйте и конфигурацию, и обычную команду.
</Answer>

## Найдите используемый файл

По умолчанию это `./seine-data/seine.config.json` относительно рабочего каталога процесса, который может отличаться от папки программы. До редактирования проверьте терминал, ярлык или службу. Разные способы запуска одного файла могут выбирать разные каталоги данных.

`--data-dir` выбирает базовый каталог; имя остаётся `seine.config.json`. При запуске из разных мест используйте постоянный абсолютный путь. Запишите программу, рабочий каталог, путь данных и все аргументы. [Руководство для Windows](/ru/blog/start-miner-automatically-windows/) показывает эти пути, включая пробелы, в Планировщике заданий.

## Какие настройки относятся к файлу?

Пример показывает основные поля подключения. Замените `@yourname` своим зарегистрированным Blocknet ID или полным адресом получения. Это образец формата, не команда. В существующей установке меняйте нужные поля вместо замены всего файла.

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

`mode`, `address`, `pool_url` и `pool_worker` выбирают режим, получателя, пул и имя машины. Сохраните `schema_version` и имеющееся `dev_fee_pool_worker`. Последнее — отдельная автоматически созданная метка; для своей машины используйте `pool_worker`. Не записывайте сюда сид-фразу и приватные ключи.

## Как сохранить изменение постоянно?

Остановите майнер и скопируйте файл. Используйте текстовый редактор, корректный JSON с двойными кавычками и исходное имя без дополнительного расширения. Измените только нужное поле в используемом каталоге. Проверьте запятые, исключите комментарии и завершающие запятые; при наличии используйте проверку JSON редактора. Копия позволяет точно сравнить старые значения.

Проверьте, не переопределяет ли запуск то же поле. Старый `--address` имеет приоритет над новым адресом в файле. Обновите аргумент или удалите, чтобы применить сохранённое значение. Запустите обычным ярлыком, скриптом или задачей и проверьте действующие настройки.

## Осознанно используйте временные параметры

При существующей конфигурации следующая опция пула задаёт имя машины для этого запуска. При следующем запуске без неё вернётся сохранённое имя. Это удобно для контролируемого изменения; для постоянного поведения добавьте опцию в обычную команду.

```text
--pool-worker desktop-02
```

При первом запуске без файла seine создаёт его из начальных данных подключения. Это отличается от временной замены существующих значений. Помните об этом при копировании команды на другой компьютер, где конфигурация может создаваться впервые. [Справочник настройки](https://github.com/zpalmtree/seine/blob/v0.2.37/docs/guides/configuration.md) описывает начальные вопросы и параметры.

## Сохраняйте параметры оборудования в команде

`--backend` и `--threads` передаются при запуске. Схема подключения не является списком всех опций. Похожее поле JSON не задаёт такой параметр выполнения. Держите выбранные настройки оборудования в скрипте, ярлыке или службе.

Управление потоками в панели меняет сеанс, не сохраняя новое значение по умолчанию. Автонастройка имеет собственные файлы кеша. Сохраняйте их отдельно от правок подключения и позволяйте каждой машине настраиваться под своё оборудование. [Руководство по автонастройке](/ru/blog/seine-automatic-cpu-tuning/) объясняет кеш и явное число потоков.

## Почему настройки кажутся сброшенными?

Сравните путь данных и аргументы с последним успешным запуском. Новая папка распаковки, другой каталог терминала или старый аргумент задачи могут объяснить отличие. При ошибке разбора сначала прочитайте имя файла и сообщение. Восстановите копию или исправьте JSON, затем запустите один раз нужным способом.

Проверьте получателя, пул, имя и принятые шары. Повторите обычный запуск для проверки сохранения; один запуск с аргументами подтверждает только эту команду. Используйте [руководство по панели](/ru/blog/seine-dashboard-explained/) и [смене адреса](https://bntpool.com/blog/ru/change-mining-wallet-address/) для будущих начислений. Храните рабочую команду вместе с копией конфигурации.
