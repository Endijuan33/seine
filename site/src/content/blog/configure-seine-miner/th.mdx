เริ่มเครื่องขุด Blocknet ด้วยการตั้งค่าที่คาดหมายได้ทุกครั้ง คู่มือนี้อ้างอิง seine v0.2.37 อธิบายตำแหน่งไฟล์ ลำดับของอาร์กิวเมนต์ และการเปลี่ยนแบบถาวร เริ่มจากการติดตั้งที่ใช้งานได้แล้ว ส่วนการเปลี่ยนตัวโปรแกรมดู[คู่มืออัปเดต](/th/blog/update-seine-miner/)

## seine เลือกการตั้งค่าอย่างไร?

<Answer>
seine รวมค่าการเชื่อมต่อที่บันทึกไว้กับอาร์กิวเมนต์เริ่มต้น อาร์กิวเมนต์ที่ระบุชัดเจนมีลำดับสูงกว่าค่าที่เกี่ยวข้องในไฟล์ โฟลเดอร์ข้อมูลกำหนดว่าจะอ่านไฟล์ใด ตัวเลือกฮาร์ดแวร์และการทำงานยังเป็นอาร์กิวเมนต์ จึงควรเก็บทั้งไฟล์และคำสั่งที่ใช้ตามปกติ
</Answer>

## หาไฟล์ที่วิธีเริ่มโปรแกรมใช้งานจริง

ค่าเริ่มต้นคือ `./seine-data/seine.config.json` ซึ่งอ้างอิงจากโฟลเดอร์ทำงานของโปรเซส และอาจต่างจากโฟลเดอร์โปรแกรม ตรวจสอบเทอร์มินัล ทางลัด หรือบริการก่อนแก้ไข วิธีเริ่มสองแบบอาจใช้โปรแกรมเดียวกันแต่คนละโฟลเดอร์ข้อมูล

`--data-dir` เลือกโฟลเดอร์หลัก โดยชื่อไฟล์ยังเป็น `seine.config.json` หากเริ่มจากหลายตำแหน่งให้ใช้พาธเต็มที่คงที่ บันทึกโปรแกรม โฟลเดอร์ทำงาน ข้อมูล และอาร์กิวเมนต์ทั้งหมด [คู่มือเริ่มอัตโนมัติบน Windows](/th/blog/start-miner-automatically-windows/) แสดงการใส่พาธใน Task Scheduler รวมถึงพาธที่มีช่องว่าง

## การตั้งค่าใดอยู่ในไฟล์?

ตัวอย่างแสดงฟิลด์การเชื่อมต่อหลัก แทน `@yourname` ด้วย Blocknet ID ที่ลงทะเบียนหรือที่อยู่รับเต็มของคุณ นี่เป็นตัวอย่างรูปแบบไฟล์ ไม่ใช่คำสั่ง ในการติดตั้งเดิมให้แก้เฉพาะฟิลด์ที่ต้องการแทนการเขียนทับทั้งไฟล์

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

`mode`, `address`, `pool_url` และ `pool_worker` เลือกโหมด ปลายทาง พูล และชื่อเครื่อง เก็บ `schema_version` และ `dev_fee_pool_worker` ที่มีอยู่ ฟิลด์หลังเป็นชื่อที่สร้างแยกต่างหาก ส่วนเครื่องของคุณใช้ `pool_worker` อย่าใส่วลีกู้คืนหรือกุญแจส่วนตัวในไฟล์นี้

## ทำอย่างไรให้การเปลี่ยนอยู่ถาวร?

หยุดโปรแกรมและสำรองไฟล์ ใช้ตัวแก้ไขข้อความกับ JSON ที่ถูกต้อง โดยใช้เครื่องหมายคำพูดคู่และชื่อไฟล์เดิมที่ไม่มีนามสกุลเพิ่ม แก้เฉพาะฟิลด์จำเป็นในโฟลเดอร์ที่ใช้จริง ตรวจสอบจุลภาค หลีกเลี่ยงความคิดเห็นและจุลภาคท้ายรายการ และใช้ตัวตรวจ JSON ของโปรแกรมแก้ไขถ้ามี สำเนาช่วยเปรียบเทียบค่าเดิมได้ตรงกัน

ตรวจสอบว่าวิธีเริ่มมีอาร์กิวเมนต์ทับค่าเดียวกันหรือไม่ `--address` เก่ามีลำดับสูงกว่าที่อยู่ใหม่ในไฟล์ อัปเดตหรือลบอาร์กิวเมนต์เพื่อใช้ค่าที่บันทึก จากนั้นเริ่มผ่านทางลัด สคริปต์ หรืองานปกติ แล้วตรวจค่าที่มีผลจริง

## ใช้ตัวเลือกชั่วคราวอย่างตั้งใจ

เมื่อมีการตั้งค่าแล้ว ตัวเลือกพูลด้านล่างเลือกชื่อเครื่องสำหรับการทำงานครั้งนี้ ครั้งถัดไปที่ไม่ใช้ตัวเลือกจะกลับมาใช้ชื่อที่บันทึก เหมาะกับการเปลี่ยนแบบควบคุม หากต้องการใช้ทุกครั้งให้เพิ่มในวิธีเริ่มตามปกติ

```text
--pool-worker desktop-02
```

เมื่อเริ่มครั้งแรกโดยไม่มีไฟล์ seine จะสร้างไฟล์จากข้อมูลการเชื่อมต่อเริ่มต้น ซึ่งต่างจากการทับค่าชั่วคราวของไฟล์เดิม โปรดจำข้อนี้เมื่อคัดลอกคำสั่งไปยังคอมพิวเตอร์อื่นที่อาจกำลังสร้างการตั้งค่าครั้งแรก [เอกสารการตั้งค่า](https://github.com/zpalmtree/seine/blob/v0.2.37/docs/guides/configuration.md) อธิบายคำถามเริ่มต้นและตัวเลือกที่รองรับ

## เก็บตัวเลือกปรับแต่งไว้ในคำสั่ง

`--backend` และ `--threads` เป็นอาร์กิวเมนต์เริ่มต้น โครงสร้างการเชื่อมต่อไม่ใช่รายการตัวเลือกทั้งหมด การเพิ่มฟิลด์ JSON ชื่อคล้ายกันไม่กำหนดตัวเลือกการทำงานนั้น เก็บการเลือกฮาร์ดแวร์ไว้ในสคริปต์ ทางลัด หรือบริการที่เริ่มเครื่องขุด

ตัวควบคุมเธรดในแดชบอร์ดเปลี่ยนเฉพาะเซสชัน ไม่บันทึกค่าเริ่มต้นใหม่ การปรับอัตโนมัติมีไฟล์แคชของตัวเอง เก็บไว้แยกจากการแก้การเชื่อมต่อและให้แต่ละเครื่องปรับตามฮาร์ดแวร์ [คู่มือปรับอัตโนมัติ](/th/blog/seine-automatic-cpu-tuning/) อธิบายการใช้แคชซ้ำและการเลือกเธรดโดยตรง

## ทำไมการตั้งค่าดูเหมือนถูกรีเซ็ต?

เปรียบเทียบพาธข้อมูลและอาร์กิวเมนต์กับการเริ่มครั้งล่าสุดที่ถูกต้อง โฟลเดอร์แตกไฟล์ใหม่ โฟลเดอร์เทอร์มินัลอื่น หรืออาร์กิวเมนต์งานเก่าอาจอธิบายความต่าง หากอ่านรูปแบบไม่ได้ให้ดูชื่อไฟล์และข้อความก่อน คืนค่าจากสำรองหรือแก้ JSON แล้วเริ่มครั้งเดียวผ่านทางที่ตั้งใจ

ตรวจปลายทาง พูล ชื่อเครื่อง และแชร์ที่ยอมรับ เริ่มตามปกติอีกครั้งเพื่อยืนยันว่าค่าคงอยู่ การรันพร้อมอาร์กิวเมนต์ครั้งเดียวพิสูจน์แค่คำสั่งนั้น ใช้[คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) และ[คู่มือเปลี่ยนที่อยู่](https://bntpool.com/blog/th/change-mining-wallet-address/) สำหรับปลายทางเครดิตงานในอนาคต เก็บวิธีเริ่มที่ใช้งานได้พร้อมไฟล์สำรอง
