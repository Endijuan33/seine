Blocknet 채굴기를 매번 예측 가능한 설정으로 시작하세요. seine v0.2.37 기준으로 저장 위치, 인수 우선순위, 영구 변경 방법을 설명합니다. 작동 중인 설치가 전제이며 프로그램 교체는 [업데이트 가이드](/ko/blog/update-seine-miner/)를 참고하세요.

## seine는 설정을 어떻게 선택하나요?

<Answer>
seine는 저장된 연결 설정과 시작 인수를 조합합니다. 명시적 연결 인수가 대응하는 저장 값보다 우선합니다. 데이터 디렉터리가 읽을 파일을 결정합니다. 하드웨어 및 실행 옵션은 시작 인수로 남으므로 설정 파일과 평소 시작 명령을 모두 보관하세요.
</Answer>

## 실제로 사용되는 파일 찾기

기본 경로는 `./seine-data/seine.config.json`입니다. 프로세스의 작업 디렉터리를 기준으로 하며 실행 파일 폴더와 다를 수 있습니다. 수정 전에 터미널, 바로 가기, 서비스 설정을 확인하세요. 같은 프로그램도 시작 방법에 따라 서로 다른 데이터 폴더를 읽을 수 있습니다.

`--data-dir`는 기준 디렉터리를 선택하며 파일명은 `seine.config.json`으로 유지됩니다. 여러 곳에서 시작한다면 고정 절대 경로를 사용하세요. 프로그램, 작업 폴더, 데이터 경로, 모든 인수를 기록합니다. [Windows 시작 가이드](/ko/blog/start-miner-automatically-windows/)는 공백이 포함된 경로까지 작업 스케줄러에 설정하는 방법을 설명합니다.

## 어떤 설정을 파일에 저장하나요?

예시는 주요 연결 필드입니다. `@yourname`을 등록된 Blocknet ID나 자신의 전체 수신 주소로 바꾸세요. 실행 명령이 아니라 파일 형식 참고입니다. 기존 설치에서는 파일 전체를 교체하지 말고 필요한 필드만 수정하세요.

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

`mode`, `address`, `pool_url`, `pool_worker`는 모드, 수신 대상, 풀, 장치 이름을 선택합니다. `schema_version`과 기존 `dev_fee_pool_worker`는 유지하세요. 마지막 필드는 별도로 생성된 이름이며 내 장치에는 `pool_worker`를 씁니다. 복구 문구와 개인 키는 여기에 넣지 마세요.

## 변경을 영구적으로 유지하려면?

채굴기를 중지하고 파일을 백업하세요. 텍스트 편집기에서 큰따옴표 문자열을 사용하는 올바른 JSON을 유지하고 추가 확장자 없이 원래 이름으로 저장합니다. 실제 데이터 폴더의 필요한 필드만 바꾸세요. 쉼표를 확인하고 주석과 끝 쉼표를 피하며 가능하면 편집기의 JSON 검증을 사용하세요. 백업으로 이전 값을 정확하게 비교할 수 있습니다.

시작 명령이 같은 설정을 덮어쓰는지 확인하세요. 오래된 `--address`는 새로 저장한 주소보다 우선합니다. 인수를 갱신하거나 제거해 파일 값을 사용하세요. 평소 바로 가기, 스크립트, 작업으로 다시 시작하고 적용 값을 확인합니다.

## 임시 옵션을 의도적으로 사용하기

기존 설정이 있으면 아래 풀 옵션은 이번 실행의 장치 이름을 선택합니다. 다음에 옵션 없이 시작하면 저장된 이름으로 돌아갑니다. 통제된 변경에 유용하지만 매번 사용하려면 평소 시작 명령에 넣으세요.

```text
--pool-worker desktop-02
```

파일 없는 첫 시작에서는 seine가 최초 연결 입력으로 파일을 만듭니다. 이는 기존 파일을 임시로 재정의하는 것과 다릅니다. 다른 컴퓨터에 명령을 복사할 때 그곳에서는 첫 설정을 만들 수 있음을 기억하세요. [설정 문서](https://github.com/zpalmtree/seine/blob/v0.2.37/docs/guides/configuration.md)에 최초 질문과 지원 옵션이 있습니다.

## 하드웨어 옵션은 시작 명령에 보관하기

`--backend`와 `--threads`는 시작 인수입니다. 연결 스키마는 모든 옵션의 목록이 아닙니다. 비슷한 JSON 필드를 추가해도 실행 옵션이 설정되지 않습니다. 하드웨어 선택은 채굴기를 실행하는 스크립트, 바로 가기, 서비스에 보관하세요.

대시보드의 스레드 조절은 현재 세션만 바꾸며 새 기본값을 저장하지 않습니다. 자동 조정은 별도의 캐시 파일을 사용합니다. 연결 편집과 별개로 보존하고 각 컴퓨터가 자신의 하드웨어에 맞게 조정하게 하세요. [자동 조정 가이드](/ko/blog/seine-automatic-cpu-tuning/)는 캐시 재사용과 명시적 스레드 선택을 설명합니다.

## 설정이 초기화된 것처럼 보이는 이유는?

데이터 경로와 인수를 마지막 정상 실행과 비교하세요. 새 압축 해제 폴더, 다른 터미널 폴더, 오래된 작업 인수가 원인일 수 있습니다. 구문 분석 실패 시 파일명과 메시지를 먼저 읽으세요. 백업을 복원하거나 JSON을 수정한 뒤 의도한 경로로 한 번 시작합니다.

수신 대상, 풀, 장치 이름과 승인된 셰어를 확인하세요. 정상적인 재시작을 반복해 유지 여부를 확인합니다. 인수를 사용한 한 번의 실행은 그 명령만 검증합니다. [대시보드 가이드](/ko/blog/seine-dashboard-explained/)와 향후 적립 대상에 대한 [주소 변경 가이드](https://bntpool.com/blog/ko/change-mining-wallet-address/)를 참고하세요. 정상 시작 방법과 설정 백업을 함께 보관합니다.
