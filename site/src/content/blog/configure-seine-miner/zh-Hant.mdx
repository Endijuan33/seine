讓 Blocknet 礦工每次都按預期設定啟動。本指南以 seine v0.2.37 為準，說明設定位置、參數優先順序與持續保留修改的方法。請從已正常運作的安裝開始；替換程式本身請見[更新指南](/zh-hant/blog/update-seine-miner/)。

## seine 如何選擇設定？

<Answer>
seine 將儲存的連線設定與啟動參數結合使用。明確指定的連線參數優先於對應的儲存值。資料目錄決定讀取哪個設定檔。硬體和執行選項仍屬於啟動參數，因此應同時保留設定檔與日常啟動指令。
</Answer>

## 找到啟動方式實際使用的設定

預設檔案為 `./seine-data/seine.config.json`。此相對路徑從程序工作目錄開始，未必是執行檔所在目錄。編輯前檢查終端機目錄、捷徑或服務設定。同一程式的兩種啟動方式可能使用不同的資料目錄。

`--data-dir` 選擇基礎目錄，檔名仍為 `seine.config.json`。若從多個位置啟動，請使用固定絕對路徑。一起記錄程式、工作目錄、資料路徑與完整參數。[Windows 自動啟動指南](/zh-hant/blog/start-miner-automatically-windows/)說明如何在工作排程器填寫這些路徑，包括含空格的路徑。

## 哪些設定屬於儲存檔案？

範例展示主要連線欄位。請將 `@yourname` 換成自己註冊的 Blocknet ID 或完整收款位址。這是檔案格式參考，不是執行指令。已有安裝應只修改相關欄位，不要直接用範例覆蓋整個檔案。

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

`mode`、`address`、`pool_url` 與 `pool_worker` 分別選擇模式、收款目標、礦池和礦機名稱。保留 `schema_version` 以及已有的 `dev_fee_pool_worker`。後者是單獨產生的標籤；自己的礦機使用 `pool_worker`。不要將助記詞或私鑰寫進連線設定檔。

## 怎樣讓修改永久生效？

停止礦工並備份原檔案。使用純文字編輯器保留合法 JSON，字串使用雙引號，儲存原檔名且不加入額外副檔名。只修改實際資料目錄中的必要欄位。檢查欄位間的逗號，不加入註解或末尾逗號；若編輯器提供 JSON 驗證，請使用它。備份可精確比較舊值，無須憑記憶重建。

檢查啟動方式是否明確覆寫同一設定。若指令裡還有舊 `--address`，修改儲存位址不會生效。更新該參數，或移除它以使用檔案值。接著透過平時的捷徑、指令碼或工作重新啟動，核對實際設定。

## 有意識地使用暫時覆寫

已有設定時，下方礦池選項只為本次執行選擇礦機名稱。下次不帶此選項啟動，會恢復使用儲存的名稱。它適合受控修改；若希望每次都如此執行，請將選項寫入日常啟動方式。

```text
--pool-worker desktop-02
```

首次啟動且沒有設定檔時，seine 會根據初始連線輸入建立檔案。這與暫時覆寫已有檔案不同。將指令複製到其他電腦時，應考慮該電腦可能正在建立首次設定。[設定參考](https://github.com/zpalmtree/seine/blob/v0.2.37/docs/guides/configuration.md)記錄首次提示與支援的啟動選項。

## 將調校選項保留在啟動指令中

`--backend` 與 `--threads` 等選項透過啟動參數提供。連線檔案結構不是所有參數的通用清單。加入同名或近似名稱的 JSON 欄位不會設定對應執行選項。將明確的硬體選擇保留在啟動礦工的指令碼、捷徑或服務中。

儀表板的執行緒控制只修改目前工作階段，不儲存新的預設執行緒數。自動調校也有自己的快取檔案。修改連線時分別保留這些檔案，並讓各電腦依自身硬體調校。[自動調校指南](/zh-hant/blog/seine-automatic-cpu-tuning/)說明快取重用及明確指定執行緒的影響。

## 為什麼設定看起來重設了？

先將資料路徑與啟動參數和上次正常執行比較。新解壓目錄、其他終端機目錄或舊排程工作參數都可能解釋差異。剖析失敗時，先讀錯誤中的檔名與訊息，再還原備份或修正 JSON，然後從預期入口啟動一次。

核對顯示的收款目標、礦池、礦機名稱與接受的份額。再次正常重新啟動以驗證持續性；一次帶覆寫參數的執行只證明那條指令有效。用[儀表板指南](/zh-hant/blog/seine-dashboard-explained/)理解工作階段，用[位址變更指南](https://bntpool.com/blog/zh-hant/change-mining-wallet-address/)處理未來礦池工作記入哪個位址。將有效啟動方式與設定備份一起儲存。
