让 Blocknet 矿工每次都按预期设置启动。本指南以 seine v0.2.37 为准，说明配置位置、参数优先级和持久修改方法。请从已正常工作的安装开始；替换程序本身见[更新指南](/zh-hans/blog/update-seine-miner/)。

## seine 如何选择设置？

<Answer>
seine 将保存的连接设置与启动参数结合使用。明确指定的连接参数优先于对应的保存值。数据目录决定读取哪个配置文件。硬件和运行选项仍属于启动参数，因此应同时保留配置文件和日常启动命令。
</Answer>

## 找到启动方式实际使用的配置

默认文件为 `./seine-data/seine.config.json`。此相对路径从进程工作目录开始，未必是可执行文件所在目录。编辑前检查终端目录、快捷方式或服务设置。同一程序的两种启动方式可能使用不同的数据目录。

`--data-dir` 选择基础目录，文件名仍为 `seine.config.json`。如果从多个位置启动，请使用固定绝对路径。一起记录程序、工作目录、数据路径和完整参数。[Windows 自动启动指南](/zh-hans/blog/start-miner-automatically-windows/)说明如何在任务计划程序中填写这些路径，包括含空格的路径。

## 哪些设置属于保存文件？

示例展示主要连接字段。请把 `@yourname` 换成自己注册的 Blocknet ID 或完整收款地址。这是文件格式参考，不是运行命令。已有安装应只修改相关字段，不要直接用示例覆盖整个文件。

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

`mode`、`address`、`pool_url` 和 `pool_worker` 分别选择模式、收款目标、矿池和矿机名称。保留 `schema_version` 以及已有的 `dev_fee_pool_worker`。后者是单独生成的标签；自己的矿机使用 `pool_worker`。不要把助记词或私钥写进连接文件。

## 怎样让修改永久生效？

停止矿工并备份原文件。用纯文本编辑器保留合法 JSON，字符串使用双引号，保存原文件名且不添加额外扩展名。只修改实际数据目录中的必要字段。检查字段间的逗号，不添加注释或末尾逗号；若编辑器提供 JSON 验证，请使用它。备份可用于精确比较旧值，无须凭记忆重建。

检查启动方式是否明确覆盖同一设置。若命令里还有旧 `--address`，修改保存地址不会生效。更新该参数，或删除它以使用文件值。然后通过平时的快捷方式、脚本或任务重启，核对实际设置。

## 有意识地使用临时覆盖

已有配置时，下面的矿池选项只为本次运行选择矿机名称。下次不带此选项启动，会恢复使用保存的名称。它适合可控修改；若希望每次都这样运行，请把选项写入日常启动方式。

```text
--pool-worker desktop-02
```

首次启动且没有配置文件时，seine 会根据初始连接输入创建文件。这与临时覆盖已有文件不同。把命令复制到其他电脑时，应考虑那台电脑可能正在创建首次配置。[配置参考](https://github.com/zpalmtree/seine/blob/v0.2.37/docs/guides/configuration.md)记录了首次提示和支持的启动选项。

## 把调优选项保留在启动命令中

`--backend` 和 `--threads` 等选项通过启动参数提供。连接文件结构不是所有参数的通用列表。添加同名或近似名称的 JSON 字段不会设置对应运行选项。将明确的硬件选择保留在启动矿工的脚本、快捷方式或服务中。

仪表盘的线程控制只修改当前会话，不保存新的默认线程数。自动调优也有自己的缓存文件。修改连接时分别保留这些文件，并让每台电脑针对自身硬件调优。[自动调优指南](/zh-hans/blog/seine-automatic-cpu-tuning/)解释缓存复用及明确指定线程的影响。

## 为什么设置看起来重置了？

先把数据路径和启动参数与上次正常运行比较。新解压目录、其他终端目录或旧计划任务参数都可能解释差异。解析失败时，先读报错中的文件名和信息，再恢复备份或修正 JSON，然后从预期入口启动一次。

核对显示的收款目标、矿池、矿机名称和接受的份额。再次正常重启以验证持久性；一次带覆盖参数的运行只证明那条命令有效。用[仪表盘指南](/zh-hans/blog/seine-dashboard-explained/)理解会话，用[地址变更指南](https://bntpool.com/blog/zh-hans/change-mining-wallet-address/)处理未来矿池工作记入哪个地址。将有效启动方式和配置备份一起保存。
