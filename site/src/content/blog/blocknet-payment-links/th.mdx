ลิงก์ชำระเงิน Blocknet รวมทุกอย่างที่ผู้จ่ายต้องใช้ในบรรทัดเดียว: จ่ายให้ใคร BNT เท่าไร และเมโมที่ใส่หรือไม่ก็ได้ เช่น เลขใบแจ้งหนี้ ส่งในแชต ใส่ในใบแจ้งหนี้หรือโปรไฟล์ แล้วผู้จ่ายวางในกระเป๋าเงินและยืนยัน คู่มือนี้แสดงลิงก์สองรูปแบบ วิธีเขียนด้วยที่อยู่หรือ `$name` และสิ่งที่กระเป๋าเงินทำเมื่อมีคนวางลิงก์

## ลิงก์ชำระเงิน Blocknet คืออะไร?

<Answer>
ลิงก์ชำระเงิน Blocknet คือบรรทัดเดียวที่มีผู้รับ จำนวนเงิน และเมโมที่ไม่บังคับ เขียนเป็น blocknet://recipient?amount=25&memo=invoice-42 หรือ bntpay.com/recipient?amount=25&memo=invoice-42 ผู้รับเป็นที่อยู่กระเป๋าเงินหรือชื่อ Blocknet ID เมื่อวางในกระเป๋าเงินแบบบรรทัดคำสั่ง จะกลายเป็นรายการส่งที่พร้อมให้ยืนยัน
</Answer>

กระเป๋าเงินแบบบรรทัดคำสั่ง Blocknet รับสองรูปแบบ:

```
blocknet://<address-or-$name>?amount=<BNT>&memo=<text>
bntpay.com/<address-or-$name>?amount=<BNT>&memo=<text>
```

ทั้งสองมีช่องเดียวกัน:

| ช่อง | ตำแหน่ง | จำเป็น | เนื้อหา |
|---|---|---|---|
| ผู้รับ | ถัดจาก `blocknet://` หรือ `bntpay.com/` | ใช่ | ที่อยู่กระเป๋าเงิน หรือชื่อสั้นแบบ `$name` |
| `amount` | query string | ใช่ | BNT ที่ขอ ทศนิยมสูงสุดแปดตำแหน่ง |
| `memo` | query string | ไม่ | ข้อความเมโม สูงสุด 124 bytes |

กระเป๋าเงินยืดหยุ่นกับวิธีพิมพ์ลิงก์ โดยรู้จักทั้ง `blocknet://` และ `blocknet:` ที่สั้นกว่า ส่วนแบบเว็บรับ `bntpay.com/` เดี่ยวๆ หรือมี `www.`, `http://` หรือ `https://` นำหน้า คำนำหน้าไม่แยกตัวพิมพ์เล็กใหญ่ และลำดับ `amount` กับ `memo` ไม่สำคัญ

รูปแบบ `bntpay.com` เป็นที่อยู่เว็บปกติ แอปแชต อีเมล และโปรไฟล์โซเชียลส่วนใหญ่จึงทำเป็นลิงก์แตะได้ รูปแบบ `blocknet://` คือ URI ของ Blocknet เหมาะกับจุดที่ลิงก์ส่งตรงเข้ากระเป๋าเงิน

## เขียนลิงก์ชำระเงินอย่างไร?

เขียนลิงก์เองได้ในสี่ขั้นตอน

1. **เลือกผู้รับ** ใช้ `address` ในกระเป๋าเงินแบบบรรทัดคำสั่งเพื่อแสดงที่อยู่ หรือใช้[ชื่อสั้น Blocknet ID](/th/blog/blocknet-id-pay-by-name/) ด้วยคำนำหน้า `$` หากยังไม่มีกระเป๋าเงิน [คู่มือกระเป๋าเงิน Blocknet](/th/blog/blocknet-wallet-for-mining/) แสดงวิธีสร้างและหาที่อยู่
2. **กำหนดจำนวนเงิน** เขียนเป็น BNT ใช้จำนวนเต็มหรือทศนิยมได้ถึงแปดตำแหน่ง เพราะหนึ่ง BNT มี 100,000,000 หน่วยย่อย
3. **เพิ่มเมโมหากต้องการ** เลขคำสั่งซื้อ ID ใบแจ้งหนี้ หรือคำขอบคุณสั้นๆ ช่วยจับคู่การจ่ายเมื่อมาถึง จำกัดไว้ที่ 124 bytes
4. **รวมส่วนต่างๆ** ใส่ผู้รับหลังคำนำหน้า ตามด้วย `?amount=` แล้ว `&memo=` หากมี

ใบแจ้งหนี้ 25 BNT ไปยังชื่อในสองรูปแบบ:

```
https://bntpay.com/$yourname?amount=25&memo=invoice-42
blocknet://$yourname?amount=25&memo=invoice-42
```

คำขอเดียวกันที่ใช้ที่อยู่เต็ม:

```
bntpay.com/<address>?amount=25&memo=invoice-42
```

### เข้ารหัสอักขระในเมโม

เมโมที่มีช่องว่างหรือเครื่องหมายต้องเขียนอักขระบางตัวเป็น URL encoding เพราะตัวลิงก์ก็ใช้อักขระเหล่านั้น กระเป๋าเงินถอดกลับก่อนสร้างการจ่าย

| อักขระ | เขียนเป็น | เหตุผล |
|---|---|---|
| ช่องว่าง | `%20` | ทำให้ลิงก์ไม่แยกเป็นหลายส่วนเมื่อแชร์ |
| `&` | `%26` | `&` เริ่มช่องถัดไป |
| `#` | `%23` | `#` จบ query string |
| `+` | `%2B` | `+` เปล่าอ่านเป็นช่องว่าง |

เช่น `memo=Order%20%231042` จะได้รับเป็น `Order #1042` ตัวอักษร ตัวเลข ขีดกลาง ขีดล่าง และจุดไม่ต้องเข้ารหัส เมโมอย่าง `invoice-42` จึงใช้ง่ายตามที่เขียน

## ลิงก์ควรใช้ที่อยู่หรือ $name?

ทั้งสองใช้ได้และเหมาะกับงานต่างกัน

**ชื่อ** ทำให้ลิงก์สั้นพอจะอ่าน พูดออกเสียง หรือใส่ประวัติส่วนตัว เขียนคำนำหน้า `$` ในลิงก์: `$yourname` กับ `@yourname` คือชื่อเดียวกัน และ `$` เป็นรูปแบบที่ลิงก์ทั้งสองส่งต่อถึงกระเป๋าเงินโดยตรง เมื่อผู้จ่ายวางลิงก์ชื่อ กระเป๋าเงินค้นหาผ่าน blocknet.id ตรวจลายเซ็น Ed25519 ของระเบียน แล้วแสดงที่อยู่เต็มพร้อมเครื่องหมายตรวจสอบแล้ว เพราะค้นหาชื่อ ณ เวลาจ่าย ลิงก์ระยะยาวอย่างลิงก์ทิปในโปรไฟล์จึงยังใช้ได้เมื่อคุณเปลี่ยนชื่อให้ชี้ไปกระเป๋าเงินใหม่ภายหลัง

**ที่อยู่เต็ม** กำหนดปลายทางไว้ในลิงก์ เหมาะกับใบแจ้งหนี้ครั้งเดียวที่ต้องการระบุกระเป๋าเงินหนึ่งใบแน่นอน

ไม่ว่าแบบใด การจ่ายบนเชนเป็นธุรกรรม Blocknet ปกติไปยัง[stealth address แบบใช้ครั้งเดียว](/th/blog/blocknet-privacy-features/) และมีความเป็นส่วนตัวเท่าการจ่ายอื่น

## เกิดอะไรขึ้นเมื่อมีคนวางลิงก์ชำระเงิน?

<Answer>
กระเป๋าเงินอ่านผู้รับ จำนวนเงินและเมโมจากลิงก์ แล้วทำรายการส่งปกติด้วยข้อมูลนั้น หากมีชื่อจะค้นหาที่อยู่ สร้างธุรกรรม แล้วแสดงจำนวนเงิน ผู้รับ ที่อยู่เต็ม ค่าธรรมเนียมและเมโม พร้อมถาม Confirm [y/N] BNT ย้ายเมื่อผู้จ่ายพิมพ์ y เท่านั้น
</Answer>

ลำดับในกระเป๋าเงินแบบบรรทัดคำสั่งเป็นดังนี้

1. **ผู้จ่ายวางลิงก์ที่พรอมป์ต์กระเป๋าเงิน** ระบบเห็นคำนำหน้า `blocknet:` หรือ `bntpay.com/` แล้วถือว่าบรรทัดนั้นเป็นการส่ง ลิงก์ไป `$yourname` จำนวน 25 BNT พร้อมเมโม `invoice-42` กลายเป็นคำขอเดียวกับ `send $yourname 25 invoice-42`
2. **ค้นหาที่อยู่จากชื่อ** สำหรับลิงก์ชื่อ กระเป๋าเงินแสดง `Resolved $yourname -> <address>` พร้อมเครื่องหมายตรวจสอบแล้ว
3. **กระเป๋าเงินตรวจยอดและสร้างการจ่าย** เลือกเหรียญ สร้างธุรกรรมส่วนตัว และคำนวณค่าธรรมเนียม
4. **ผู้จ่ายเห็นสรุป** แสดงจำนวนเงินและผู้รับ ค่าธรรมเนียม ที่อยู่เต็มเมื่อใช้ชื่อ เงินทอนหากมี และเมโม ตามด้วย `Confirm [y/N]`
5. **ผู้จ่ายยืนยัน** พิมพ์ `y` เพื่อส่งธุรกรรมและแสดง ID พร้อมลิงก์ explorer ที่ `explorer.blocknetcrypto.com` คำตอบอื่นแสดง `Cancelled` และปล่อยเหรียญที่กระเป๋าเงินกันไว้

สรุปเปิดโอกาสให้ผู้จ่ายตรวจคำขอ จึงไม่มีอะไรออกจากกระเป๋าเงินก่อนเห็นสรุป ทุกลิงก์ต้องมีจำนวนเงิน หากไม่มี กระเป๋าเงินตอบ `payment link missing amount` และหยุดก่อนสร้างอะไร

เมโมในลิงก์ส่งไปพร้อมการจ่ายในรูป[เมโมเข้ารหัส](/th/blog/blocknet-encrypted-memos/)ของ Blocknet เมื่อ BNT มาถึง คำสั่ง `history` แสดงเมโมใต้การจ่ายขาเข้า คุณจึงจับคู่กับใบแจ้งหนี้หรือคำสั่งซื้อได้

### ทดสอบลิงก์ก่อนแชร์

ดูสิ่งที่ผู้จ่ายจะเห็นได้โดยวางลิงก์ของคุณในกระเป๋าเงินตัวเอง หากมีเงินอย่างน้อยเท่าจำนวนที่ขอ จะแสดงสรุปเต็ม ตรวจผู้รับ จำนวนเงินและเมโม แล้วตอบ `n` จะไม่มีการส่ง

## ลิงก์ชำระเงินเหมาะกับงานใด

- **ใบแจ้งหนี้** ใส่ลิงก์ที่ใช้เลขใบแจ้งหนี้เป็นเมโมไว้ท้ายใบแจ้งหนี้หรือในอีเมล ผู้จ่ายวางหนึ่งบรรทัดและเมโมบอกว่าใบใดชำระแล้ว
- **ร้านค้าและหน้าคำสั่งซื้อ** สร้างลิงก์ต่อคำสั่งซื้อโดยใส่เลขคำสั่งซื้อในเมโม ทุกการจ่ายจึงมาพร้อมป้ายกำกับ
- **ทิปและเงินบริจาค** ลิงก์ไป `$yourname` พร้อมจำนวนแนะนำใส่ในโปรไฟล์ README หรือโอเวอร์เลย์สตรีมได้
- **หารบิล** ส่งลิงก์พร้อมส่วนของแต่ละคนและเมโมอย่าง `dinner%20friday` ในแชตกลุ่ม

หากคุณขุด BNT ด้วย ใช้ชื่อเดียวกันได้ ทั้ง seine และ bntpool.com รับชื่อสั้น Blocknet ID เป็นที่อยู่รับเงิน เงินจากการขุดและลิงก์จึงมาถึงกระเป๋าเงินเดียวกัน [คู่มือการขุด Blocknet](/th/blog/how-to-mine-blocknet/) อธิบายการตั้งค่า
