Blocknet ID のショートネームがあれば、相手は `@yourname` 宛てに支払えるようになり、チャットのメッセージに収まる支払いリンクを共有でき、同じ名前宛てに bntpool.com でマイニングできます。このガイドでは、名前の仕組み、blocknet.id での取得方法、ウォレットと seine での使い方を説明します。

## Blocknet ID のショートネームとは何ですか？

<Answer>
Blocknet ID のショートネームは、@alice や $alice のような、Blocknet ウォレットのアドレスを指す短い名前です。blocknet.id で登録します。ウォレット、seine、bntpool.com は名前を検索し、そのレコードに blocknet.id が署名していることを確認してから、対応するフルアドレスを使います。
</Answer>

名前を受け付ける場所では、どこでも同じルールが適用されます。

- **2 つのプレフィックス。** `@name` と `$name` は同じ名前です。好きなほうを使えます。
- **大文字と小文字を区別しない。** `@Alice` と `@alice` は同じアドレスに解決されます。
- **シンプルな文字。** a〜z の英字、0〜9 の数字、アンダースコア、ハイフン、ドット。
- **最大 64 文字。**

blocknet.id のすべてのレコードには署名があります。ウォレットは名前を解決するとき、レコードを取得し、その Ed25519 署名を blocknet.id が `https://blocknet.id/.well-known/blocknet-id.json` で公開している署名鍵と照合します。署名されたペイロードには名前、アドレス、最終更新日時が含まれ、ウォレットはアドレスを使う前にこの 3 つがすべて一致することを確認します。また、各名前には blocknet.id に公開ページがあり、アドレス、署名されたペイロード、署名が表示されるので、誰でも自分でレコードを確認できます。

## なぜアドレスではなく名前宛てに支払うのですか？

Blocknet アドレスは、公開スペンドキー、公開ビューキー、チェックサムを base58 でエンコードしたもので、92 文字または 93 文字になります。アプリ間でコピーしたり、読み上げたり、プロフィールに載せたりするには長すぎます。ショートネームなら、会話の中で伝えたり、ステッカーに印刷したり、自己紹介欄に書いたりできます。

確認ステップもわかりやすくなります。名前宛てに送金すると、ウォレットは解決したアドレスを表示し、検証済みであることを示してから支払いの承認を求めます。名前は、もともと共有するはずだったアドレスの代わりになるだけです。チェーン上では、支払いは[使い捨てステルスアドレス](/ja/blog/blocknet-privacy-features/)宛ての通常の Blocknet トランザクションなので、ほかの支払いと同じようにプライベートなままです。

## Blocknet ID はどうやって取得しますか？

<Answer>
ウォレットのアドレスをコピーし、blocknet.id を開いて欲しい名前を検索します。利用可能であれば料金が表示されるので、アドレスを貼り付けて送信します。現在のキャンペーン期間中は 9 文字以上の名前は無料です。登録すれば、名前はウォレット、seine、bntpool.com で使えます。
</Answer>

1. **アドレスをコピーする。** コマンドライン版ウォレットでは `address` コマンドでアドレスが表示され、その後に「Get a short name like @name or $name at https://blocknet.id」という行が続きます。ウォレットは[コマンドライン版のリリース](https://github.com/blocknetprivacy/blocknet/releases/latest)または[デスクトップ版のリリース](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)から入手できます。
2. **名前を検索する。** [blocknet.id](https://blocknet.id) にアクセスし、「find a name」ボックスに名前を入力して Search を押します。入力中に、使えない文字が含まれていたり名前が長すぎたりすると、ページが知らせてくれます。
3. **結果を確認する。** 利用可能な名前には料金が表示されます。すでに登録されている名前には、そのアドレス、最終更新日時、公開ページへのリンクが表示されます。
4. **登録する。** ウォレットのアドレスを貼り付けて「Claim free」（有料の名前の場合は「Register」）を押します。

料金は名前の長さに応じた 1 回限りの支払いです。執筆時点（2026 年 10 月）では、キャンペーンにより 9 文字以上の名前はすべて無料で、サイトの言葉を借りれば「no invoice, no payment」（請求書なし、支払いなし）です。8 文字の名前は 100 BNT で、短くなるほど高くなり、1 文字の名前では 6,000 BNT です。すべての長さの料金は[料金ページ](https://blocknet.id/pricing)に掲載されています。

後で名前を管理するには、blocknet.id の「sign in」から Blocknet アドレスでサインインします。名前を別のアドレスに向け直すのは管理ページで行います。

## 名前宛てに BNT を送るには？

コマンドライン版ウォレットでは、アドレスの位置に名前を書きます。

```
send @rock 100 "hello"
```

ウォレットは `@rock` を解決し、検証済みマーク付きで `Resolved @rock -> <address>` と表示してから確認を求めます。確認画面には名前、フルアドレス、手数料、メモが表示されます。`$rock` の形式も同じように使え、`send` は整数でも小数でも金額を受け付けます。

ウォレットの API も、送金リクエストのすべての受取人について同じ方法で名前を解決するので、ウォレット上に作られたツールは追加の作業なしで名前宛ての支払いに対応できます。

## 名前を使った支払いリンクはどう機能しますか？

[支払いリンク](/ja/blog/blocknet-payment-links/)には、受取人、金額、任意のメモが含まれます。Blocknet は 2 つの形式に対応しています。

```
blocknet://<address>?amount=25&memo=invoice-42
https://bntpay.com/$yourname?amount=25&memo=invoice-42
```

bntpay.com のリンクはアドレスの代わりに名前を使えるので、短いままです。開くと「Pay $yourname」、金額、メモが書かれたページが表示され、「Open in Wallet」ボタンで支払いを `blocknet://` リンクとして開けます。どちらの形式もコマンドライン版ウォレットに貼り付けると、送金内容が入力された状態で確認を求められます。`amount` フィールドは含めてください。メモは任意で、最大 124 バイトのテキストを入れられます。

これで、投げ銭用のリンクを 1 つ投稿したり、請求書を 1 通のメッセージで送ったりするのが簡単になります。

## @name 宛てにマイニングするには？

seine と bntpool.com はどちらも、受け取りアドレスとしてショートネームを受け付けます。[seine](/ja/#download) を初めて起動したら、アドレスの入力欄に `@yourname` と入力し、デフォルトのプールをそのまま使います。コマンドラインで指定する場合は、引用符で囲みます。

```sh
./seine --address '@yourname'
```

<Note>
シェルコマンドでは、特に `$name` の形式の場合、シェルがそのまま渡すようショートネームを引用符で囲んでください。ショートネームには seine v0.2.16 以降が必要です。
</Note>

その後の流れは次のとおりです。

- **seine は起動時に名前を解決します。** blocknet.id の署名済みレコードを検証し、アドレスを確認して、解決したフルアドレスをログに記録し、プールへの再接続を含めて実行中はずっとそのアドレスを使います。
- **プールもログイン時に名前を受け付けます。** bntpool.com はマイナーが名前で接続すると署名済みの対応付けを検証し、解決したフルアドレスをジョブ、シェア、残高、支払いに使います。
- **名前で自分の情報を検索できます。** [bntpool.com](https://bntpool.com) の統計ページは `@name` と `$name` を受け付けるので、アドレスを貼り付けなくてもハッシュレートと残高を確認できます。
- **保存した名前は次回の実行時に改めて解決されます。** seine は名前を設定に保存するので、起動するたびにその時点で名前が指しているアドレスを使います。

残高はフルアドレスに属するので、後で名前を変更しても既存の残高の送り先が変わることはありません。すでに獲得した分はそれを獲得したアドレスに残ってそこへ支払われ、新たなマイニング分は新しいアドレスに割り当てられます。同じ名前は、自分のノードに対するソロモードでも使えます。

マイニングが初めての方は、[Blocknet のマイニングガイド](/ja/blog/how-to-mine-blocknet/)で seine のダウンロード、ハードウェア、bntpool.com での支払いについてご覧ください。
