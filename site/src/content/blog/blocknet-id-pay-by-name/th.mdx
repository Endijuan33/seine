เมื่อมีชื่อสั้น Blocknet ID คนอื่นจ่ายให้คุณที่ `@yourname` ได้ คุณแชร์ลิงก์ชำระเงินที่พอดีในข้อความแชต และขุดบน bntpool.com ไปยังชื่อเดียวกันได้ คู่มือนี้อธิบายการทำงานของชื่อ วิธีจดที่ blocknet.id และวิธีใช้ในกระเป๋าเงินกับ seine

## ชื่อสั้น Blocknet ID คืออะไร?

<Answer>
ชื่อสั้น Blocknet ID คือชื่อสั้นๆ เช่น @alice หรือ $alice ที่ชี้ไปยังที่อยู่กระเป๋าเงิน Blocknet ของคุณ คุณจดได้ที่ blocknet.id กระเป๋าเงิน seine และ bntpool.com จะค้นหาชื่อ ตรวจว่า blocknet.id ลงลายเซ็นระเบียน แล้วใช้ที่อยู่เต็มที่ชื่อนั้นชี้ไป
</Answer>

กฎเหมือนกันทุกที่ที่รองรับชื่อ:

- **คำนำหน้าสองแบบ** `@name` และ `$name` คือชื่อเดียวกัน เลือกใช้แบบที่ชอบ
- **ไม่แยกตัวพิมพ์เล็กใหญ่** `@Alice` และ `@alice` ชี้ไปที่อยู่เดียวกัน
- **อักขระง่ายๆ** อักษร a ถึง z ตัวเลข 0 ถึง 9 ขีดล่าง ขีดกลาง และจุด
- **สูงสุด 64 ตัวอักษร**

ทุกระเบียนที่ blocknet.id มีลายเซ็น เมื่อกระเป๋าเงินค้นหาชื่อ จะดึงระเบียนแล้วตรวจลายเซ็น Ed25519 กับคีย์ลงลายเซ็นที่ blocknet.id เผยแพร่ไว้ที่ `https://blocknet.id/.well-known/blocknet-id.json` ข้อมูลที่ลงลายเซ็นมีชื่อ ที่อยู่ และเวลาอัปเดตล่าสุด กระเป๋าเงินยืนยันว่าทั้งสามตรงกันก่อนใช้ที่อยู่ แต่ละชื่อยังมีหน้าสาธารณะที่ blocknet.id แสดงที่อยู่ ข้อมูลที่ลงลายเซ็นและลายเซ็น ทุกคนจึงตรวจระเบียนได้เอง

## ทำไมจ่ายให้ชื่อแทนที่อยู่?

ที่อยู่ Blocknet คือการเข้ารหัส base58 ของ public spend key, public view key และเช็กซัม รวมเป็น 92 หรือ 93 ตัวอักษร ซึ่งยาวมากเมื่อต้องคัดลอกข้ามแอป อ่านออกเสียง หรือใส่ในโปรไฟล์ ชื่อสั้นพูดในประโยค พิมพ์บนสติกเกอร์ หรือใส่ในประวัติส่วนตัวได้

คุณยังได้ขั้นตอนยืนยันที่ชัดเจน เมื่อส่งไปยังชื่อ กระเป๋าเงินแสดงที่อยู่ที่ค้นได้พร้อมเครื่องหมายตรวจสอบแล้วก่อนอนุมัติการจ่าย ชื่อเพียงแทนที่อยู่ที่คุณจะแชร์อยู่แล้ว บนเชน การจ่ายยังเป็นธุรกรรม Blocknet ปกติไปยัง[stealth address แบบใช้ครั้งเดียว](/th/blog/blocknet-privacy-features/) จึงเป็นส่วนตัวเท่ากับการจ่ายอื่น

## ขอ Blocknet ID อย่างไร?

<Answer>
คัดลอกที่อยู่กระเป๋าเงิน เปิด blocknet.id แล้วค้นหาชื่อที่ต้องการ หากยังว่าง เว็บไซต์จะแสดงราคา ให้วางที่อยู่แล้วส่งคำขอ ชื่อเก้าตัวอักษรขึ้นไปฟรีระหว่างโปรโมชันปัจจุบัน เมื่อจดแล้วใช้ชื่อในกระเป๋าเงิน seine และ bntpool.com ได้
</Answer>

1. **คัดลอกที่อยู่** ในกระเป๋าเงินแบบบรรทัดคำสั่ง คำสั่ง `address` แสดงที่อยู่ ตามด้วยบรรทัด “รับชื่อสั้นอย่าง @name หรือ $name ได้ที่ https://blocknet.id” ดาวน์โหลดกระเป๋าเงินจาก[รีลีสแบบบรรทัดคำสั่ง](https://github.com/blocknetprivacy/blocknet/releases/latest) หรือ[รีลีสเดสก์ท็อป](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)
2. **ค้นหาชื่อ** ไปที่ [blocknet.id](https://blocknet.id) พิมพ์ชื่อในช่อง “find a name” แล้วกด Search ขณะพิมพ์ หน้าจะแจ้งหากมีอักขระที่ใช้ไม่ได้หรือชื่อยาวเกินไป
3. **ดูผลลัพธ์** ชื่อที่ว่างแสดงราคา ชื่อที่จดแล้วแสดงที่อยู่ เวลาอัปเดตล่าสุด และลิงก์หน้าสาธารณะ
4. **จดชื่อ** วางที่อยู่กระเป๋าเงินแล้วกด “Claim free” หรือ “Register” สำหรับชื่อที่มีราคา

ราคาเป็นการจ่ายครั้งเดียวตามความยาวชื่อ ณ เวลาที่เขียน (ตุลาคม 2026) ทุกชื่อเก้าตัวอักษรขึ้นไปฟรีตามโปรโมชัน ซึ่งเว็บไซต์ระบุว่า “ไม่มีใบแจ้งหนี้ ไม่ต้องชำระเงิน” ชื่อแปดตัวอักษรราคา 100 BNT และชื่อสั้นกว่านั้นแพงขึ้น สูงสุด 6,000 BNT สำหรับตัวอักษรเดียว [หน้าราคา](https://blocknet.id/pricing) แสดงทุกความยาว

หากต้องการจัดการชื่อภายหลัง ให้ใช้ “sign in” ที่ blocknet.id ด้วยที่อยู่ Blocknet ของคุณ หน้าจัดการเป็นที่สำหรับเปลี่ยนชื่อให้ชี้ไปยังที่อยู่อื่น

## ส่ง BNT ให้ชื่ออย่างไร?

ในกระเป๋าเงินแบบบรรทัดคำสั่ง ใส่ชื่อแทนที่อยู่:

```
send @rock 100 "hello"
```

กระเป๋าเงินค้นหา `@rock` แสดง `Resolved @rock -> <address>` พร้อมเครื่องหมายตรวจสอบแล้ว จากนั้นขอให้ยืนยัน หน้ายืนยันแสดงชื่อ ที่อยู่เต็ม ค่าธรรมเนียม และเมโม รูปแบบ `$rock` ทำงานเหมือนกัน และ `send` รับทั้งจำนวนเต็มและจำนวนทศนิยม

API กระเป๋าเงินค้นหาชื่อแบบเดียวกันให้ผู้รับทุกรายในคำขอส่ง เครื่องมือที่สร้างบนกระเป๋าเงินจึงรองรับการจ่ายด้วยชื่อโดยไม่ต้องเพิ่มงาน

## ลิงก์ชำระเงินใช้กับชื่ออย่างไร?

[ลิงก์ชำระเงิน](/th/blog/blocknet-payment-links/) มีผู้รับ จำนวนเงิน และเมโมที่ใส่หรือไม่ก็ได้ Blocknet รองรับสองรูปแบบ:

```
blocknet://<address>?amount=25&memo=invoice-42
https://bntpay.com/$yourname?amount=25&memo=invoice-42
```

ลิงก์ bntpay.com ใช้ชื่อแทนที่อยู่ได้จึงยังสั้น เมื่อเปิดจะเห็นหน้า “Pay $yourname” จำนวนเงินและเมโม พร้อมปุ่ม “Open in Wallet” ที่เปิดการจ่ายเป็นลิงก์ `blocknet://` หากวางรูปแบบใดรูปแบบหนึ่งในกระเป๋าเงินแบบบรรทัดคำสั่ง ระบบกรอกการส่งให้ยืนยัน ต้องใส่ช่อง `amount` ส่วนเมโมไม่บังคับและเก็บข้อความได้สูงสุด 124 bytes

จึงโพสต์ลิงก์เดียวเพื่อรับทิปหรือส่งใบแจ้งหนี้ในข้อความเดียวได้สะดวก

## ขุดไปยัง @name ของคุณอย่างไร?

ทั้ง seine และ bntpool.com รับชื่อสั้นเป็นที่อยู่รับเงิน เมื่อเปิด [seine](/th/#download) ครั้งแรก ให้ใส่ `@yourname` เมื่อถามที่อยู่ แล้วใช้พูลเริ่มต้น หากส่งผ่านบรรทัดคำสั่ง ให้ใส่อัญประกาศ:

```sh
./seine --address '@yourname'
```

<Note>
ใส่อัญประกาศรอบชื่อสั้นในคำสั่งเชลล์ โดยเฉพาะรูปแบบ `$name` เพื่อให้เชลล์ส่งต่อโดยไม่เปลี่ยนค่า ชื่อสั้นต้องใช้ seine v0.2.16 ขึ้นไป
</Note>

สิ่งที่จะเกิดขึ้นต่อไป:

- **seine ค้นหาที่อยู่จากชื่อตอนเริ่มทำงาน** ตรวจระเบียนที่ลงลายเซ็นจาก blocknet.id ตรวจที่อยู่ บันทึกที่อยู่เต็มที่ค้นได้ และใช้ที่อยู่นั้นตลอดการทำงาน รวมถึงเมื่อเชื่อมต่อพูลใหม่
- **พูลรับชื่อเมื่อเข้าสู่ระบบด้วย** bntpool.com ตรวจการจับคู่ชื่อที่ลงลายเซ็นเมื่อนักขุดเชื่อมต่อด้วยชื่อ แล้วใช้ที่อยู่เต็มกับงาน แชร์ ยอดคงเหลือและการจ่าย
- **ค้นหาตัวเองด้วยชื่อได้** หน้าสถิติบน [bntpool.com](https://bntpool.com) รับ `@name` และ `$name` คุณจึงติดตามแฮชเรตและยอดคงเหลือโดยไม่ต้องวางที่อยู่
- **ชื่อที่บันทึกไว้จะค้นหาใหม่ในการเปิดครั้งถัดไป** seine เก็บชื่อในไฟล์ตั้งค่า การเปิดใหม่แต่ละครั้งจึงใช้ที่อยู่ที่ชี้อยู่ในขณะนั้น

เพราะยอดคงเหลือเป็นของที่อยู่เต็ม การเปลี่ยนชื่อภายหลังไม่เปลี่ยนปลายทางของยอดเดิม สิ่งที่ขุดได้แล้วคงอยู่กับที่อยู่ที่สร้างรายได้นั้นและจ่ายไปที่เดิม ส่วนการขุดใหม่ไปยังที่อยู่ใหม่ ชื่อเดียวกันยังใช้ขุดเดี่ยวกับโหนดของคุณเองได้
