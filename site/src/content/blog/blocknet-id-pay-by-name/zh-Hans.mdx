有了 Blocknet ID 短名称，别人可以向 `@yourname` 付款，你可以分享一条放得进聊天消息的付款链接，还可以用同一个名称在 bntpool.com 挖矿。本指南介绍名称如何运作、如何在 blocknet.id 注册，以及如何在钱包和 seine 中使用它。

## 什么是 Blocknet ID 短名称？

<Answer>
Blocknet ID 短名称是 @alice 或 $alice 这样的短名称，指向你的 Blocknet 钱包地址。你在 blocknet.id 注册它。钱包、seine 和 bntpool.com 会查询该名称，检查记录是否由 blocknet.id 签名，然后使用它所对应的完整地址。
</Answer>

凡是接受名称的地方，规则都相同：

- **两种前缀。** `@name` 和 `$name` 是同一个名称，用哪个都可以。
- **不区分大小写。** `@Alice` 和 `@alice` 解析到同一个地址。
- **简单的字符。** 字母 a 到 z、数字 0 到 9、下划线、连字符和点。
- **最长 64 个字符。**

blocknet.id 上的每条记录都带有签名。钱包解析名称时，会获取这条记录，然后用 blocknet.id 在 `https://blocknet.id/.well-known/blocknet-id.json` 公布的签名公钥检查它的 Ed25519 签名。签名内容包含名称、地址和最后更新时间，钱包确认三者都匹配后才会使用该地址。每个名称在 blocknet.id 上还有一个公开页面，显示它的地址、签名内容和签名，任何人都可以自行核对。

## 为什么要付款给名称而不是地址？

Blocknet 地址是公开花费密钥、公开查看密钥和校验和的 base58 编码，长度为 92 或 93 个字符。要在应用之间复制、大声念出来或放进个人资料，这都太长了。短名称则可以在一句话里说出来、印在贴纸上或写进个人简介。

你还会得到一个清楚的确认步骤。向名称付款时，钱包会显示它解析得到的地址，并在你批准付款前标记为已验证。名称只是代替你原本就要分享的地址。在链上，这笔付款是一笔普通的 Blocknet 交易，发送到[一次性隐身地址](/zh-hans/blog/blocknet-privacy-features/)，因此和其他付款一样私密。

## 如何获取 Blocknet ID？

<Answer>
复制你的钱包地址，打开 blocknet.id，搜索你想要的名称。如果名称可用，网站会显示价格，粘贴你的地址并提交即可。当前优惠活动期间，九个字符及以上的名称免费。注册完成后，你的名称就能在钱包、seine 和 bntpool.com 中使用。
</Answer>

1. **复制你的地址。** 在命令行钱包中，`address` 命令会显示地址，后面跟着一行“Get a short name like @name or $name at https://blocknet.id”。钱包可从[命令行版本发布页](https://github.com/blocknetprivacy/blocknet/releases/latest)或[桌面版本发布页](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)下载。
2. **搜索名称。** 打开 [blocknet.id](https://blocknet.id)，在“find a name”输入框中输入名称，然后点击 Search。输入时，如果出现不允许的字符或名称过长，页面会提示你。
3. **查看结果。** 可用的名称会显示价格。已被注册的名称会显示它的地址、最后更新时间，以及指向其公开页面的链接。
4. **注册。** 粘贴你的钱包地址，点击“Claim free”（付费名称为“Register”）。

价格按名称长度一次性收取。截至撰写本文时（2026 年 10 月），九个字符及以上的名称在优惠活动中全部免费，用网站的话说就是“no invoice, no payment”（无需账单，无需付款）。八个字符的名称为 100 BNT，更短的名称价格更高，单个字符的名称最高 6,000 BNT。[价格页面](https://blocknet.id/pricing)列出了每种长度的价格。

之后要管理你的名称，可在 blocknet.id 点击“sign in”，用你的 Blocknet 地址登录。在管理页面中可以把名称指向另一个地址。

## 如何向名称发送 BNT？

在命令行钱包中，把名称填在原本填地址的位置：

```
send @rock 100 "hello"
```

钱包会解析 `@rock`，显示 `Resolved @rock -> <address>` 并带有已验证标记，然后请你确认。确认信息会显示名称、完整地址、手续费和你的备注。`$rock` 的写法效果相同，`send` 可以发送整数或小数金额。

钱包的 API 会以同样方式解析发送请求中每个收款人的名称，因此基于钱包开发的工具无需额外工作就能支持向名称付款。

## 付款链接如何配合名称使用？

[付款链接](/zh-hans/blog/blocknet-payment-links/)包含收款人、金额和可选的备注。Blocknet 支持两种形式：

```
blocknet://<address>?amount=25&memo=invoice-42
https://bntpay.com/$yourname?amount=25&memo=invoice-42
```

bntpay.com 链接可以用名称代替地址，所以链接很短。打开它会看到一个页面，显示“Pay $yourname”、金额和备注，并有一个“Open in Wallet”按钮，以 `blocknet://` 链接的形式打开这笔付款。把任一形式粘贴到命令行钱包中，它都会为你填好一笔待确认的发送。请包含 `amount` 字段；备注是可选的，最多可容纳 124 字节的文字。

这样就能轻松发布一条用于打赏的链接，或在一条消息里发出账单。

## 如何挖矿到你的 @name？

seine 和 bntpool.com 都接受短名称作为收款地址。第一次启动 [seine](/zh-hans/#download) 时，在地址提示处输入 `@yourname`，并接受默认矿池。如果要在命令行中传入，请加上引号：

```sh
./seine --address '@yourname'
```

<Note>
在 shell 命令中请给短名称加引号，尤其是 `$name` 形式，这样 shell 才会原样传递。短名称需要 seine v0.2.16 或更新版本。
</Note>

接下来会发生这些事：

- **seine 在启动时解析名称。** 它验证来自 blocknet.id 的签名记录，检查地址，在日志中记录解析得到的完整地址，并在整个运行期间（包括重新连接矿池时）都使用这个地址。
- **矿池在登录时也接受名称。** 矿工用名称连接时，bntpool.com 会验证签名映射，并在任务、份额、余额和付款中使用解析得到的完整地址。
- **你可以按名称查询自己。** [bntpool.com](https://bntpool.com) 的统计页面接受 `@name` 和 `$name`，所以不必粘贴地址就能查看算力和余额。
- **保存的名称会在下次运行时重新解析。** seine 会把名称保存在配置中，因此每次重新启动都会使用名称当时指向的地址。

由于余额属于完整地址，之后更改名称绝不会转移已有余额。你已经赚到的收益仍属于赚取它的地址并支付到那里，而新的挖矿收益会计入新地址。同一个名称在对接自己节点的独立挖矿（solo）模式下也能使用。
