Blocknet ID 짧은 이름이 있으면 다른 사람이 `@yourname`으로 결제할 수 있고, 채팅 메시지 하나에 들어가는 결제 링크를 공유할 수 있으며, 같은 이름으로 bntpool.com에서 채굴할 수 있습니다. 이 가이드에서는 이름이 작동하는 방식, blocknet.id에서 이름을 받는 방법, 지갑과 seine에서 이름을 쓰는 방법을 다룹니다.

## Blocknet ID 짧은 이름이란 무엇입니까?

<Answer>
Blocknet ID 짧은 이름은 @alice나 $alice처럼 Blocknet 지갑 주소를 가리키는 짧은 이름입니다. blocknet.id에서 등록합니다. 지갑, seine, bntpool.com은 이름을 조회하고 blocknet.id가 레코드에 서명했는지 확인한 뒤, 이름에 연결된 전체 주소를 사용합니다.
</Answer>

이름을 받는 곳이라면 어디서나 규칙이 같습니다.

- **두 가지 접두사.** `@name`과 `$name`은 같은 이름입니다. 원하는 쪽을 쓰면 됩니다.
- **대소문자 구분 없음.** `@Alice`와 `@alice`는 같은 주소를 가리킵니다.
- **간단한 문자.** 영문 a~z, 숫자 0~9, 밑줄, 하이픈, 마침표.
- **최대 64자.**

blocknet.id의 모든 레코드는 서명되어 있습니다. 지갑은 이름을 주소로 변환할 때 레코드를 가져온 뒤, blocknet.id가 `https://blocknet.id/.well-known/blocknet-id.json`에 공개한 서명 키로 Ed25519 서명을 검사합니다. 서명된 데이터에는 이름, 주소, 마지막 업데이트 시각이 들어 있으며, 지갑은 세 가지가 모두 일치하는지 확인한 뒤에 주소를 사용합니다. 이름마다 blocknet.id에 주소, 서명된 데이터, 서명을 보여 주는 공개 페이지도 있으므로 누구나 직접 레코드를 확인할 수 있습니다.

## 주소 대신 이름으로 결제하면 무엇이 좋습니까?

Blocknet 주소는 공개 지출 키, 공개 조회 키, 체크섬을 base58로 인코딩한 것으로 92~93자에 이릅니다. 앱 사이에서 복사하거나, 소리 내어 읽거나, 프로필에 넣기에는 깁니다. 짧은 이름은 문장 속에서 말하거나, 스티커에 인쇄하거나, 자기소개에 넣을 수 있습니다.

확인 단계도 명확해집니다. 이름으로 보내면 지갑은 결제를 승인하기 전에 변환된 주소를 출력하고 검증됨(verified)으로 표시합니다. 이름은 어차피 공유했을 주소를 대신할 뿐입니다. 체인에서 결제는 [일회용 스텔스 주소](/ko/blog/blocknet-privacy-features/)로 보내는 일반 Blocknet 트랜잭션이므로, 다른 결제와 똑같이 프라이빗하게 유지됩니다.

## Blocknet ID는 어떻게 받습니까?

<Answer>
지갑 주소를 복사하고 blocknet.id를 열어 원하는 이름을 검색하세요. 사용할 수 있는 이름이면 사이트에 가격이 표시됩니다. 주소를 붙여 넣고 제출하면 됩니다. 현재 프로모션 기간에는 9자 이상의 이름이 무료입니다. 등록하면 지갑, seine, bntpool.com에서 바로 이름을 쓸 수 있습니다.
</Answer>

1. **주소를 복사합니다.** 명령줄 지갑에서 `address` 명령을 실행하면 주소가 출력되고, 이어서 "Get a short name like @name or $name at https://blocknet.id"라는 줄이 표시됩니다. 지갑은 [명령줄 지갑 릴리스](https://github.com/blocknetprivacy/blocknet/releases/latest)나 [데스크톱 지갑 릴리스](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)에서 받을 수 있습니다.
2. **이름을 검색합니다.** [blocknet.id](https://blocknet.id)로 가서 "find a name"(이름 찾기) 상자에 이름을 입력하고 Search(검색)를 누르세요. 입력하는 동안 허용되지 않는 문자가 있거나 이름이 너무 길면 페이지가 알려 줍니다.
3. **결과를 확인합니다.** 사용할 수 있는 이름은 가격이 표시됩니다. 이미 등록된 이름은 주소, 마지막 업데이트 시각, 공개 페이지 링크가 표시됩니다.
4. **등록합니다.** 지갑 주소를 붙여 넣고 "Claim free"(무료 등록)를 누르세요. 유료 이름은 "Register"(등록)입니다.

가격은 이름 길이에 따른 일회성 요금입니다. 이 글을 쓰는 시점(2026년 10월)에는 프로모션으로 9자 이상의 모든 이름이 무료이며, 사이트 표현으로는 "no invoice, no payment", 즉 청구서도 결제도 없습니다. 8자 이름은 100 BNT이고, 더 짧은 이름은 더 비싸져 한 글자 이름은 6,000 BNT입니다. [가격 페이지](https://blocknet.id/pricing)에 길이별 가격이 모두 나와 있습니다.

나중에 이름을 관리하려면 blocknet.id에서 Blocknet 주소로 "sign in"(로그인)하세요. 관리 페이지에서 이름이 가리키는 주소를 바꿀 수 있습니다.

## 이름으로 BNT를 보내려면 어떻게 합니까?

명령줄 지갑에서 주소 자리에 이름을 넣으세요.

```
send @rock 100 "hello"
```

지갑은 `@rock`을 주소로 변환해 검증 표시와 함께 `Resolved @rock -> <address>`를 출력한 뒤 확인을 요청합니다. 확인 화면에는 이름, 전체 주소, 수수료, 메모가 표시됩니다. `$rock` 형식도 똑같이 작동하며, `send`는 정수와 소수 금액을 모두 받습니다.

지갑 API도 송금 요청의 모든 수신자에 대해 같은 방식으로 이름을 주소로 변환하므로, 지갑을 기반으로 만든 도구는 추가 작업 없이 이름 결제를 지원합니다.

## 이름과 함께 결제 링크는 어떻게 작동합니까?

[결제 링크](/ko/blog/blocknet-payment-links/)에는 수신자, 금액, 선택 사항인 메모가 담깁니다. Blocknet은 두 가지 형식을 지원합니다.

```
blocknet://<address>?amount=25&memo=invoice-42
https://bntpay.com/$yourname?amount=25&memo=invoice-42
```

bntpay.com 링크는 주소 대신 이름을 쓸 수 있으므로 짧게 유지됩니다. 링크를 열면 "Pay $yourname"($yourname에게 결제), 금액, 메모가 표시된 페이지와 결제를 `blocknet://` 링크로 여는 "Open in Wallet"(지갑에서 열기) 버튼이 나타납니다. 어느 형식이든 명령줄 지갑에 붙여 넣으면 송금 내용이 채워지고 확인만 하면 됩니다. `amount` 필드는 넣어야 하며, 메모는 선택 사항으로 최대 124바이트의 텍스트를 담습니다.

덕분에 후원용 링크 하나를 올려 두거나, 메시지 한 통으로 청구서를 보내기가 쉬워집니다.

## @name으로 채굴하려면 어떻게 합니까?

seine와 bntpool.com 모두 짧은 이름을 수령 주소로 받습니다. [seine](/ko/#download)를 처음 실행할 때 주소 입력란에 `@yourname`을 입력하고 기본 풀을 선택하세요. 명령줄에서 넘기려면 따옴표로 감싸세요.

```sh
./seine --address '@yourname'
```

<Note>
셸 명령에서는 짧은 이름, 특히 `$name` 형식을 따옴표로 감싸야 셸이 그대로 전달합니다. 짧은 이름은 seine v0.2.16 이상이 필요합니다.
</Note>

그다음에는 이렇게 진행됩니다.

- **seine는 시작할 때 이름을 주소로 변환합니다.** blocknet.id의 서명된 레코드를 검증하고, 주소를 검사하고, 변환된 전체 주소를 로그에 남긴 뒤, 풀 재연결을 포함해 실행하는 동안 그 주소를 유지합니다.
- **풀도 로그인 시 이름을 받습니다.** 채굴기가 이름으로 접속하면 bntpool.com이 서명된 매핑을 검증하고, 변환된 전체 주소를 작업, 셰어, 잔액, 지급에 사용합니다.
- **이름으로 내 통계를 조회할 수 있습니다.** [bntpool.com](https://bntpool.com)의 통계 페이지는 `@name`과 `$name`을 받으므로, 주소를 붙여 넣지 않고도 해시레이트와 잔액을 확인할 수 있습니다.
- **저장된 이름은 다음 실행 때 다시 변환됩니다.** seine는 설정에 이름을 저장하므로, 새로 시작할 때마다 그 시점에 이름이 가리키는 주소를 사용합니다.

잔액은 전체 주소에 속하므로, 나중에 이름을 바꿔도 기존 잔액이 다른 곳으로 가지 않습니다. 이미 번 금액은 그 금액을 번 주소에 남아 그 주소로 지급되고, 새로 채굴한 몫은 새 주소로 갑니다. 같은 이름은 자신의 노드를 상대로 하는 솔로 모드에서도 작동합니다.

채굴이 처음이라면 [Blocknet 채굴 가이드](/ko/blog/how-to-mine-blocknet/)에서 seine 다운로드, 하드웨어, bntpool.com 지급을 차례로 안내합니다.
