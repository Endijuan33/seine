เฝ้าดูเงินเข้า Blocknet บนคอมพิวเตอร์เครื่องที่สองโดยเก็บสิทธิ์อนุมัติการจ่ายไว้ในกระเป๋าเต็ม คู่มือนี้ใช้ CLI ทางการ v1.2.0 และ core สาธารณะ v0.22.0 ที่ตรวจเมื่อ 27 ตุลาคม 2026 โดยตามขั้นตอนส่งออกไฟล์ อธิบายสิทธิ์ที่ไฟล์ให้ และแสดงวิธีตรวจบันทึกรับหลังโหลด

## สร้างกระเป๋า Blocknet แบบดูอย่างเดียวอย่างไร?

<Answer>
เปิดกระเป๋าเต็มแล้วใช้ viewkeys สร้างไฟล์ดูที่เข้ารหัสด้วยรหัสผ่านแยก ย้ายไฟล์ไปเครื่องที่ตั้งใจ โหลดแล้วตรวจที่อยู่กับชนิดดูอย่างเดียว ปล่อยให้สแกนตามทัน จากนั้นใช้ดูเงินเข้า โดยยังใช้กระเป๋าเต็มเพื่อใช้จ่าย
</Answer>

## เลือกรายการรับที่ต้องการเฝ้าดู

เริ่มจากกระเป๋าเต็มที่ต้องการดูเงินเข้า [คู่มือตั้งค่ากระเป๋า](/th/blog/blocknet-wallet-for-mining/) อธิบายการสร้างหรือกู้คืน สำเนาดูตรงกับที่อยู่ของกระเป๋านั้น ไม่ได้สร้างตัวตนรับเงินแยกหรือย้ายเหรียญเข้าบัญชีใหม่ จดว่าของกระเป๋าใดและเครือข่ายใดก่อนจัดการไฟล์ส่งออก

สำหรับการขุด คุณใช้ที่อยู่รับเงินที่ตรวจแล้วเดิมต่อได้ กระเป๋าดูช่วยตรวจบันทึกเงินเข้าบนอีกเครื่องที่ไว้ใจ [คู่มือติดตามพูล](https://bntpool.com/blog/th/track-your-miner-on-bntpool/) ทำงานอีกแบบ คือแสดงแชร์ ยอดพูล และกิจกรรมจ่ายโดยไม่ใช้กุญแจกระเป๋า เลือกหน้าที่ตอบคำถามคุณ สิทธิ์ดูมีประโยชน์เมื่อจำเป็นต้องดูบันทึกรับส่วนตัว

## ส่งออกไฟล์ดูจากกระเป๋าเต็ม

บนเครื่องที่มีกระเป๋าเต็ม เชื่อมต่อ mainnet core ที่ทำงานอยู่:

```sh
blocknet attach mainnet
```

เปิดกระเป๋าที่ต้องการและตรวจที่อยู่ด้วยคำสั่งเชลล์:

```text
load
address
```

หากล็อกอยู่ ใช้พรอมต์ปลดล็อกตามปกติ เก็บเซสชันนี้เป็นส่วนตัวเพราะขั้นถัดไปแสดงข้อมูลกุญแจดู

เริ่มส่งออก:

```text
viewkeys
```

[ไคลเอนต์ที่ตรวจสอบ](https://github.com/blocknetprivacy/blocknet/blob/948af4de8b7a3e3cddc86a329c7d2d003cb3fd6b/attach_wallet.go) อธิบายว่ากุญแจส่วนตัวสำหรับดูเผยเงินเข้าและถามให้ดำเนินต่อ ทำต่อเมื่อคุณตั้งใจให้สิทธิ์นั้นเท่านั้น จากนั้นระบบขอรหัสผ่านกระเป๋าเต็ม รหัสผ่านใหม่ของไฟล์ดูอย่างเดียว และยืนยันรหัสใหม่ เลือกและเก็บรหัสไฟล์สำหรับเครื่องปลายทาง

## ควรย้ายไฟล์ไหน?

เมื่อส่งออกสำเร็จ ไคลเอนต์แสดงกุญแจดูและพาธไฟล์ที่บันทึก ใช้พาธจริงนั้นระบุไฟล์ดูที่ส่งออก ย้ายด้วยวิธีที่เหมาะกับข้อมูลกระเป๋าส่วนตัวไปเครื่องที่คุณควบคุม ปกป้องรหัสผ่านไฟล์แยกต่างหาก อย่าใส่ผลกุญแจจากเทอร์มินัลในภาพหน้าจอหรือบันทึกแก้ปัญหา

[เอกสารกระเป๋า](https://github.com/blocknetprivacy/blocknet/blob/948af4de8b7a3e3cddc86a329c7d2d003cb3fd6b/docs/reference-wallet.md) ระบุโฟลเดอร์เริ่มต้นเป็น `~/.config/bnt/wallets/` และเทียบเท่าบน Windows คือ `C:\Users\<you>\.config\bnt\wallets\` การตั้งค่าพาธกระเป๋าอาจเปลี่ยนโฟลเดอร์ที่ load แสดง คัดลอกไฟล์ส่งออกเข้าโฟลเดอร์กระเป๋าปลายทางเพื่อให้ไคลเอนต์หาเจอ เก็บกระเป๋าเต็มต้นฉบับและสำรองกู้คืนไว้ในที่เก็บที่ตั้งใจ

## โหลดและตรวจสำเนาบนเครื่องที่สอง

เตรียม core ที่ทำงานบนปลายทางตาม [คู่มือโหนด](/th/blog/run-blocknet-node/) แล้วเชื่อมเครือข่ายเดียวกัน เปิดไฟล์ส่งออกด้วยรหัสผ่านที่เลือกสำหรับไฟล์นั้น:

```text
load
```

หากกระเป๋าอื่นเปิดอยู่ เชลล์ทางการรองรับการยกเลิกโหลดก่อนโหลดไฟล์ที่ต้องการ เลือกตามชื่อไฟล์ส่งออก ไม่ควรคิดว่ารายการแรกถูกต้องเสมอ

ตรวจสำเนาผ่านไคลเอนต์:

```text
address
status
```

เทียบที่อยู่รับเต็มกับกระเป๋าเต็ม ตรวจชนิดดูอย่างเดียวที่ไคลเอนต์แสดง การตรวจนี้ยืนยันทั้งตัวตนและสิทธิ์ที่ตั้งใจ ไม่ต้องทดลองส่งเพื่อทดสอบความต่าง เพราะ [core ที่ตรวจสอบ](https://github.com/blocknetprivacy/core/blob/5a0a5b510c1dce46f4eeb12c33a291052e44e7b3/api_handlers.go) ปฏิเสธการส่งและลงนามข้อความจากกระเป๋าดูอย่างเดียว

## ให้กระเป๋าดูค้นหาเงินเข้า

โหนดปลายทางต้องมีบล็อกที่เกี่ยวข้อง และกระเป๋าที่โหลดต้องสแกน ใช้คำสั่งเชลล์เหล่านี้ดูบันทึก:

```text
outputs
history
```

กระเป๋าที่เพิ่งโหลดหรือนำเข้าอาจยังตามอยู่แม้โหนดมีเพียร์ ตาม [คู่มือซิงก์กระเป๋า](/th/blog/blocknet-wallet-not-syncing/) เพื่อแยกการดาวน์โหลดเชนจากการสแกน และตัดสินว่าจำเป็นต้องสแกนหรือไม่

จับคู่รายการรับกับ ID ที่มีจากกระเป๋าเต็มหรือบันทึกจ่าย [คู่มือตัวสำรวจ](/th/blog/blocknet-explorer-guide/) ช่วยยืนยันการบรรจุสาธารณะ ส่วนกระเป๋าดูให้รายละเอียดเงินเข้า ใช้กระเป๋าเต็มสำหรับตัดสินใจใช้จ่ายปัจจุบันและอนุมัติ ถือสำเนาดูเป็นตัวติดตามเงินเข้า ไม่ควรคิดว่าสะท้อนทุกบันทึกส่งออกหรือทุกการตัดสินยอดที่ใช้ได้

## กุญแจส่วนตัวสำหรับดูให้อะไรบ้าง?

[เอกสารเชลล์ทางการ](https://github.com/blocknetprivacy/blocknet/blob/948af4de8b7a3e3cddc86a329c7d2d003cb3fd6b/docs/reference-core.md) เตือนว่าผู้ถือกุญแจดูเห็นเงินเข้าได้ ไฟล์ดูที่เข้ารหัสป้องกันสิทธิ์ด้วยรหัสผ่านของตัวเอง แต่เมื่อเปิดก็เผยข้อมูลการชำระเงินส่วนตัว ให้สิทธิ์เฉพาะคนหรือเครื่องที่ตั้งใจ การเปลี่ยนรหัสไฟล์ไม่เพิกถอนกุญแจดูที่ผู้อื่นคัดลอกแล้ว

เก็บความลับทั้งใช้จ่ายและดูออกจากเครื่องมือสาธารณะกับข้อความช่วยเหลือ ที่อยู่รับมีไว้แชร์เพื่อชำระเงิน แต่กุญแจส่วนตัวสำหรับดูมีอีกหน้าที่ [คู่มือที่อยู่ stealth](/th/blog/stealth-addresses-explained/) อธิบายว่ากระเป๋าจำเอาต์พุตตนอย่างไร สำหรับการตั้งค่านี้ให้โอนเฉพาะสิทธิ์ดูที่ตั้งใจ และเก็บข้อมูลกู้คืนไว้กับกระเป๋าเต็ม

## รักษาขั้นตอนดูที่ทำซ้ำได้

เมื่อกลับมาเครื่องติดตาม โหลดไฟล์ดูเดิม ตรวจเครือข่ายกับที่อยู่ และดูความคืบหน้าก่อนสรุปว่ารายการหาย แยกบันทึกเงินรับจากเงินที่คุณอนุมัติใช้จ่ายได้ หากกระเป๋าต้นทางมีที่อยู่ใหม่เพราะสร้างกระเป๋าอื่น สำเนาดูเดิมยังตรงกับอันเก่า

เก็บสำรองกู้คืนกระเป๋าเต็มไว้แม้ตั้งค่าดูสำเร็จ สำเนาดูไม่แทนข้อมูลใช้จ่ายที่จำเป็นต่อการกู้คืน [คู่มือ seed](/th/blog/seed-phrase-explained/) อธิบายสำรอง ส่วน [การส่งและรับ](/th/blog/send-receive-blocknet/) อธิบายขั้นตอนจ่าย กระเป๋าเต็ม สำรอง และสำเนาดูจึงมีหน้าที่ชัดเจนแยกกันในกิจวัตร
