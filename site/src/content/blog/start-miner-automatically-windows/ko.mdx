로그인할 때 정상 동작하는 seine 설정을 Windows가 열도록 구성합니다. 사용자 세션에서 작업 스케줄러를 사용하며 해제 방법도 명확합니다. 먼저 [Windows 설정](/ko/blog/mine-blocknet-on-windows/)을 완료하고 풀이 셰어를 승인하는지 확인하세요. 검증된 명령을 자동화하면 결과를 확인하기 쉽습니다.

## Blocknet 채굴기를 자동으로 시작하려면?

<Answer>
Windows 계정용 작업을 만들고 로그인 시 실행되도록 설정한 뒤 압축을 푼 seine 실행 파일을 지정합니다. 기존 데이터 폴더와 작업 폴더를 사용하고 같은 작업의 두 번째 인스턴스를 막은 후, 시험 실행에서 승인된 셰어를 확인합니다.
</Answer>

## 어떤 파일과 설정을 보관해야 하나요?

압축을 푼 릴리스에 고정 폴더를 사용하세요. 라이브러리를 포함한 모든 파일을 함께 보관하고 그 안의 프로그램을 지정합니다. 성공한 수동 실행의 데이터 폴더를 찾으세요. seine은 기본적으로 작업 폴더 기준 `./seine-data`를 사용하고 `seine.config.json`에 연결 설정을 저장합니다. 시작 폴더가 달라지면 다른 설정을 찾을 수 있습니다.

예시는 `C:\Users\YOUR_USER\Apps\seine`를 사용합니다. 전체 경로를 실제 설치 폴더로 바꾸세요. 데이터는 기존 위치에 유지하고 정상 동작하는 명령도 보관하세요. 명시적인 백엔드나 조정 옵션이 계속 필요할 수 있습니다. 이 작업에는 지갑 복구 구문이나 개인 키가 필요하지 않습니다.

## 로그인 작업 만들기

시작 메뉴에서 **작업 스케줄러**를 열고 **작업 만들기**를 선택합니다. **seine mining**처럼 알아볼 이름을 지정하세요. **일반**에서 수동 채굴에 쓰던 계정과 **사용자가 로그온할 때만 실행**을 선택합니다. 이 일반 설정에서는 **가장 높은 수준의 권한으로 실행**을 해제합니다. **트리거**에서 특정 사용자의 **로그온할 때**를 추가하고 사용하도록 설정합니다. [Microsoft 설명](https://learn.microsoft.com/en-us/windows/win32/taskschd/starting-an-executable-when-a-user-logs-on)을 참고하세요.

**동작**에서 **프로그램 시작**을 추가하고 각 필드를 따로 입력합니다.

- **프로그램/스크립트:** 찾아보기로 `C:\Users\YOUR_USER\Apps\seine\seine.exe` 선택.
- **인수 추가:** 기존 데이터 폴더에 맞춘 `--data-dir "C:\Users\YOUR_USER\Apps\seine\seine-data"` 뒤에 검증된 명령의 옵션 입력.
- **시작 위치:** `C:\Users\YOUR_USER\Apps\seine`를 따옴표 없이 입력.

[작업 폴더](https://learn.microsoft.com/en-us/windows/win32/taskschd/execaction-workingdirectory)는 프로세스의 시작 위치입니다. 프로그램 필드에 옵션을 넣거나 시작 위치에 실행 파일 이름을 넣지 마세요. 예시 경로를 그대로 두지 말고 실제 파일을 선택하세요.

## 실행 조건 설정하기

**설정**에서 테스트를 위해 요청 시 실행을 허용하세요. 이미 실행 중이면 **새 인스턴스 시작 안 함**을 선택합니다. 이 [인스턴스 정책](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-multipleinstances)은 같은 작업에만 적용되며 따로 실행한 채굴기를 감지하지 않습니다. 테스트 전에 수동 실행을 종료하세요. 의도한 프로세스 하나가 확인하기 쉽고 같은 설정을 쓰는 두 번째 실행을 막습니다.

로그인 중 계속 채굴하려면 **작업이 다음 시간 이상 실행되면 중지**를 해제하세요. 그렇지 않으면 [실행 시간 제한](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-executiontimelimit)이 적용됩니다. **조건**도 확인하세요. 유휴 상태 요구는 즉시 테스트를 막을 수 있습니다. 노트북에서 AC 전원 조건을 유지하면 전원이 연결된 경우에만 이 방식을 사용합니다. 사용 방식에 맞게 저장하세요.

## 자동 채굴이 작동하는지 확인하려면?

수동 채굴기를 정상 종료한 뒤 작업을 선택하고 **실행**을 누릅니다. 창에서 지급 주소, 풀, 장비 이름을 확인하고 승인된 셰어를 기다리세요. bntpool.com의 My Stats에서 같은 주소를 찾아 해당 장비가 작업을 보내는지 확인합니다. 작업 실행 상태는 프로세스만 증명하며 승인된 셰어가 유효한 풀 작업을 증명합니다.

실제 트리거 테스트는 다른 작업을 저장한 뒤 로그아웃하고 선택한 계정으로 로그인하는 것입니다. 화면 잠금과 해제는 다른 동작입니다. 주소와 최근 셰어를 다시 확인하세요. [대시보드 가이드](/ko/blog/seine-dashboard-explained/)가 장치와 연결 정보를 설명합니다. 업데이트를 위해 작업 이름과 폴더를 기록하세요.

## 시작하지 않으면 무엇을 확인하나요?

실행 파일 경로, 계정, 인수, 시작 위치를 정상 수동 명령과 비교하세요. 초기 설정이 다시 나오면 데이터 경로와 접근 권한을 먼저 확인합니다. 라이브러리를 못 읽으면 전체 압축 해제를 확인하세요. 창이 없다면 채굴기 설정을 바꾸기 전에 활성 트리거와 전원·유휴 조건을 확인합니다.

채굴기는 실행되지만 셰어가 안 보이면 주소, 풀 연결, 장비의 최근 셰어를 확인하세요. 두 컴퓨터가 같은 지갑을 쓰면 [여러 컴퓨터 가이드](https://bntpool.com/blog/ko/mine-multiple-computers-one-wallet/)에 따라 서로 다른 이름을 지정합니다. 작업은 검증된 설정을 여는 데 사용하고, 연결과 하드웨어 진단은 실행 중인 채굴기에서 하세요.

## 자동 시작 해제 또는 업데이트

이후 실행을 막으려면 작업을 선택해 **사용 안 함**으로 바꾸세요. 이미 실행 중인 채굴기는 해당 창에서 정상 종료합니다. 작업 비활성화만으로 그 프로세스는 끝나지 않습니다. 원할 때 다시 활성화하세요. Windows 전체 시작이나 절전 설정을 바꾸지 않고 선택을 확인하고 되돌릴 수 있습니다.

릴리스를 교체하기 전에 작업을 비활성화하고 채굴기를 중지하세요. [업데이트 가이드](/ko/blog/update-seine-miner/)에 따라 데이터를 보관하고 경로가 바뀌면 동작을 수정합니다. 실행으로 시험한 뒤 트리거를 다시 활성화하세요. Linux 시스템 서비스는 이 Windows 로그인 방식과 다른 [서버 설정](/ko/blog/mine-blocknet-on-servers/)을 사용합니다.
