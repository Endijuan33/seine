ตั้ง Windows ให้เปิด seine ที่ใช้งานได้อยู่แล้วเมื่อลงชื่อเข้าใช้ คู่มือนี้ใช้ Task Scheduler ภายในเซสชันของคุณและมีวิธีปิดที่ชัดเจน ทำตาม[การตั้งค่าบน Windows](/th/blog/mine-blocknet-on-windows/) ก่อนและยืนยันว่าพูลยอมรับแชร์ การทำให้คำสั่งที่ผ่านการทดสอบเป็นอัตโนมัติช่วยให้ตรวจสอบผลได้ง่าย

## เริ่มตัวขุด Blocknet อัตโนมัติอย่างไร?

<Answer>
สร้างงานสำหรับบัญชี Windows ให้เริ่มเมื่อลงชื่อเข้าใช้ และตั้งการกระทำให้เปิดโปรแกรม seine ที่แตกไฟล์แล้ว ระบุโฟลเดอร์ข้อมูลเดิมและโฟลเดอร์ทำงาน ป้องกันอินสแตนซ์ที่สองของงานเดียวกัน แล้วตรวจสอบแชร์ที่ยอมรับหลังทดลองเปิด
</Answer>

## ควรเก็บไฟล์และการตั้งค่าใดไว้?

เลือกโฟลเดอร์ถาวรสำหรับรุ่นที่แตกไฟล์ เก็บเนื้อหาในแพ็กเกจทั้งหมดไว้ด้วยกัน รวมถึงไลบรารี แล้วชี้ไปยังโปรแกรมในนั้น หาโฟลเดอร์ข้อมูลที่การเปิดด้วยมือสำเร็จใช้อยู่ โดยปริยาย seine ใช้ `./seine-data` อ้างอิงจากโฟลเดอร์ทำงาน และเก็บการเชื่อมต่อใน `seine.config.json` โฟลเดอร์เริ่มต้นที่ต่างกันอาจทำให้ค้นหาการตั้งค่าอีกชุด

ตัวอย่างใช้ `C:\Users\YOUR_USER\Apps\seine` ให้แทนที่พาธทั้งหมดด้วยตำแหน่งติดตั้งจริง เก็บข้อมูลเดิมไว้ที่เดิมและบันทึกคำสั่งที่ใช้งานได้ด้วย ตัวเลือก backend หรือการปรับแต่งที่ระบุเองอาจยังจำเป็น งานนี้ไม่ต้องใช้วลีกู้คืนหรือกุญแจส่วนตัวของกระเป๋า

## สร้างงานเมื่อลงชื่อเข้าใช้

เปิด **Task Scheduler** จาก Start แล้วเลือก **Create Task** ตั้งชื่อที่จำได้ เช่น **seine mining** ใน **General** เลือกบัญชีที่ใช้ขุดด้วยมือและ **Run only when user is logged on** อย่าเลือก **Run with highest privileges** สำหรับการตั้งค่าปกตินี้ ใน **Triggers** เพิ่ม **At log on** สำหรับผู้ใช้ของคุณโดยเฉพาะและเปิดใช้งานทริกเกอร์ อ่าน[เอกสาร Microsoft](https://learn.microsoft.com/en-us/windows/win32/taskschd/starting-an-executable-when-a-user-logs-on)

ใน **Actions** เพิ่ม **Start a program** แล้วกรอกแยกช่อง:

- **Program/script:** เลือก `C:\Users\YOUR_USER\Apps\seine\seine.exe` ผ่าน Browse
- **Add arguments:** ใส่ `--data-dir "C:\Users\YOUR_USER\Apps\seine\seine-data"` โดยใช้โฟลเดอร์ข้อมูลเดิม ตามด้วยตัวเลือกของคำสั่งที่ทำงานได้
- **Start in:** ใส่ `C:\Users\YOUR_USER\Apps\seine` โดยไม่มีเครื่องหมายคำพูด

[โฟลเดอร์ทำงาน](https://learn.microsoft.com/en-us/windows/win32/taskschd/execaction-workingdirectory) กำหนดตำแหน่งเริ่มต้นของโปรเซส อย่าใส่ตัวเลือกในช่องโปรแกรมหรือชื่อไฟล์โปรแกรมใน Start in เลือกไฟล์จริงแทนการปล่อยพาธตัวอย่างไว้

## ตั้งเงื่อนไขการทำงาน

ใน **Settings** อนุญาตให้เรียกงานตามต้องการเพื่อทดสอบ หากงานกำลังทำงานอยู่ เลือก **Do not start a new instance** [นโยบายอินสแตนซ์](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-multipleinstances) นี้ใช้กับงานนั้นเท่านั้น ไม่ตรวจพบตัวขุดที่เปิดแยกไว้ จึงควรปิดตัวที่เปิดด้วยมือก่อนทดสอบ โปรเซสเดียวที่ตั้งใจเปิดตรวจสอบง่ายและไม่เกิดสำเนาที่สองใช้การตั้งค่าเดียวกัน

หากต้องการขุดต่อเนื่องตลอดเซสชัน ให้ยกเลิก **Stop the task if it runs longer than** มิฉะนั้นจะมี[ขีดจำกัดเวลา](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-executiontimelimit) ตรวจ **Conditions** ด้วย เงื่อนไขเครื่องว่างอาจขัดขวางการทดสอบทันที บนแล็ปท็อป การคงเงื่อนไขไฟ AC จำกัดขั้นตอนนี้ไว้ตอนเสียบปลั๊ก บันทึกตัวเลือกที่ตรงกับการใช้งาน

## ตรวจสอบการขุดอัตโนมัติอย่างไร?

หยุดตัวขุดที่เปิดด้วยมือตามปกติ เลือกงานแล้วกด **Run** ตรวจที่อยู่รับเงิน พูล และชื่อเครื่องในหน้าต่าง รอแชร์ที่ยอมรับ ค้นหาที่อยู่นั้นใน My Stats บน bntpool.com และยืนยันว่าเครื่องที่ต้องการส่งงาน สถานะงานกำลังทำงานยืนยันเพียงโปรเซส ส่วนแชร์ที่ยอมรับยืนยันงานที่มีประโยชน์ต่อพูล

ทดสอบทริกเกอร์จริงโดยบันทึกงานอื่น ออกจากระบบ แล้วลงชื่อเข้าใช้บัญชีที่เลือก การล็อกและปลดล็อกหน้าจอเป็นคนละการกระทำ ตรวจที่อยู่และแชร์ล่าสุดอีกครั้ง [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายอุปกรณ์และการเชื่อมต่อ จดชื่องานและโฟลเดอร์ไว้สำหรับการอัปเดต

## ถ้าไม่เริ่มควรตรวจอะไร?

เทียบพาธโปรแกรม บัญชี อาร์กิวเมนต์ และ Start in กับคำสั่งที่เปิดด้วยมือได้ หากถามการตั้งค่าเริ่มต้นอีก ให้ตรวจพาธข้อมูลและสิทธิ์เข้าถึง หากโหลดไลบรารีไม่ได้ ให้ตรวจว่าแตกไฟล์ครบ หากไม่มีหน้าต่าง ให้ตรวจทริกเกอร์ที่เปิดใช้และเงื่อนไขพลังงานหรือเครื่องว่างก่อนเปลี่ยนการตั้งค่าตัวขุด

ถ้าตัวขุดทำงานแต่ไม่เห็นแชร์ ให้ตรวจที่อยู่ การเชื่อมต่อพูล และแชร์ล่าสุดของเครื่อง หากสองเครื่องใช้กระเป๋าเดียวกัน ตั้งชื่อต่างกันตาม[คู่มือหลายคอมพิวเตอร์](https://bntpool.com/blog/th/mine-multiple-computers-one-wallet/) ให้งานทำหน้าที่เปิดการตั้งค่าที่ทดสอบแล้ว ส่วนการวิเคราะห์เครือข่ายและฮาร์ดแวร์ทำในตัวขุดที่ทำงานอยู่

## ปิดการเริ่มอัตโนมัติหรืออัปเดตตัวขุด

เพื่อป้องกันการเปิดครั้งถัดไป เลือกงานแล้ว **Disable** หยุดตัวขุดที่เปิดอยู่ตามปกติในหน้าต่าง เพราะปิดงานไม่ได้หยุดโปรเซสนั้น เปิดใช้งานอีกครั้งเมื่อต้องการ ทางเลือกนี้มองเห็นและย้อนกลับได้โดยไม่เปลี่ยนการเริ่มต้นหรือโหมดพักของ Windows ทั้งระบบ

ก่อนเปลี่ยนรุ่น ให้ปิดงานและหยุดตัวขุด ทำตาม[คู่มืออัปเดต](/th/blog/update-seine-miner/) เก็บข้อมูลไว้ และแก้การกระทำหากพาธโปรแกรมเปลี่ยน ทดลองด้วย Run ก่อนเปิดทริกเกอร์อีกครั้ง หากต้องการบริการระบบ Linux ใช้[การตั้งค่าเซิร์ฟเวอร์](/th/blog/mine-blocknet-on-servers/) ซึ่งต่างจากการเปิดเมื่อเข้าสู่ Windows นี้
