อัปเดต seine โดยรักษาการเชื่อมต่อพูลและตัวเลือกที่ใช้งานได้อยู่ คู่มือนี้อ้างอิงรุ่นสาธารณะ v0.2.36 ครอบคลุมการเตรียม เปลี่ยนไฟล์ และตรวจสอบ หากติดตั้งครั้งแรกให้ใช้คู่มือ [Windows](/th/blog/mine-blocknet-on-windows/), [Linux](/th/blog/mine-blocknet-on-linux/) หรือ [Mac](/th/blog/mine-blocknet-on-mac/)

## อัปเดต seine อย่างไร?

<Answer>
ดาวน์โหลดและตรวจสอบไฟล์ทางการสำหรับระบบของคุณ หยุดโปรแกรม เก็บไดเรกทอรีข้อมูล แล้วเปลี่ยนไฟล์แอป เริ่มใหม่ด้วยไดเรกทอรีทำงานและอาร์กิวเมนต์เดิม ตรวจสอบเวอร์ชัน ปลายทางรับเงิน การเชื่อมต่อ และแชร์ที่ยอมรับก่อนอัปเดตเครื่องอื่น
</Answer>

## ตรวจสอบเวอร์ชันปัจจุบันอย่างไร?

ใช้คำสั่งเวอร์ชันกับไฟล์ที่ใช้งานจริง สำเนาเก่าอาจต่างจากโปรแกรมที่ทางลัดหรือบริการเรียกใช้ จดพาธ ไดเรกทอรีทำงาน และอาร์กิวเมนต์ไว้ด้วยกันเพื่อทำซ้ำได้ ใน Windows เปิด PowerShell ที่โฟลเดอร์โปรแกรมปัจจุบัน:

```powershell
.\seine.exe --version
```

ใน Linux หรือ macOS เปิดเทอร์มินัลในโฟลเดอร์นั้น:

```sh
./seine --version
```

เปรียบเทียบกับ[รุ่นทางการ](https://github.com/zpalmtree/seine/releases) seine ตรวจสอบเมื่อเริ่มและทุก 12 ชั่วโมง โดยแจ้งในแดชบอร์ดและบันทึก ข้อความมีลิงก์ดาวน์โหลด ส่วนเวลาติดตั้งคุณเลือกเอง อ่านบันทึกการเปลี่ยนแปลงด้านแพลตฟอร์ม รันไทม์ และตัวเลือกเริ่มต้น

## ต้องเก็บการตั้งค่าใด?

seine อ่าน `./seine-data/seine.config.json` ตามค่าเริ่มต้น `./` หมายถึงไดเรกทอรีทำงาน การย้ายโปรแกรมแล้วเปิดจากที่อื่นอาจเปลี่ยนตำแหน่งค้นหา หากใช้ `--data-dir` ให้ชี้ที่เดิม พาธแบบเต็มระบุตำแหน่งชัดเจนเมื่อทางลัด สคริปต์ หรือบริการเลือกไดเรกทอรีทำงาน

การตั้งค่าเก็บโหมดขุด ที่อยู่รับเงิน URL พูล และชื่อเครื่อง เก็บไดเรกทอรีข้อมูลทั้งหมดรวมไฟล์ปรับแต่ง เก็บคำสั่ง สคริปต์ หรือนิยามบริการด้วย เพราะ `--backend` และ `--threads` แยกจากช่องข้อมูลเชื่อมต่อ การเก็บทั้งสองส่วนรักษารูปแบบที่ต้องการหลังเริ่มใหม่

## ดาวน์โหลดและตรวจสอบไฟล์ใหม่

ใช้[หน้าดาวน์โหลด](/th/#download)หรือรุ่นทางการ เลือกไฟล์ตามระบบและสถาปัตยกรรม CPU ดาวน์โหลด `SHA256SUMS.txt` ที่แยกไว้ของรุ่นเดียวกัน เปรียบเทียบ checksum ก่อนแตกไฟล์ในโฟลเดอร์อื่น [คู่มือตรวจสอบ](/th/blog/antivirus-flags-crypto-miner/)อธิบายขั้นตอน Windows และคำเตือนการดาวน์โหลด

เก็บไฟล์ในแพ็กเกจไว้ด้วยกัน รุ่น Windows มีไลบรารี NVIDIA ข้าง `seine.exe` การคัดลอกเฉพาะโปรแกรมอาจปะปนเวอร์ชัน [คู่มือ NVIDIA](/th/blog/mine-blocknet-nvidia-gpu/)อธิบายรันไทม์ [เอกสาร v0.2.36](https://github.com/zpalmtree/seine/blob/v0.2.36/docs/guides/configuration.md)ระบุการบันทึกค่าและพฤติกรรมเริ่มต้นที่ใช้ในบทความนี้

## หยุด สำรอง และเปลี่ยนไฟล์

ออกด้วย `q` หรือ `Ctrl+C` แล้วรอจนโปรเซสจบ ถ้าเป็นบริการให้ใช้ตัวจัดการและคำนึงถึงการเริ่มอัตโนมัติก่อนเปลี่ยนไฟล์ เมื่อหยุดแล้วสำรองแอปและข้อมูลไว้ในเครื่อง แยกสำเนาจากโฟลเดอร์ที่แตกใหม่เพื่อให้ระบุสองเวอร์ชันได้

วางไฟล์ใหม่ในตำแหน่งติดตั้งพร้อมเก็บข้อมูลเดิม หากแยกโฟลเดอร์ตามเวอร์ชัน ให้เปลี่ยนพาธโปรแกรมในทางลัดหรือบริการและรักษาไดเรกทอรีทำงานกับพาธข้อมูลอย่างชัดเจน เปิดหนึ่งอินสแตนซ์ด้วยตัวเลือกเดิม ถ้ามีหลายเครื่องให้ตรวจสอบหนึ่งเครื่องให้ครบก่อน

## ยืนยันว่าอัปเดตสำเร็จอย่างไร?

ตรวจสอบเวอร์ชันของไฟล์ที่ติดตั้งอีกครั้งเทียบกับที่ดาวน์โหลด เริ่มโปรแกรมแล้วเช็กปลายทางรับเงิน พูล ชื่อเครื่อง และ backend CPU/GPU ที่ต้องการ ข้อมูลปรับแต่งที่เข้ากันได้อาจนำกลับมาใช้ รอการปรับแต่งเริ่มต้นจบก่อนประเมิน hashrate [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/)อธิบายแต่ละส่วน

ดูแชร์ที่ยอมรับแล้วเปิด [My Stats](https://bntpool.com/stats) ของที่อยู่เดียวกัน ค่าประมาณพูลต้องมีแชร์และเวลาเพื่อให้เสถียร ความต่างทันทีของ hashrate ยังไม่พอระบุปัญหาอัปเดต โปรเซสใหม่เริ่มเซสชันในเครื่องใหม่ด้วย เปรียบเทียบที่อยู่ เครื่อง และกิจกรรมก่อนเทียบตัวนับระยะสั้น

## ถ้าคำถามตั้งค่าเริ่มต้นกลับมา?

ตรวจสอบไดเรกทอรีทำงานและ `--data-dir` ก่อน โฟลเดอร์ใหม่มักไม่มีการตั้งค่าในพาธสัมพัทธ์เริ่มต้น หยุดอินสแตนซ์และชี้ข้อมูลเดิม หากข้อผิดพลาดระบุไฟล์ตั้งค่า ให้เก็บไฟล์และข้อความตรงตัวไว้ตรวจสอบ อย่าใส่วลีกู้คืน คีย์ส่วนตัว หรือโทเคน API ควบคุมในภาพหรือรายงานสาธารณะ

ถ้าเริ่มไม่ได้ให้บันทึกเวอร์ชัน ระบบ พาธ และข้อผิดพลาดตรงตัว แล้วใช้คู่มือแพลตฟอร์ม สำเนาเก็บแอปเก่าและการตั้งค่าด้วยกัน ก่อนย้อนกลับให้ตรวจข้อกำหนดความเข้ากันได้ในบันทึกรุ่นใหม่ ใช้การตั้งค่าที่ทราบแล้วตรวจแชร์อีกครั้ง การเปลี่ยนโปรแกรมขุดไม่ต้องสร้างกระเป๋าใหม่
