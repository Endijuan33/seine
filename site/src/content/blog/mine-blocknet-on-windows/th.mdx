คู่มือนี้พาคุณตั้งแต่ดาวน์โหลด ZIP สำหรับ Windows ไปจนถึงมี share ที่ยอมรับบน bntpool.com คุณจะตรวจสอบไฟล์บีบอัด แตกไฟล์ ใส่ที่อยู่รับเงิน และยืนยันว่า CPU กับการ์ด NVIDIA ที่รองรับกำลังขุดอยู่ คำสั่งด้านล่างใช้ PowerShell ที่ทำงานบน Windows โดยตรง

## เริ่มขุด Blocknet บน Windows อย่างไร?

<Answer>
ดาวน์โหลด `seine-windows-x86_64.zip` แตกไฟล์ทั้งชุด แล้วเปิด `seine.exe` ใส่ที่อยู่ Blocknet หรือ `@name` ที่ลงทะเบียนไว้ จากนั้นยอมรับ `stratum+tcp://bntpool.com:3333` เป็นพูล seine เลือกแบ็กเอนด์ CPU และ NVIDIA ที่ใช้ได้ จัดจำนวนเธรดให้เหมาะกับหน่วยความจำ และเริ่มปรับแต่งระหว่างขุด
</Answer>

เตรียมที่อยู่รับเงินสาธารณะให้พร้อมก่อนเปิดโปรแกรมขุด [คู่มือกระเป๋าเงิน](/th/blog/blocknet-wallet-for-mining/) อธิบายวิธีรับที่อยู่ ให้ใส่เฉพาะที่อยู่รับเงินเท่านั้น โปรแกรมขุดไม่ต้องใช้วลีกู้คืนกระเป๋าเงินหรือคีย์สำหรับใช้จ่าย [Blocknet ID](/th/blog/blocknet-id-pay-by-name/) ที่ลงทะเบียนไว้ก็ใช้ได้ คุณจึงใช้ `@name` แทนที่อยู่ยาวได้

แต่ละเธรดขุดของ CPU ใช้บล็อกหน่วยความจำขนาด 2 GiB seine ตรวจสอบ RAM ที่มีและจำนวนคอร์ เผื่อหน่วยความจำไว้ และเลือกจำนวนเธรดเริ่มต้นให้ คุณเริ่มด้วยค่าเริ่มต้นบนเดสก์ท็อปหรือแล็ปท็อปได้โดยไม่ต้องคำนวณจำนวนเธรดหรือเลือกเคอร์เนล CPU ก่อน

## ขั้นตอนที่ 1: ดาวน์โหลดและตรวจสอบไฟล์บีบอัดสำหรับ Windows

เปิด [ส่วนดาวน์โหลด](/th/#download) แล้วเลือก Windows x86_64 ไฟล์บีบอัดมีชื่อว่า `seine-windows-x86_64.zip` ดาวน์โหลด `SHA256SUMS.txt` จาก [รุ่นเผยแพร่](https://github.com/zpalmtree/seine/releases/latest) เดียวกัน หากต้องการตรวจสอบ ZIP ก่อนแตกไฟล์ ไฟล์บีบอัดและไฟล์เช็กซัมต้องมาจากรุ่นเผยแพร่เดียวกัน

![ZIP สำหรับ Windows ในตารางดาวน์โหลดอย่างเป็นทางการของ seine](/assets/blog/windows-download.png)

ใน PowerShell ให้เปลี่ยนไปยังโฟลเดอร์ Downloads แล้วคำนวณค่าแฮช SHA-256 ของไฟล์บีบอัด:

```powershell
cd "$HOME\Downloads"
Get-FileHash .\seine-windows-x86_64.zip -Algorithm SHA256
```

เปรียบเทียบแฮชที่แสดงกับรายการของ ZIP ไฟล์นั้นใน `SHA256SUMS.txt` ตัวอักษรพิมพ์ใหญ่หรือเล็กไม่มีผล แต่เลขฐานสิบหกทุกหลักต้องตรงกัน [เอกสาร Get-FileHash ของ Microsoft](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) อธิบายวิธีตรวจสอบไฟล์ที่เก็บในโฟลเดอร์อื่น เช็กซัมยืนยันว่าไฟล์บีบอัดตรงกับรุ่นที่เผยแพร่ ให้ดาวน์โหลดทั้งสองไฟล์จากหน้ารุ่นเผยแพร่อย่างเป็นทางการ

## ขั้นตอนที่ 2: แตก ZIP ทั้งหมด

ใน File Explorer ให้คลิกขวาที่ ZIP ที่ดาวน์โหลดแล้วเลือก **Extract All (แยกทั้งหมด)** เลือกโฟลเดอร์ที่คุณเขียนไฟล์ได้ แล้วเปิดโฟลเดอร์ที่แตกไฟล์ เก็บ `seine.exe` และ DLL ที่มาด้วยกันไว้ด้วยกัน เพราะไฟล์บีบอัดสำหรับ Windows มีไลบรารีรันไทม์ NVIDIA ที่โปรแกรมขุดใช้งาน

ดับเบิลคลิก `seine.exe` จากโฟลเดอร์ที่แตกไฟล์ หากชอบใช้เทอร์มินัล ให้เปิด PowerShell ในโฟลเดอร์นั้นแล้วรัน:

```powershell
.\seine.exe
```

คำนำหน้า `./` หรือ `.\` บอกให้เชลล์เรียกใช้ไฟล์ปฏิบัติการในไดเรกทอรีปัจจุบัน การเรียกใช้จากโฟลเดอร์ที่แตกไฟล์ยังทำให้ seine มีตำแหน่งคงที่สำหรับบันทึกการตั้งค่า ให้ใช้โฟลเดอร์เดิมในการเปิดครั้งถัดไปเพื่อให้โปรแกรมพบที่อยู่และพูลที่คุณใส่ไว้

## ขั้นตอนที่ 3: ใส่ที่อยู่และพูล

เมื่อโปรแกรมถามครั้งแรก ให้วางที่อยู่รับ Blocknet หรือ `@name` ที่ลงทะเบียนไว้แล้วกดยืนยัน ยอมรับ URL พูลเริ่มต้น `stratum+tcp://bntpool.com:3333` หากมีการถามชื่อเครื่องขุด ให้ตั้งชื่อบนพูลที่จำได้ง่ายเพื่อแยกพีซี Windows เครื่องนี้จากเครื่องอื่นที่ขุดเข้าที่อยู่เดียวกัน

[คู่มือการกำหนดค่า](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md) อธิบายคำถามเหล่านี้และการตั้งค่าที่บันทึกไว้ ตามค่าเริ่มต้นจะอยู่ใน `seine-data/seine.config.json` โดยอ้างอิงจากโฟลเดอร์ที่ใช้เปิดโปรแกรม เมื่อเปิดครั้งถัดไป seine จะนำกลับมาใช้ ส่วนชื่อย่อจะถูกแปลงเป็นที่อยู่อีกครั้งเมื่อเริ่มการทำงานรอบใหม่

คุณระบุชื่อย่อที่ลงทะเบียนไว้ใน PowerShell โดยตรงได้เช่นกัน:

```powershell
.\seine.exe --address '@name' --pool-url stratum+tcp://bntpool.com:3333
```

แทน `@name` ด้วยชื่อย่อที่คุณลงทะเบียนไว้ ไม่ต้องกำหนดแฟล็กจำนวนเธรดและเคอร์เนล CPU เพื่อให้ seine เลือกโดยอัตโนมัติ สำหรับการตั้งค่าทั่วไปในระบบปฏิบัติการต่าง ๆ ดู [วิธีขุด Blocknet](/th/blog/how-to-mine-blocknet/)

## รู้ได้อย่างไรว่าการขุดทำงานแล้ว?

<Answer>
ตรวจสอบว่าแดชบอร์ด seine แสดงอัตราแฮชและ share ที่ยอมรับ จากนั้นค้นหาที่อยู่รับเงินเดียวกันบนหน้า My Stats ของ bntpool.com แดชบอร์ดแสดงงานปัจจุบันของโปรแกรมขุด ส่วนพูลบันทึก share ที่ส่งและรางวัล รอให้การปรับแต่งอัตโนมัติเข้าที่ก่อนเปรียบเทียบอัตราหรือเปลี่ยนการตั้งค่า
</Answer>

[คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายอัตราแฮช สถานะการขุด และแผงข้อมูลพูล อัตราแฮชที่ทำงานอยู่แสดงการคำนวณแฮชในเครื่อง ส่วน share ที่ยอมรับยืนยันว่างานไปถึงพูลแล้ว เปิด [My Stats](https://bntpool.com/stats) แล้วใส่ที่อยู่หรือชื่อย่อเดียวกันเพื่อติดตาม share และยอดคงเหลือของเครื่องขุดนี้

เมื่อทดสอบการตั้งค่าใหม่ ให้แยก share ที่ยอมรับออกจากการจ่ายเงิน share มีส่วนในรางวัลพูล ส่วนการจ่ายเงินเป็นไปตามกฎการยืนยันและยอดคงเหลือของพูล [คู่มือ PPLNS](https://bntpool.com/blog/how-pplns-payouts-work/) อธิบายลำดับดังกล่าว คุณตรวจสอบการเชื่อมต่อได้ทันทีโดยไม่ต้องรอการจ่ายเงินครั้งแรก

## ขุดด้วย CPU และ NVIDIA บนพีซีเครื่องเดียวกัน

ตามค่าเริ่มต้น seine ใช้ CPU และการ์ด NVIDIA ที่รองรับร่วมกัน ให้ติดตั้งไดรเวอร์ NVIDIA รุ่นปัจจุบัน ZIP สำหรับ Windows มีไลบรารีรันไทม์อยู่แล้ว จึงไม่ต้องติดตั้ง CUDA Toolkit แยกต่างหาก เมื่อย้ายโฟลเดอร์โปรแกรมขุด ให้เก็บ DLL ที่แตกไว้ข้างไฟล์ปฏิบัติการ

เมื่อเปิดครั้งแรก seine ปรับแต่ง GPU แต่ละตัวและจดจำการตั้งค่า การปรับแต่ง CPU ก็ทำงานระหว่างขุดเช่นกัน [คู่มือฮาร์ดแวร์](/th/blog/blocknet-mining-hardware-hashrate/) อธิบายการจัดสรรหน่วยความจำและผลที่วัดได้ ส่วน [คู่มือ NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) ครอบคลุมการใช้หลายการ์ด หากต้องการหยุดอย่างถูกต้อง ให้กด `q` ในแดชบอร์ดหรือ `Ctrl+C` ในเทอร์มินัล

## ตัวเลือกเพิ่มเติม: เปิด large pages ของ Windows

การเริ่มโปรแกรมตามปกติจะลองใช้ large pages อยู่แล้วและกลับไปใช้หน้าหน่วยความจำปกติเมื่อจำเป็น หากต้องการเตรียม large pages บน Windows Pro, Enterprise หรือ Education ให้เปิด `secpol.msc` ไปที่ **Local Policies → User Rights Assignment → Lock pages in memory** แล้วเพิ่มบัญชีที่ใช้รัน seine ออกจากระบบแล้วเข้าสู่ระบบอีกครั้งเพื่อให้เซสชันใหม่ได้รับสิทธิ์นี้

[คู่มือ large pages](/th/blog/huge-pages-blocknet-mining/) อธิบายการตั้งค่าเสริมนี้โดยละเอียด หลังเข้าสู่ระบบอีกครั้ง ให้เปิด seine ตามปกติและตรวจสอบบันทึกตอนเริ่มโปรแกรมเพื่อดูโหมดหน้าหน่วยความจำที่เลือก ให้ใช้โหมดอัตโนมัติเริ่มต้นขณะตั้งค่าให้ทำงานได้เป็นครั้งแรก แล้วจึงเปรียบเทียบผลวัดบนพีซีเครื่องเดิมหากเปลี่ยนการตั้งค่าหน้าหน่วยความจำ
