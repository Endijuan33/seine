Это руководство проведёт вас от скачивания ZIP-архива для Windows до принятых шар на bntpool.com. Вы проверите архив, распакуете файлы, укажете адрес выплат и убедитесь, что CPU и поддерживаемые карты NVIDIA майнят. Команды ниже предназначены для PowerShell в самой Windows.

## Как начать майнить Blocknet на Windows?

<Answer>
Скачайте `seine-windows-x86_64.zip`, распакуйте весь архив и откройте `seine.exe`. Введите адрес Blocknet или зарегистрированное имя `@name`, затем оставьте пул `stratum+tcp://bntpool.com:3333`. seine выбирает доступные бэкенды CPU и NVIDIA, подбирает число потоков под объём памяти и начинает настройку во время майнинга.
</Answer>

Подготовьте публичный адрес выплат перед запуском майнера. В [руководстве по кошельку](/ru/blog/blocknet-wallet-for-mining/) объясняется, как его получить. Вводите только адрес получения: майнеру не нужны сид-фраза кошелька или ключи расходования. Зарегистрированный [Blocknet ID](/ru/blog/blocknet-id-pay-by-name/) тоже подходит: вместо длинного адреса можно использовать `@name`.

Каждый поток майнинга CPU использует блок памяти размером 2 GiB. seine проверяет доступную ОЗУ и число ядер, оставляет запас памяти и сам выбирает начальное число потоков. На настольном компьютере или ноутбуке можно начать с настроек по умолчанию: заранее рассчитывать число потоков или выбирать вычислительное ядро CPU не нужно.

## Шаг 1: скачайте и проверьте архив для Windows

Откройте [раздел загрузки](/ru/#download) и выберите Windows x86_64. Архив называется `seine-windows-x86_64.zip`. Скачайте `SHA256SUMS.txt` из того же [релиза](https://github.com/zpalmtree/seine/releases/latest), если хотите проверить ZIP перед распаковкой. Архив и файл контрольных сумм должны относиться к одной версии релиза.

![ZIP-архив для Windows в официальной таблице загрузок seine](/assets/blog/windows-download.png)

В PowerShell перейдите в папку загрузок и вычислите хеш SHA-256 архива:

```powershell
cd "$HOME\Downloads"
Get-FileHash .\seine-windows-x86_64.zip -Algorithm SHA256
```

Сравните показанный хеш со строкой именно этого ZIP в `SHA256SUMS.txt`. Регистр букв не важен; все шестнадцатеричные цифры должны совпасть. [Документация Microsoft по Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) поможет проверить файл в другой папке. Контрольная сумма подтверждает соответствие архива опубликованному релизу; скачивайте оба файла с официальной страницы релиза.

## Шаг 2: полностью распакуйте ZIP

В Проводнике нажмите правой кнопкой на скачанный ZIP и выберите **Извлечь все**. Укажите папку с правом записи, затем откройте распакованную папку. Храните `seine.exe` вместе с прилагаемыми DLL: архив для Windows содержит библиотеки среды выполнения NVIDIA, которые использует майнер.

Дважды нажмите `seine.exe` в распакованной папке. Если предпочитаете терминал, откройте PowerShell в этой папке и выполните:

```powershell
.\seine.exe
```

Префикс `./` или `.\` указывает оболочке запустить исполняемый файл из текущей папки. Запуск из распакованной папки также даёт seine постоянное место для сохранения настроек. При последующих запусках используйте ту же папку, чтобы программа нашла введённые адрес и пул.

## Шаг 3: укажите адрес и пул

При первом запросе вставьте адрес получения Blocknet или зарегистрированное имя `@name` и подтвердите его. Оставьте URL пула по умолчанию: `stratum+tcp://bntpool.com:3333`. Если программа предложит, задайте узнаваемое имя рига в пуле, чтобы отличать этот ПК с Windows от другого компьютера, майнящего на тот же адрес.

В [руководстве по настройке](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md) описаны эти запросы и сохранённые настройки. По умолчанию они находятся в `seine-data/seine.config.json` относительно папки запуска. При следующих запусках seine использует их повторно. Короткие имена разрешаются заново при каждом новом запуске.

Зарегистрированное короткое имя можно указать и напрямую в PowerShell:

```powershell
.\seine.exe --address '@name' --pool-url stratum+tcp://bntpool.com:3333
```

Замените `@name` своим зарегистрированным коротким именем. Не задавайте флаги числа потоков и вычислительного ядра CPU, чтобы seine выбрал их автоматически. Общие инструкции для разных операционных систем приведены в статье [как майнить Blocknet](/ru/blog/how-to-mine-blocknet/).

## Как убедиться, что майнинг работает?

<Answer>
Проверьте, что панель seine показывает хешрейт и принятые шары, затем найдите тот же адрес выплат на странице My Stats сайта bntpool.com. Панель показывает текущую работу майнера, а пул учитывает отправленные шары и награды. Дождитесь завершения автоматической настройки, прежде чем сравнивать показатели или менять параметры.
</Answer>

В [руководстве по панели](/ru/blog/seine-dashboard-explained/) объясняются хешрейт, состояние майнинга и блоки информации о пуле. Текущий хешрейт показывает локальное вычисление хешей, а принятая шара подтверждает, что работа дошла до пула. Откройте [My Stats](https://bntpool.com/stats) и введите тот же адрес или короткое имя, чтобы следить за шарами и балансом этого рига.

При проверке новой установки различайте принятые шары и выплаты. Шары участвуют в распределении наград пула; выплата следует правилам подтверждения и баланса пула. В [руководстве по PPLNS](https://bntpool.com/blog/how-pplns-payouts-work/) описана эта последовательность. Проверить соединение можно сразу, не дожидаясь первой выплаты.

## Майнинг на CPU и NVIDIA на одном ПК

По умолчанию seine использует CPU и поддерживаемые карты NVIDIA вместе. Установите актуальный драйвер NVIDIA; ZIP-архив для Windows уже содержит библиотеки среды выполнения, поэтому отдельно устанавливать CUDA Toolkit не нужно. При переносе папки майнера оставляйте распакованные DLL рядом с исполняемым файлом.

При первом запуске seine настраивает каждую GPU и запоминает параметры. Настройка CPU также идёт во время майнинга. В [руководстве по оборудованию](/ru/blog/blocknet-mining-hardware-hashrate/) описаны подбор памяти и измеренные результаты, а в [руководстве по NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) — работа с несколькими картами. Для корректной остановки нажмите `q` в панели или `Ctrl+C` в терминале.

## По желанию: включите большие страницы Windows

При обычном запуске программа уже пробует большие страницы и при необходимости переходит на обычные. Чтобы подготовить большие страницы в Windows Pro, Enterprise или Education, откройте `secpol.msc`, перейдите в **Локальные политики → Назначение прав пользователя → Блокировка страниц в памяти** и добавьте учётную запись, под которой работает seine. Выйдите из системы и войдите снова, чтобы новый сеанс получил это право.

В [руководстве по большим страницам](/ru/blog/huge-pages-blocknet-mining/) эта необязательная настройка описана подробно. После повторного входа запустите seine как обычно и проверьте выбранный режим страниц в журнале запуска. Оставьте автоматический режим по умолчанию, пока налаживаете первый рабочий запуск, а при изменении настроек страниц сравнивайте измерения на том же ПК.
