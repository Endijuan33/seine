Ce guide vous accompagne du téléchargement du ZIP Windows jusqu’aux shares acceptés sur bntpool.com. Vous extrairez les fichiers, saisirez votre adresse de paiement et confirmerez que votre CPU et vos éventuelles cartes NVIDIA compatibles minent. Les commandes ci-dessous utilisent PowerShell et Windows en natif.

## Comment commencer à miner Blocknet sous Windows ?

<Answer>
Téléchargez `seine-windows-x86_64.zip`, extrayez toute l’archive et ouvrez `seine.exe`. Saisissez votre adresse Blocknet ou votre `@name` enregistré, puis acceptez `stratum+tcp://bntpool.com:3333` comme pool. seine sélectionne les moteurs CPU et NVIDIA disponibles, adapte le nombre de threads à la mémoire et commence ses réglages pendant le minage.
</Answer>

Préparez votre adresse publique de paiement avant d’ouvrir le mineur. Le [guide du portefeuille](/fr/blog/blocknet-wallet-for-mining/) explique comment en obtenir une. Saisissez uniquement l’adresse de réception : le mineur n’a besoin ni de la phrase de récupération ni des clés de dépense de votre portefeuille. Un [Blocknet ID](/fr/blog/blocknet-id-pay-by-name/) enregistré fonctionne aussi : vous pouvez donc utiliser `@name` à la place de la longue adresse.

Chaque thread de minage CPU utilise un bloc de mémoire de 2 GiB. seine vérifie la RAM disponible et le nombre de cœurs, conserve une réserve de mémoire et choisit pour vous le nombre initial de threads. Sur un ordinateur fixe ou portable, vous pouvez commencer avec les paramètres par défaut ; inutile de calculer un nombre de threads ou de choisir d’abord un kernel CPU.

## Étape 1 : télécharger l’archive Windows

Ouvrez la [section de téléchargement](/fr/#download) et choisissez Windows x86_64. L’archive s’appelle `seine-windows-x86_64.zip`.

![ZIP Windows dans le tableau officiel des téléchargements de seine](/assets/blog/windows-download.png)

## Étape 2 : extraire le ZIP complet

Dans l’Explorateur de fichiers, faites un clic droit sur le ZIP téléchargé et choisissez **Extraire tout**. Sélectionnez un dossier dans lequel vous pouvez écrire, puis ouvrez le dossier extrait. Gardez `seine.exe` et les DLL qui l’accompagnent ensemble : l’archive Windows contient les bibliothèques d’exécution NVIDIA utilisées par le mineur.

Double-cliquez sur `seine.exe` depuis le dossier extrait. Si vous préférez un terminal, ouvrez PowerShell dans ce dossier et exécutez :

```powershell
.\seine.exe
```

Le préfixe `./` ou `.\` indique au shell d’exécuter le programme présent dans le répertoire courant. Le lancement depuis un dossier extrait donne aussi à seine un emplacement stable pour enregistrer ses paramètres. Utilisez ce même dossier aux prochains lancements afin qu’il retrouve l’adresse et le pool que vous avez saisis.

## Étape 3 : saisir votre adresse et votre pool

À la première invite, collez votre adresse de réception Blocknet ou votre `@name` enregistré et confirmez. Acceptez l’URL du pool par défaut, `stratum+tcp://bntpool.com:3333`. Si cela vous est demandé, donnez à la machine un nom reconnaissable dans le pool afin de distinguer ce PC Windows d’un autre ordinateur minant vers la même adresse.

Le [guide de configuration](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md) décrit ces invites et les paramètres enregistrés. Par défaut, ceux-ci se trouvent dans `seine-data/seine.config.json`, relativement au dossier de lancement. Aux démarrages suivants, seine les réutilise. Les noms courts sont de nouveau résolus au début de chaque exécution.

Vous pouvez aussi fournir directement un nom court enregistré dans PowerShell :

```powershell
.\seine.exe --address '@name' --pool-url stratum+tcp://bntpool.com:3333
```

Remplacez `@name` par votre propre nom court enregistré. Si vous ne définissez pas les options de threads et de kernel CPU, seine les choisit automatiquement. Pour la configuration générale sur les différents systèmes d’exploitation, consultez [comment miner Blocknet](/fr/blog/how-to-mine-blocknet/).

## Comment savoir si le minage fonctionne ?

<Answer>
Vérifiez que le tableau de bord de seine affiche un taux de hachage et des shares acceptés, puis recherchez la même adresse de paiement sur la page My Stats de bntpool.com. Le tableau de bord décrit le travail actuel du mineur ; le pool enregistre les shares soumis et les récompenses. Laissez le réglage automatique se stabiliser avant de comparer les taux ou de modifier les paramètres.
</Answer>

Le [guide du tableau de bord](/fr/blog/seine-dashboard-explained/) explique le taux de hachage, l’état du minage et les panneaux du pool. Un taux de hachage actif indique une activité locale de calcul ; un share accepté confirme que le travail est arrivé au pool. Ouvrez [My Stats](https://bntpool.com/stats) et saisissez la même adresse ou le même nom court pour suivre les shares et le solde de cette machine.

Distinguez les shares acceptés des paiements lorsque vous vérifiez une nouvelle configuration. Les shares contribuent aux récompenses du pool ; un paiement suit les règles de confirmation et de solde du pool. Le [guide PPLNS](https://bntpool.com/blog/how-pplns-payouts-work/) explique cette séquence. Vous pouvez vérifier immédiatement la connexion sans attendre le premier paiement.

## Miner avec le CPU et NVIDIA sur le même PC

seine utilise par défaut le CPU et les cartes NVIDIA compatibles ensemble. Installez un pilote NVIDIA récent ; le ZIP Windows contient déjà les bibliothèques d’exécution, vous n’avez donc pas besoin d’installer séparément le CUDA Toolkit. Laissez les DLL extraites à côté de l’exécutable lorsque vous déplacez le dossier du mineur.

Au premier lancement, seine règle chaque GPU et mémorise ses paramètres. Le réglage du CPU s’effectue aussi pendant le minage. Le [guide du matériel](/fr/blog/blocknet-mining-hardware-hashrate/) explique le dimensionnement de la mémoire et les résultats mesurés, tandis que le [guide NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) traite de l’utilisation de plusieurs cartes. Pour arrêter proprement, appuyez sur `q` dans le tableau de bord ou sur `Ctrl+C` dans le terminal.

## Facultatif : activer les grandes pages de Windows

Au démarrage normal, le programme essaie déjà d’utiliser les grandes pages et se rabat sur les pages normales. Pour préparer les grandes pages sous Windows Pro, Enterprise ou Education, ouvrez `secpol.msc`, allez dans **Stratégies locales → Attribution des droits utilisateur → Verrouiller des pages en mémoire** et ajoutez le compte qui exécute seine. Fermez puis rouvrez votre session pour que la nouvelle session reçoive ce droit.

Le [guide des grandes pages](/fr/blog/huge-pages-blocknet-mining/) détaille cette configuration facultative. Après vous être reconnecté, lancez seine normalement et consultez son journal de démarrage pour connaître le mode de pages sélectionné. Conservez le mode automatique par défaut pendant la mise en place de votre première configuration fonctionnelle, puis comparez les mesures sur le même PC si vous changez les paramètres de pages.
