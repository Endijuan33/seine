Цей посібник проведе вас від завантаження ZIP-архіву для Windows до прийнятих шар на bntpool.com. Ви перевірите архів, розпакуєте файли, вкажете адресу виплат і переконаєтеся, що CPU та підтримувані карти NVIDIA майнять. Команди нижче призначені для PowerShell безпосередньо у Windows.

## Як почати майнити Blocknet на Windows?

<Answer>
Завантажте `seine-windows-x86_64.zip`, розпакуйте весь архів і відкрийте `seine.exe`. Введіть адресу Blocknet або зареєстроване ім’я `@name`, потім залиште пул `stratum+tcp://bntpool.com:3333`. seine вибирає доступні бекенди CPU й NVIDIA, добирає кількість потоків відповідно до пам’яті та починає налаштування під час майнінгу.
</Answer>

Підготуйте публічну адресу виплат перед відкриттям майнера. [Посібник із гаманця](/uk/blog/blocknet-wallet-for-mining/) пояснює, як її отримати. Вводьте лише адресу отримання: майнеру не потрібні сід-фраза гаманця чи ключі витрачання. Зареєстрований [Blocknet ID](/uk/blog/blocknet-id-pay-by-name/) також підходить: замість довгої адреси можна використовувати `@name`.

Кожен потік майнінгу CPU використовує блок пам’яті розміром 2 GiB. seine перевіряє доступну оперативну пам’ять і кількість ядер, залишає запас пам’яті та сам вибирає початкову кількість потоків. На настільному комп’ютері чи ноутбуці можна почати з типових налаштувань: заздалегідь обчислювати кількість потоків або вибирати обчислювальне ядро CPU не потрібно.

## Крок 1: завантажте й перевірте архів для Windows

Відкрийте [розділ завантаження](/uk/#download) і виберіть Windows x86_64. Архів має назву `seine-windows-x86_64.zip`. Завантажте `SHA256SUMS.txt` із того самого [релізу](https://github.com/zpalmtree/seine/releases/latest), якщо хочете перевірити ZIP перед розпакуванням. Архів і файл контрольних сум мають бути з однієї версії релізу.

![ZIP-архів для Windows в офіційній таблиці завантажень seine](/assets/blog/windows-download.png)

У PowerShell перейдіть до папки завантажень і обчисліть хеш SHA-256 архіву:

```powershell
cd "$HOME\Downloads"
Get-FileHash .\seine-windows-x86_64.zip -Algorithm SHA256
```

Порівняйте показаний хеш із записом саме цього ZIP у `SHA256SUMS.txt`. Регістр літер не має значення; усі шістнадцяткові цифри мають збігатися. [Документація Microsoft щодо Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) допоможе перевірити файл в іншій папці. Контрольна сума засвідчує відповідність архіву опублікованому релізу; завантажуйте обидва файли з офіційної сторінки релізу.

## Крок 2: повністю розпакуйте ZIP

У Провіднику клацніть завантажений ZIP правою кнопкою та виберіть **Видобути все**. Виберіть папку, до якої маєте право запису, і відкрийте розпаковану папку. Зберігайте `seine.exe` разом із супровідними DLL: архів для Windows містить бібліотеки середовища виконання NVIDIA, які використовує майнер.

Двічі клацніть `seine.exe` у розпакованій папці. Якщо віддаєте перевагу терміналу, відкрийте PowerShell у цій папці й виконайте:

```powershell
.\seine.exe
```

Префікс `./` або `.\` вказує оболонці запустити виконуваний файл із поточної папки. Запуск із розпакованої папки також дає seine постійне місце для збереження налаштувань. Під час наступних запусків використовуйте ту саму папку, щоб програма знайшла введені адресу та пул.

## Крок 3: вкажіть адресу й пул

На першому запиті вставте адресу отримання Blocknet або зареєстроване ім’я `@name` і підтвердьте його. Залиште типовий URL пулу — `stratum+tcp://bntpool.com:3333`. Якщо буде запропоновано, задайте впізнаване ім’я рига в пулі, щоб відрізняти цей ПК із Windows від іншого комп’ютера, який майнить на ту саму адресу.

[Посібник із налаштування](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md) описує ці запити та збережені параметри. За замовчуванням вони розташовані в `seine-data/seine.config.json` відносно папки запуску. Під час наступних запусків seine використовує їх повторно. Короткі імена визначаються заново на початку кожного запуску.

Зареєстроване коротке ім’я можна також указати безпосередньо в PowerShell:

```powershell
.\seine.exe --address '@name' --pool-url stratum+tcp://bntpool.com:3333
```

Замініть `@name` своїм зареєстрованим коротким ім’ям. Не задавайте прапорці потоків і обчислювального ядра CPU, щоб seine вибрав їх автоматично. Загальні інструкції для різних операційних систем наведено в статті [як майнити Blocknet](/uk/blog/how-to-mine-blocknet/).

## Як переконатися, що майнінг працює?

<Answer>
Перевірте, що панель seine показує хешрейт і прийняті шари, потім знайдіть ту саму адресу виплат на сторінці My Stats сайту bntpool.com. Панель показує поточну роботу майнера, а пул обліковує надіслані шари та винагороди. Дочекайтеся завершення автоматичного налаштування, перш ніж порівнювати показники чи змінювати параметри.
</Answer>

[Посібник із панелі](/uk/blog/seine-dashboard-explained/) пояснює хешрейт, стан майнінгу та панелі пулу. Поточний хешрейт показує локальне обчислення хешів, а прийнята шара підтверджує, що робота дійшла до пулу. Відкрийте [My Stats](https://bntpool.com/stats) і введіть ту саму адресу чи коротке ім’я, щоб стежити за шарами й балансом цього рига.

Перевіряючи нове налаштування, розрізняйте прийняті шари та виплати. Шари беруть участь у розподілі винагород пулу; виплата залежить від правил підтвердження та балансу пулу. [Посібник із PPLNS](https://bntpool.com/blog/how-pplns-payouts-work/) пояснює цю послідовність. Перевірити з’єднання можна одразу, не чекаючи першої виплати.

## Майнінг на CPU й NVIDIA на одному ПК

За замовчуванням seine використовує CPU й підтримувані карти NVIDIA разом. Установіть актуальний драйвер NVIDIA; ZIP-архів для Windows уже містить бібліотеки середовища виконання, тому окремо встановлювати CUDA Toolkit не потрібно. Переміщуючи папку майнера, залишайте розпаковані DLL поруч із виконуваним файлом.

Під час першого запуску seine налаштовує кожну GPU та запам’ятовує параметри. Налаштування CPU також відбувається під час майнінгу. [Посібник з обладнання](/uk/blog/blocknet-mining-hardware-hashrate/) пояснює добір пам’яті й виміряні результати, а [посібник із NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) — роботу з кількома картами. Для коректної зупинки натисніть `q` на панелі або `Ctrl+C` у терміналі.

## За бажанням: увімкніть великі сторінки Windows

Звичайний запуск уже намагається використовувати великі сторінки й за потреби переходить на звичайні. Щоб підготувати великі сторінки у Windows Pro, Enterprise або Education, відкрийте `secpol.msc`, перейдіть до **Локальні політики → Призначення прав користувача → Блокування сторінок у пам’яті** та додайте обліковий запис, під яким працює seine. Вийдіть із системи й увійдіть знову, щоб новий сеанс отримав це право.

[Посібник із великих сторінок](/uk/blog/huge-pages-blocknet-mining/) докладно описує це необов’язкове налаштування. Після повторного входу запустіть seine як зазвичай і перевірте вибраний режим сторінок у журналі запуску. Залиште типовий автоматичний режим, поки налагоджуєте перший робочий запуск, а після зміни параметрів сторінок порівнюйте вимірювання на тому самому ПК.
