このガイドでは、Windows版ZIPのダウンロードから、bntpool.comでシェアが承認されるまでを説明します。アーカイブを確認してファイルを展開し、受取アドレスを入力して、CPUと対応NVIDIAカードがマイニングしていることを確かめます。以下のコマンドはWindows上で直接動かすPowerShell用です。

## WindowsでBlocknetのマイニングを始めるには？

<Answer>
`seine-windows-x86_64.zip`をダウンロードし、アーカイブ全体を展開して`seine.exe`を開きます。Blocknetアドレスまたは登録済みの`@name`を入力し、プールには`stratum+tcp://bntpool.com:3333`をそのまま使います。seineは利用可能なCPUとNVIDIAのバックエンドを選び、メモリに合わせてスレッド数を決め、マイニングしながら調整を始めます。
</Answer>

マイナーを開く前に公開の受取アドレスを用意してください。取得方法は[ウォレットガイド](/ja/blog/blocknet-wallet-for-mining/)で説明しています。入力するのは受取アドレスだけです。マイナーにウォレットのシードフレーズや支出鍵は必要ありません。登録済みの[Blocknet ID](/ja/blog/blocknet-id-pay-by-name/)も使えるため、長いアドレスの代わりに`@name`を指定できます。

CPUマイニングの各スレッドは2 GiBのメモリブロックを使います。seineは利用可能なRAMとコア数を確認し、メモリに余裕を残して初期スレッド数を選びます。デスクトップでもノートPCでもデフォルト設定で始められます。最初にスレッド数を計算したり、CPUカーネルを選んだりする必要はありません。

## ステップ1：Windows版アーカイブをダウンロードして確認する

[ダウンロードセクション](/ja/#download)を開き、Windows x86_64を選びます。アーカイブ名は`seine-windows-x86_64.zip`です。展開前にZIPを検証する場合は、同じ[リリース](https://github.com/zpalmtree/seine/releases/latest)から`SHA256SUMS.txt`をダウンロードしてください。アーカイブとチェックサムファイルは同じリリースバージョンのものを使います。

![seine公式ダウンロード一覧のWindows版ZIP](/assets/blog/windows-download.png)

PowerShellでDownloadsフォルダーに移動し、アーカイブのSHA-256ハッシュを計算します。

```powershell
cd "$HOME\Downloads"
Get-FileHash .\seine-windows-x86_64.zip -Algorithm SHA256
```

表示されたハッシュを、`SHA256SUMS.txt`にある該当ZIPの項目と比較します。英字の大小は問いませんが、16進数のすべての桁が一致する必要があります。別のフォルダーに保存したファイルを確認する方法は、[MicrosoftのGet-FileHashドキュメント](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash)を参照してください。チェックサムはアーカイブが公開リリースと一致することを確認するものです。両方のファイルを公式リリースページからダウンロードしてください。

## ステップ2：ZIP全体を展開する

エクスプローラーでダウンロードしたZIPを右クリックし、**すべて展開**を選びます。書き込み可能なフォルダーを指定し、展開先フォルダーを開きます。`seine.exe`と付属のDLLは一緒に保存してください。Windows版アーカイブにはマイナーが使うNVIDIAランタイムライブラリが含まれています。

展開先フォルダー内の`seine.exe`をダブルクリックします。ターミナルを使う場合は、そのフォルダーでPowerShellを開いて次を実行します。

```powershell
.\seine.exe
```

`./`または`.\`という接頭辞は、現在のディレクトリにある実行ファイルを起動するようシェルに伝えます。展開先フォルダーから実行すれば、seineの設定の保存先も一定になります。次回以降も同じフォルダーを使うことで、入力済みのアドレスとプールを読み込めます。

## ステップ3：アドレスとプールを入力する

最初の入力欄にBlocknetの受取アドレスまたは登録済みの`@name`を貼り付けて確定します。デフォルトのプールURLである`stratum+tcp://bntpool.com:3333`をそのまま使います。リグ名を求められた場合は、同じアドレスにマイニングする別のマシンと区別できるよう、このWindows PCに分かりやすいプール上の名前を付けてください。

[設定ガイド](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md)に、これらの入力と保存される設定の説明があります。デフォルトの保存先は、起動したフォルダーを基準とする`seine-data/seine.config.json`です。次回以降の起動時にはseineが再利用します。短縮名は、新しく起動するたびに再解決されます。

登録済みの短縮名をPowerShellで直接指定することもできます。

```powershell
.\seine.exe --address '@name' --pool-url stratum+tcp://bntpool.com:3333
```

`@name`を自分の登録済み短縮名に置き換えてください。CPUのスレッド数とカーネルのフラグを指定しなければ、seineが自動で選びます。各OSに共通する設定は、[Blocknetのマイニング方法](/ja/blog/how-to-mine-blocknet/)を参照してください。

## マイニングが動作しているか確認するには？

<Answer>
seineのダッシュボードにハッシュレートと承認されたシェアが表示されていることを確認し、bntpool.comのMy Statsページで同じ受取アドレスを検索します。ダッシュボードはマイナーの現在の作業を示し、プールは送信されたシェアと報酬を記録します。速度の比較や設定の変更は、自動調整が落ち着くまで待ってください。
</Answer>

[ダッシュボードガイド](/ja/blog/seine-dashboard-explained/)では、ハッシュレート、マイニング状態、プールのパネルを説明しています。稼働中のハッシュレートはローカルでのハッシュ計算を示し、承認されたシェアは作業がプールに届いたことを確認するものです。[My Stats](https://bntpool.com/stats)を開いて同じアドレスまたは短縮名を入力すると、このリグのシェアと残高を追跡できます。

新しい設定を確認するときは、承認されたシェアと支払いを区別してください。シェアはプール報酬に寄与し、支払いはプールの承認と残高のルールに従います。この流れは[PPLNSガイド](https://bntpool.com/blog/how-pplns-payouts-work/)で説明しています。最初の支払いを待たずに、接続をすぐ確認できます。

## 同じPCでCPUとNVIDIAを使ってマイニングする

seineはデフォルトでCPUと対応NVIDIAカードを同時に使います。新しいNVIDIAドライバーをインストールしてください。Windows版ZIPにはランタイムライブラリが含まれているので、CUDA Toolkitを別途インストールする必要はありません。マイナーのフォルダーを移動するときも、展開したDLLは実行ファイルと同じ場所に置いてください。

初回起動時に、seineは各GPUを調整して設定を記憶します。CPUの調整もマイニング中に行われます。[ハードウェアガイド](/ja/blog/blocknet-mining-hardware-hashrate/)ではメモリの割り当てと測定結果を、[NVIDIAガイド](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)では複数カードの使用を説明しています。正常に停止するには、ダッシュボードで`q`を押すか、ターミナルで`Ctrl+C`を押します。

## 任意：Windowsのラージページを有効にする

通常の起動でもラージページを試し、使えない場合は通常のページに切り替えます。Windows Pro、Enterprise、Educationでラージページを準備するには、`secpol.msc`を開き、**ローカル ポリシー → ユーザー権利の割り当て → メモリ内のページのロック**に進んで、seineを実行するアカウントを追加します。新しいログオンセッションに権限を反映するため、サインアウトしてサインインし直してください。

[ラージページガイド](/ja/blog/huge-pages-blocknet-mining/)では、この任意の設定を詳しく説明しています。再サインイン後は通常どおりseineを起動し、起動ログで選択されたページモードを確認します。最初の動作する設定を整える間はデフォルトの自動モードを維持し、ページ設定を変える場合は同じPCで測定結果を比較してください。
