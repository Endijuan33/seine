本指南介绍如何在 Linux 桌面或服务器上运行 seine，从选择压缩包一直到确认矿池接受份额。文中使用已验证的官方 v0.2.26 版本作为示例。请准备好 Blocknet 收款地址；[钱包指南](/zh-hans/blog/blocknet-wallet-for-mining/)说明了如何找到它。输入的是公开地址或已注册的 `@name`，绝不能输入钱包恢复助记词。

## 如何开始在 Linux 上挖掘 Blocknet？

<Answer>
选择与处理器匹配的 Linux 压缩包，验证其 SHA-256 校验和，然后解压到可写文件夹。运行 `./seine`，输入收款地址，并接受默认的 bntpool.com 连接。seine 会自动设置 CPU 线程数；在 Linux x86_64 上安装相应运行时库后，也能使用受支持的 NVIDIA 显卡。
</Answer>

## 第 1 步：检查架构与 glibc

打开终端，运行下面两条只读检查命令。第一条识别机器架构；第二条在基于 glibc 的系统上输出 GNU C 库版本。它们不会启动挖矿，也不会更改计算机配置。

```sh
uname -m
getconf GNU_LIBC_VERSION
```

根据架构选择下表中的压缩包。v0.2.26 的两个 Linux 软件包都要求 glibc 2.39 或更高版本。安装后续版本时，请重新检查该版本的要求。如果系统使用其他 C 库或更早的 glibc，请使用兼容的发行版环境，或按照[源码构建说明](https://github.com/zpalmtree/seine/blob/master/docs/BUILDING.md)操作。

| 命令输出 | 版本压缩包 | 后端 |
|---|---|---|
| `x86_64` | `seine-linux-x86_64.tar.gz` | CPU 和 NVIDIA |
| `aarch64` | `seine-linux-aarch64.tar.gz` | CPU |

每个 CPU 挖矿线程需要一个 2 GiB 的内存块。seine 根据可用内存和 CPU 资源选择初始线程数，然后在挖矿过程中进行调整。首次运行时，请不要手动覆盖线程和计算内核设置；先建立正常连接，再更改性能参数。

## 第 2 步：下载并验证压缩包

在[下载区](/zh-hans/#download)选择 Linux 或 Linux ARM64。同时从同一[官方版本](https://github.com/zpalmtree/seine/releases/latest)下载作为版本附件发布的 `SHA256SUMS.txt` 文件。将同一版本的压缩包与校验和文件放在一起。下方示例使用 x86_64；在 ARM64 上，请将命令中的 `seine-linux-x86_64.tar.gz` 替换为 `seine-linux-aarch64.tar.gz`。

<img src="/assets/blog/linux-download.png" alt="列出 Linux 与 Linux ARM64 压缩包的官方下载表" width="1200" height="900" loading="lazy" />

在终端进入浏览器保存文件的目录，然后计算压缩包的校验和。此示例假定文件位于主目录下的 Downloads 文件夹；如果你的下载目录使用其他名称，请改用实际目录。

```sh
cd "$HOME/Downloads"
sha256sum seine-linux-x86_64.tar.gz
```

将完整的十六进制哈希与已下载的 `SHA256SUMS.txt` 中该压缩包对应的行进行比较。解压或运行之前，每一位都必须一致。此次比较应使用版本页面单独提供的校验和文件：压缩包内部还包含用于解压后文件的清单。校验和一致表示文件符合已发布的值；两个文件都应从官方来源下载。

## 第 3 步：解压并检查可执行文件

在主目录下创建专用文件夹，将压缩包解压进去，然后让二进制程序输出帮助信息。v0.2.26 压缩包的根目录包含 `./seine`，因此下列命令会将可执行文件直接放入新文件夹。帮助命令会直接退出，不启动挖矿会话。

```sh
mkdir -p "$HOME/seine"
tar -xzf seine-linux-x86_64.tar.gz -C "$HOME/seine"
cd "$HOME/seine"
chmod u+x ./seine
./seine --help
```

请使用自己的账户执行这些步骤。`chmod u+x` 为文件所有者添加执行权限，不需要进行系统级安装。`./` 前缀告诉 shell 运行当前目录中的文件。请将解压得到的文档和许可证文件与二进制程序保存在一起。

## 第 4 步：输入地址并连接

从解压后的文件夹启动：

```sh
./seine
```

输入收款地址或已注册的 `@name`，接受 `stratum+tcp://bntpool.com:3333`，并在提示时选择易于识别的矿机名称。后续启动时，seine 会重用相对于工作目录的 `seine-data/seine.config.json`。始终从同一文件夹启动，可以更方便地找到这些设置。[配置参考](https://github.com/zpalmtree/seine/blob/v0.2.26/docs/guides/configuration.md)说明了交互提示和数据目录。

观察矿工程序的算力和已接受份额计数。然后打开 [My Stats](https://bntpool.com/stats)，查询同一个收款地址。份额被接受说明矿池收到了计算工作；付款则遵循独立的奖励与支付流程。[仪表盘指南](/zh-hans/blog/seine-dashboard-explained/)解释了矿工程序的各个面板。按 `q` 或 `Ctrl+C` 可以正常停止。

## 在 Linux 上使用 NVIDIA 挖矿需要什么？

Linux x86_64 上的 GPU 挖矿需要 NVIDIA 驱动以及兼容的 NVRTC 运行时库。NVRTC 会在启动时编译 GPU 计算内核。按照 [NVIDIA 设置指南](/zh-hans/blog/mine-blocknet-nvidia-gpu/)，通过发行版或 NVIDIA 软件包安装运行时及匹配的 builtins 库。软件包名称取决于发行版和 CUDA 版本，因此请使用适合自己系统的说明。

这些库就绪后，默认模式可以同时使用 CPU 和受支持的 NVIDIA 显卡挖矿。若想在准备 GPU 运行时的同时先建立 CPU 挖矿连接，请明确选择 CPU：

```sh
./seine --backend cpu
```

这表示本次启动仅使用 CPU。关于 GPU 设备选择与 GPU 份额接受情况，请继续阅读 NVIDIA 指南。这里介绍的 ARM64 版本包含 CPU 后端；安装 CUDA 不会为该压缩包增加 NVIDIA 后端。

## 如何解决 Linux 启动错误？

根据第一条错误消息选择下一步检查。架构或运行时错误发生在份额被接受之前，因此更改矿池地址或线程数无法解决这一阶段的问题。检查可执行文件和环境期间，请保留已验证的压缩包。

| 消息或现象 | 检查内容 |
|---|---|
| `Exec format error` | 架构不匹配：将 `uname -m` 与压缩包文件名进行比较。 |
| `GLIBC_2.39 not found` | 二进制程序需要更新的 glibc。请使用兼容系统或从源码构建；系统 C 库应继续由发行版管理。 |
| `Permission denied` | 检查用户执行权限，并使用允许执行程序的文件系统上的文件夹。 |
| `libnvrtc` / `libnvrtc-builtins` | 安装兼容的 NVIDIA 运行时与匹配的 builtins 库，或在准备期间使用 `--backend cpu`。 |

份额开始被接受后，可以参阅[大页内存指南](/zh-hans/blog/huge-pages-blocknet-mining/)进行可选的 Linux 内存页设置。[服务器指南](/zh-hans/blog/mine-blocknet-on-servers/)介绍无头运行与 NUMA 分配。这两项准备都不是完成本首次运行教程的必要条件；请分别进行每项更改，以便判断机器上具体发生了什么变化。
