## Bagaimana memulai penambangan Blocknet di Linux?

<Answer>
Unduh seine, ekstrak, masukkan alamat Blocknet Anda, lalu pastikan share diterima di bntpool.com. Mulai dengan pengaturan otomatis; tips performa tersedia setelah langkah penyiapan.
</Answer>

## Langkah 1: unduh versi yang tepat

Buka [bagian unduhan](/id/#download). Jalankan `uname -m`: pilih `seine-linux-x86_64.tar.gz` untuk `x86_64` atau `seine-linux-aarch64.tar.gz` untuk `aarch64`. Versi Linux memerlukan glibc 2.39 atau lebih baru. Versi x86_64 mendukung CPU dan NVIDIA; ARM64 mendukung penambangan CPU.

<img src="/assets/blog/setup-download.webp" alt="Tabel unduhan resmi dengan arsip Linux dan Linux ARM64" loading="lazy" />

## Langkah 2: ekstrak dan jalankan

Buka Terminal. Perintah ini menganggap arsip berada di folder Downloads; gunakan lokasi sebenarnya jika berbeda. Pada ARM64, ganti `seine-linux-x86_64.tar.gz` dengan `seine-linux-aarch64.tar.gz`. Perintah tersebut mengekstrak seine ke folder pribadi dan menjalankannya:

```sh
mkdir -p "$HOME/seine"
tar -xzf "$HOME/Downloads/seine-linux-x86_64.tar.gz" -C "$HOME/seine"
cd "$HOME/seine"
./seine
```

## Langkah 3: masukkan alamat dompet

Tempel alamat penerimaan Blocknet publik atau `@name` terdaftar Anda, lalu tekan Enter untuk menerima `stratum+tcp://bntpool.com:3333`. [Panduan dompet](/id/blog/blocknet-wallet-for-mining/) menunjukkan tempat menemukan alamat. Seine tidak memerlukan frasa pemulihan atau kunci pembelanjaan Anda. Nama worker pool ditetapkan secara otomatis.

## Langkah 4: periksa share yang diterima

Cari hashrate dan penghitung **Accepted** yang bertambah pada [dasbor](/id/blog/seine-dashboard-explained/). Share yang diterima menegaskan pool menerima pekerjaan Anda; bukan berarti pembayaran sudah terjadi. Tekan `q` atau `Ctrl+C` untuk berhenti.

## Apa yang dibutuhkan untuk menambang dengan NVIDIA di Linux?

Penambangan GPU di Linux x86_64 memerlukan driver NVIDIA dan pustaka runtime NVRTC yang kompatibel. NVRTC mengompilasi kernel GPU saat startup. Instal runtime dan pustaka builtins yang cocok melalui distribusi atau paket NVIDIA sesuai [panduan NVIDIA](/id/blog/mine-blocknet-nvidia-gpu/). Nama paket bergantung pada distribusi dan versi CUDA; ikuti petunjuk untuk sistem Anda.

Dengan pustaka tersebut, mode bawaan bisa menambang dengan CPU dan kartu NVIDIA yang didukung secara bersamaan. Untuk mulai menambang dengan CPU sambil menyiapkan runtime GPU, pilih secara eksplisit:

```sh
./seine --backend cpu
```

Pilihan ini hanya memakai CPU untuk pemanggilan tersebut. Untuk memilih perangkat GPU dan memeriksa share GPU diterima, lanjutkan ke panduan NVIDIA. Rilis ARM64 yang dibahas memuat backend CPU; memasang CUDA tidak menambahkan backend NVIDIA ke arsip itu.

## Bagaimana mengatasi kesalahan startup Linux?

Gunakan pesan kesalahan pertama untuk menentukan pemeriksaan berikutnya:

| Pesan atau gejala | Yang perlu diperiksa |
|---|---|
| `Exec format error` | Arsitektur salah: bandingkan `uname -m` dengan nama arsip. |
| `GLIBC_2.39 not found` | Biner memerlukan glibc lebih baru. Gunakan sistem yang kompatibel atau kompilasi dari sumber; biarkan distribusi mengelola pustaka C sistem. |
| `Permission denied` | Periksa izin eksekusi pengguna dan gunakan folder pada sistem berkas yang mengizinkan eksekusi. |
| `libnvrtc` / `libnvrtc-builtins` | Instal runtime NVIDIA kompatibel dan pustaka builtins yang cocok, atau gunakan `--backend cpu` sambil menyiapkannya. |

Setelah share diterima, [panduan huge pages](/id/blog/huge-pages-blocknet-mining/) membahas pengaturan halaman opsional di Linux. [Panduan server](/id/blog/mine-blocknet-on-servers/) mencakup operasi tanpa antarmuka grafis dan penempatan NUMA. Keduanya tidak diperlukan untuk mengikuti langkah awal ini; lakukan setiap perubahan secara terpisah agar efeknya pada mesin dapat diketahui.
