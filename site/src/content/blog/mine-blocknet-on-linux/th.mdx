คู่มือนี้ช่วยให้คุณเรียกใช้ seine บนเดสก์ท็อปหรือเซิร์ฟเวอร์ Linux ตั้งแต่เลือกไฟล์บีบอัดจนถึงตรวจสอบแชร์ที่พูลยอมรับ โดยใช้รุ่นทางการ v0.2.26 เป็นตัวอย่างที่ตรวจสอบแล้ว เตรียมที่อยู่รับ Blocknet ให้พร้อม [คู่มือกระเป๋าเงิน](/th/blog/blocknet-wallet-for-mining/) อธิบายวิธีค้นหาที่อยู่นี้ คุณต้องป้อนที่อยู่สาธารณะหรือ `@name` ที่ลงทะเบียนไว้ ห้ามป้อนวลีกู้คืนกระเป๋าเงินเด็ดขาด

## จะเริ่มขุด Blocknet บน Linux ได้อย่างไร?

<Answer>
เลือกไฟล์บีบอัด Linux ที่ตรงกับหน่วยประมวลผล ตรวจสอบค่าเช็กซัม SHA-256 แล้วแตกไฟล์ลงในโฟลเดอร์ที่เขียนข้อมูลได้ เรียกใช้ `./seine` ป้อนที่อยู่รับเงิน และยอมรับการเชื่อมต่อ bntpool.com ตามค่าเริ่มต้น seine กำหนดจำนวนเธรด CPU โดยอัตโนมัติ และใช้การ์ด NVIDIA ที่รองรับบน Linux x86_64 ได้ด้วยเมื่อติดตั้งไลบรารีรันไทม์แล้ว
</Answer>

## ขั้นตอนที่ 1: ตรวจสอบสถาปัตยกรรมและ glibc

เปิดเทอร์มินัลแล้วเรียกใช้คำสั่งตรวจสอบแบบอ่านอย่างเดียวสองคำสั่งนี้ คำสั่งแรกระบุสถาปัตยกรรมของเครื่อง ส่วนคำสั่งที่สองแสดงรุ่นของไลบรารี GNU C บนระบบที่ใช้ glibc ทั้งสองคำสั่งไม่เริ่มขุดและไม่เปลี่ยนการตั้งค่าคอมพิวเตอร์

```sh
uname -m
getconf GNU_LIBC_VERSION
```

จับคู่สถาปัตยกรรมกับไฟล์บีบอัดในตารางด้านล่าง แพ็กเกจ Linux ทั้งสองตัวของ v0.2.26 ต้องใช้ glibc 2.39 ขึ้นไป เมื่อติดตั้งรุ่นใหม่กว่านี้ ให้ตรวจสอบข้อกำหนดของรุ่นอีกครั้ง หากระบบใช้ไลบรารี C อื่นหรือ glibc รุ่นเก่ากว่า ให้ใช้สภาพแวดล้อมดิสทริบิวชันที่เข้ากันได้ หรือทำตาม[คำแนะนำการบิลด์จากซอร์ส](https://github.com/zpalmtree/seine/blob/master/docs/BUILDING.md)

| ผลลัพธ์คำสั่ง | ไฟล์บีบอัดของรุ่น | แบ็กเอนด์ |
|---|---|---|
| `x86_64` | `seine-linux-x86_64.tar.gz` | CPU และ NVIDIA |
| `aarch64` | `seine-linux-aarch64.tar.gz` | CPU |

แต่ละเธรดขุดบน CPU ต้องใช้บล็อกหน่วยความจำขนาด 2 GiB seine เลือกจำนวนเธรดเริ่มต้นจากหน่วยความจำและทรัพยากร CPU ที่พร้อมใช้ แล้วปรับระหว่างขุด ในการเรียกใช้ครั้งแรก อย่าเพิ่งกำหนดค่าทับเธรดหรือเคอร์เนลประมวลผล คุณสามารถทำให้เชื่อมต่อได้ก่อนแล้วค่อยเปลี่ยนการตั้งค่าประสิทธิภาพ

## ขั้นตอนที่ 2: ดาวน์โหลดและตรวจสอบไฟล์บีบอัด

เลือก Linux หรือ Linux ARM64 ใน[ส่วนดาวน์โหลด](/th/#download) และดาวน์โหลดไฟล์ `SHA256SUMS.txt` ที่แนบแยกไว้กับ[รุ่นทางการ](https://github.com/zpalmtree/seine/releases/latest) เดียวกันด้วย เก็บไฟล์บีบอัดและไฟล์เช็กซัมของรุ่นเดียวกันไว้ด้วยกัน ตัวอย่างด้านล่างใช้ x86_64 สำหรับ ARM64 ให้แทนที่ `seine-linux-x86_64.tar.gz` ด้วย `seine-linux-aarch64.tar.gz` ในคำสั่ง

<img src="/assets/blog/linux-download.png" alt="ตารางดาวน์โหลดทางการที่มีไฟล์บีบอัด Linux และ Linux ARM64" width="1200" height="900" loading="lazy" />

ในเทอร์มินัล ให้เปิดไดเรกทอรีที่เบราว์เซอร์บันทึกไฟล์ไว้แล้วคำนวณเช็กซัมของไฟล์บีบอัด ตัวอย่างนี้สมมติว่าใช้โฟลเดอร์ Downloads ภายใต้โฮมไดเรกทอรี หากชื่อไม่ตรงกัน ให้ใช้ไดเรกทอรีดาวน์โหลดจริงของคุณ

```sh
cd "$HOME/Downloads"
sha256sum seine-linux-x86_64.tar.gz
```

เปรียบเทียบค่าแฮชฐานสิบหกทั้งหมดกับบรรทัดของไฟล์บีบอัดนั้นใน `SHA256SUMS.txt` ที่ดาวน์โหลดมา ทุกหลักต้องตรงกันก่อนแตกไฟล์หรือเรียกใช้ สำหรับการเปรียบเทียบนี้ ให้ใช้ไฟล์เช็กซัมที่แนบแยกกับรุ่น เนื่องจากในไฟล์บีบอัดมีรายการตรวจสอบสำหรับไฟล์หลังแตกด้วยเช่นกัน เช็กซัมที่ตรงกันยืนยันว่าไฟล์ตรงกับค่าที่เผยแพร่ โดยต้องดาวน์โหลดทั้งสองไฟล์จากแหล่งทางการ

## ขั้นตอนที่ 3: แตกไฟล์และตรวจสอบไฟล์ปฏิบัติการ

สร้างโฟลเดอร์เฉพาะภายในโฮมไดเรกทอรี แตกไฟล์บีบอัดลงไป แล้วสั่งให้ไบนารีแสดงวิธีใช้ ไฟล์บีบอัด v0.2.26 มี `./seine` อยู่ที่ราก ดังนั้นคำสั่งเหล่านี้จะวางไฟล์ปฏิบัติการไว้ในโฟลเดอร์ใหม่โดยตรง คำสั่งแสดงวิธีใช้จะจบการทำงานโดยไม่เริ่มเซสชันขุด

```sh
mkdir -p "$HOME/seine"
tar -xzf seine-linux-x86_64.tar.gz -C "$HOME/seine"
cd "$HOME/seine"
chmod u+x ./seine
./seine --help
```

ทำขั้นตอนเหล่านี้ด้วยบัญชีของคุณเอง `chmod u+x` ให้สิทธิ์เจ้าของไฟล์ในการเรียกใช้ โดยไม่ต้องติดตั้งให้ทั้งระบบ คำนำหน้า `./` บอกเชลล์ให้เรียกใช้ไฟล์ในไดเรกทอรีปัจจุบัน เก็บเอกสารและไฟล์ใบอนุญาตที่แตกออกมาไว้กับไบนารี

## ขั้นตอนที่ 4: ป้อนที่อยู่และเชื่อมต่อ

เริ่มจากโฟลเดอร์ที่แตกไฟล์ไว้:

```sh
./seine
```

ป้อนที่อยู่รับหรือ `@name` ที่ลงทะเบียนไว้ ยอมรับ `stratum+tcp://bntpool.com:3333` และเลือกชื่อเครื่องขุดที่จดจำได้ง่ายเมื่อมีคำถาม ในการเริ่มครั้งถัดไป seine จะใช้ `seine-data/seine.config.json` ที่อ้างอิงจากไดเรกทอรีทำงานเดิม การเริ่มจากโฟลเดอร์เดียวกันทำให้ค้นหาการตั้งค่าเหล่านี้ได้ง่าย [เอกสารอ้างอิงการตั้งค่า](https://github.com/zpalmtree/seine/blob/v0.2.26/docs/guides/configuration.md) อธิบายคำถามตอนเริ่มและไดเรกทอรีข้อมูล

ดูอัตราแฮชของโปรแกรมขุดและตัวนับแชร์ที่ยอมรับ จากนั้นเปิด [My Stats](https://bntpool.com/stats) แล้วค้นหาที่อยู่รับเดียวกัน แชร์ที่ยอมรับยืนยันว่าพูลได้รับงาน ส่วนการจ่ายเงินเป็นไปตามกระบวนการคำนวณรางวัลและจ่ายเงินแยกต่างหาก [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายแผงต่าง ๆ ของโปรแกรมขุด กด `q` หรือ `Ctrl+C` เพื่อหยุดอย่างถูกต้อง

## ต้องใช้อะไรเพื่อขุดด้วย NVIDIA บน Linux?

การขุดด้วย GPU บน Linux x86_64 ต้องใช้ไดรเวอร์ NVIDIA และไลบรารีรันไทม์ NVRTC ที่เข้ากันได้ NVRTC คอมไพล์เคอร์เนล GPU ตอนเริ่มทำงาน ติดตั้งรันไทม์และไลบรารี builtins ที่ตรงกันผ่านแพ็กเกจของดิสทริบิวชันหรือ NVIDIA ตาม[คู่มือตั้งค่า NVIDIA](/th/blog/mine-blocknet-nvidia-gpu/) ชื่อแพ็กเกจขึ้นอยู่กับดิสทริบิวชันและรุ่น CUDA จึงควรใช้คำแนะนำสำหรับระบบของคุณ

เมื่อมีไลบรารีเหล่านี้ โหมดเริ่มต้นสามารถขุดด้วย CPU และการ์ด NVIDIA ที่รองรับพร้อมกันได้ หากต้องการเริ่มขุดด้วย CPU ระหว่างเตรียมรันไทม์ GPU ให้เลือกอย่างชัดเจน:

```sh
./seine --backend cpu
```

ตัวเลือกนี้ใช้เฉพาะ CPU สำหรับการเรียกใช้ครั้งนั้น สำหรับการเลือกอุปกรณ์ GPU และการตรวจสอบแชร์ GPU ที่ยอมรับ ให้อ่านคู่มือ NVIDIA ต่อ รุ่น ARM64 ที่อธิบายในที่นี้มีแบ็กเอนด์ CPU การติดตั้ง CUDA ไม่ได้เพิ่มแบ็กเอนด์ NVIDIA ลงในไฟล์บีบอัดนั้น

## จะแก้ไขข้อผิดพลาดตอนเริ่ม Linux ได้อย่างไร?

ใช้ข้อความผิดพลาดแรกเพื่อเลือกว่าจะตรวจสอบอะไรต่อ ข้อผิดพลาดของสถาปัตยกรรมหรือรันไทม์เกิดก่อนที่จะมีแชร์ที่ยอมรับ ดังนั้นการเปลี่ยนที่อยู่พูลหรือจำนวนเธรดจึงไม่แก้ปัญหาในขั้นนั้น เก็บไฟล์บีบอัดที่ตรวจสอบแล้วไว้ระหว่างตรวจสอบไฟล์ปฏิบัติการและสภาพแวดล้อม

| ข้อความหรืออาการ | สิ่งที่ควรตรวจสอบ |
|---|---|
| `Exec format error` | สถาปัตยกรรมไม่ตรงกัน: เปรียบเทียบ `uname -m` กับชื่อไฟล์บีบอัด |
| `GLIBC_2.39 not found` | ไบนารีต้องใช้ glibc รุ่นใหม่กว่า ใช้ระบบที่เข้ากันได้หรือบิลด์จากซอร์ส และให้ดิสทริบิวชันดูแลไลบรารี C ของระบบต่อไป |
| `Permission denied` | ตรวจสอบสิทธิ์การเรียกใช้ของผู้ใช้ และใช้โฟลเดอร์บนระบบไฟล์ที่อนุญาตให้เรียกใช้โปรแกรม |
| `libnvrtc` / `libnvrtc-builtins` | ติดตั้งรันไทม์ NVIDIA ที่เข้ากันได้และไลบรารี builtins ที่ตรงกัน หรือใช้ `--backend cpu` ระหว่างเตรียมให้พร้อม |

เมื่อแชร์ได้รับการยอมรับแล้ว [คู่มือ huge pages](/th/blog/huge-pages-blocknet-mining/) อธิบายการตั้งค่าหน้าหน่วยความจำ Linux ที่เลือกทำเพิ่มเติมได้ ส่วน[คู่มือเซิร์ฟเวอร์](/th/blog/mine-blocknet-on-servers/) ครอบคลุมการทำงานแบบไม่มีจอและการจัดวาง NUMA ทั้งสองอย่างไม่ใช่ข้อกำหนดในการทำตามคู่มือเริ่มใช้งานครั้งแรกนี้ ควรเปลี่ยนทีละอย่างเพื่อแยกได้ว่าเครื่องของคุณเปลี่ยนแปลงอะไรไป
