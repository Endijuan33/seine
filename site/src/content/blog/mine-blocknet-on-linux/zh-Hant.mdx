本指南說明如何在 Linux 桌上型電腦或伺服器上執行 seine，從選擇壓縮檔到確認礦池接受份額。文中使用已驗證的官方 v0.2.26 版本作為範例。請準備好 Blocknet 收款地址；[錢包指南](/zh-hant/blog/blocknet-wallet-for-mining/)說明如何找到它。輸入的是公開地址或已註冊的 `@name`，絕不能輸入錢包復原助記詞。

## 如何開始在 Linux 上挖掘 Blocknet？

<Answer>
選擇符合處理器架構的 Linux 壓縮檔，驗證 SHA-256 校驗和，然後解壓縮至可寫入的資料夾。執行 `./seine`，輸入收款地址，並接受預設的 bntpool.com 連線。seine 會自動設定 CPU 執行緒數；在 Linux x86_64 安裝對應的執行階段程式庫後，也能使用支援的 NVIDIA 顯示卡。
</Answer>

## 步驟 1：檢查架構與 glibc

開啟終端機，執行下列兩項唯讀檢查。第一項辨識電腦架構；第二項會在以 glibc 為基礎的系統上輸出 GNU C 程式庫版本。它們不會啟動挖礦，也不會變更電腦設定。

```sh
uname -m
getconf GNU_LIBC_VERSION
```

依架構選擇下表中的壓縮檔。v0.2.26 的兩個 Linux 套件都需要 glibc 2.39 或更新版本。安裝後續版本時，請重新檢查該版本的需求。如果系統使用其他 C 程式庫或較舊的 glibc，請使用相容的發行版環境，或依照[從原始碼建置的說明](https://github.com/zpalmtree/seine/blob/master/docs/BUILDING.md)操作。

| 指令輸出 | 版本壓縮檔 | 後端 |
|---|---|---|
| `x86_64` | `seine-linux-x86_64.tar.gz` | CPU 與 NVIDIA |
| `aarch64` | `seine-linux-aarch64.tar.gz` | CPU |

每個 CPU 挖礦執行緒需要一個 2 GiB 的記憶體區塊。seine 根據可用記憶體與 CPU 資源選擇初始執行緒數，接著在挖礦過程中調整。首次執行時，請不要手動覆寫執行緒與運算核心程式設定；先建立正常連線，再變更效能參數。

## 步驟 2：下載並驗證壓縮檔

在[下載區](/zh-hant/#download)選擇 Linux 或 Linux ARM64。同時從相同的[官方版本](https://github.com/zpalmtree/seine/releases/latest)下載作為版本附件提供的 `SHA256SUMS.txt`。將同一版本的壓縮檔與校驗和檔案放在一起。下方範例使用 x86_64；在 ARM64 上，請將指令中的 `seine-linux-x86_64.tar.gz` 替換為 `seine-linux-aarch64.tar.gz`。

<img src="/assets/blog/linux-download.png" alt="列出 Linux 與 Linux ARM64 壓縮檔的官方下載表" width="1200" height="900" loading="lazy" />

在終端機進入瀏覽器儲存檔案的目錄，然後計算壓縮檔的校驗和。本範例假設檔案位於家目錄下的 Downloads 資料夾；若你的下載目錄使用其他名稱，請改用實際目錄。

```sh
cd "$HOME/Downloads"
sha256sum seine-linux-x86_64.tar.gz
```

將完整的十六進位雜湊值與下載的 `SHA256SUMS.txt` 中該壓縮檔對應的行比較。解壓縮或執行前，每一位都必須相符。此次比較應使用版本頁面另外提供的校驗和檔案：壓縮檔內也包含用於解壓縮後檔案的清單。校驗和相符表示檔案符合公開的數值；兩個檔案都應從官方來源下載。

## 步驟 3：解壓縮並檢查執行檔

在家目錄下建立專用資料夾，將壓縮檔解壓縮進去，然後讓二進位程式顯示說明。v0.2.26 壓縮檔的根目錄包含 `./seine`，因此下列指令會將執行檔直接放在新資料夾內。說明指令會直接結束，不會啟動挖礦工作階段。

```sh
mkdir -p "$HOME/seine"
tar -xzf seine-linux-x86_64.tar.gz -C "$HOME/seine"
cd "$HOME/seine"
chmod u+x ./seine
./seine --help
```

請使用自己的帳號執行這些步驟。`chmod u+x` 為檔案擁有者新增執行權限，不需要進行全系統安裝。`./` 前綴會指示 shell 執行目前目錄中的檔案。請將解壓縮取得的文件與授權檔案和二進位程式保存在一起。

## 步驟 4：輸入地址並連線

從解壓縮後的資料夾啟動：

```sh
./seine
```

輸入收款地址或已註冊的 `@name`，接受 `stratum+tcp://bntpool.com:3333`，並在提示時選擇容易辨識的礦機名稱。後續啟動時，seine 會重用相對於工作目錄的 `seine-data/seine.config.json`。固定從同一資料夾啟動，可以更方便地找到這些設定。[設定參考文件](https://github.com/zpalmtree/seine/blob/v0.2.26/docs/guides/configuration.md)說明了互動提示與資料目錄。

觀察礦工程式的雜湊率與已接受份額計數。接著開啟 [My Stats](https://bntpool.com/stats)，查詢相同的收款地址。份額獲接受表示礦池收到了運算工作；付款則遵循另外的獎勵與支付流程。[儀表板指南](/zh-hant/blog/seine-dashboard-explained/)解釋礦工程式的各個面板。按 `q` 或 `Ctrl+C` 即可正常停止。

## 在 Linux 上使用 NVIDIA 挖礦需要什麼？

Linux x86_64 上的 GPU 挖礦需要 NVIDIA 驅動程式與相容的 NVRTC 執行階段程式庫。NVRTC 會在啟動時編譯 GPU 運算核心程式。依照 [NVIDIA 設定指南](/zh-hant/blog/mine-blocknet-nvidia-gpu/)，透過發行版或 NVIDIA 套件安裝執行階段及相符的 builtins 程式庫。套件名稱取決於發行版與 CUDA 版本，因此請使用適合自己系統的說明。

這些程式庫就緒後，預設模式可以同時使用 CPU 與支援的 NVIDIA 顯示卡挖礦。若想在準備 GPU 執行階段時先設定好 CPU 挖礦，請明確選擇 CPU：

```sh
./seine --backend cpu
```

這表示本次啟動僅使用 CPU。關於 GPU 裝置選擇與 GPU 份額接受情況，請繼續閱讀 NVIDIA 指南。此處介紹的 ARM64 版本包含 CPU 後端；安裝 CUDA 不會為這個壓縮檔新增 NVIDIA 後端。

## 如何解決 Linux 啟動錯誤？

根據第一則錯誤訊息選擇下一步檢查。架構或執行階段錯誤發生在份額被接受之前，因此變更礦池地址或執行緒數無法解決這個階段的問題。檢查執行檔與環境期間，請保留已驗證的壓縮檔。

| 訊息或症狀 | 檢查項目 |
|---|---|
| `Exec format error` | 架構不符：將 `uname -m` 與壓縮檔檔名比較。 |
| `GLIBC_2.39 not found` | 二進位程式需要更新的 glibc。請使用相容系統或從原始碼建置；系統 C 程式庫應繼續由發行版管理。 |
| `Permission denied` | 檢查使用者執行權限，並使用允許執行程式之檔案系統上的資料夾。 |
| `libnvrtc` / `libnvrtc-builtins` | 安裝相容的 NVIDIA 執行階段及相符的 builtins 程式庫，或在準備期間使用 `--backend cpu`。 |

份額開始獲接受後，可參閱[巨型記憶體分頁指南](/zh-hant/blog/huge-pages-blocknet-mining/)進行選用的 Linux 分頁設定。[伺服器指南](/zh-hant/blog/mine-blocknet-on-servers/)介紹無頭執行與 NUMA 配置。這兩項準備都不是完成本首次執行教學的必要條件；請分別進行每項變更，以便判斷電腦上具體改變了什麼。
