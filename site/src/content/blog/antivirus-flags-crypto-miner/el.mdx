Αν τα Windows μπλοκάρουν μια λήψη seine ή ένα εξαγμένο αρχείο εξαφανιστεί, εντοπίστε πρώτα το ακριβές αρχείο και μήνυμα. Ο οδηγός εξηγεί πώς να ελέγξετε την επίσημη έκδοση, να συγκρίνετε το SHA-256 και να συλλέξετε χρήσιμα στοιχεία αναφοράς. Το παράδειγμα χρησιμοποιεί seine v0.2.26, ελεγμένο στις 25 Οκτωβρίου 2026.

## Τι ελέγχετε όταν τα Windows μπλοκάρουν έναν miner;

<Answer>
Καταγράψτε μήνυμα, όνομα αρχείου και έκδοση πριν αλλάξετε οτιδήποτε. Ανοίξτε την Ασφάλεια των Windows και ελέγξτε το Ιστορικό προστασίας για την ανίχνευση. Έπειτα πάρτε το συμπιεσμένο αρχείο και το άθροισμα από την επίσημη έκδοση seine. Αντιστοιχίστε ακριβώς αρχείο και έκδοση πριν αποφασίσετε πώς θα χειριστείτε την ειδοποίηση.
</Answer>

Αναπτύξτε την αντίστοιχη εγγραφή στο [Ιστορικό προστασίας](https://support.microsoft.com/en-us/windows/security/windows-security/protection-history-in-the-windows-security-app). Τα Windows ενδέχεται να απαιτούν δικαιώματα διαχειριστή για τις λεπτομέρειες απειλής. Σημειώστε αν αφορά το ZIP, το `seine.exe` ή μια DLL. Η απουσία εκτελέσιμου και μια ειδοποίηση λήψης του browser μπορεί να προκύψουν σε διαφορετικά στάδια· κρατήστε το όνομα μαζί με το μήνυμα.

## Προειδοποίηση SmartScreen ή ανίχνευση antivirus;

Το [SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) αξιολογεί ληφθείσες εφαρμογές με στοιχεία φήμης του αρχείου και του εκδότη. Μια ειδοποίηση άγνωστης εφαρμογής διαφέρει από μια ονομασμένη ανίχνευση antivirus. Καταγράψτε το πραγματικό μήνυμα: η λέξη miner στο όνομα δεν δείχνει ποιος έλεγχος παρενέβη ούτε γιατί έγινε αποκλεισμός.

Η Microsoft περιλαμβάνει επίσης λογισμικό εξόρυξης στα [κριτήρια δυνητικά ανεπιθύμητων εφαρμογών](https://learn.microsoft.com/en-us/defender-xdr/criteria), ειδικά για εταιρικά περιβάλλοντα. Σε διαχειριζόμενο υπολογιστή εργασίας ή σχολείου, ρωτήστε τον διαχειριστή για την πολιτική. Πρόκειται για κατηγορία λογισμικού, όχι για συμπέρασμα σχετικά με τη λήψη σας. Διερευνήστε τη συγκεκριμένη ειδοποίηση χωρίς να θεωρείτε κάθε προειδοποίηση miner ψευδή ανίχνευση.

## Πάρτε ZIP και άθροισμα από την ίδια έκδοση

Ανοίξτε τις [επίσημες εκδόσεις seine](https://github.com/zpalmtree/seine/releases) μέσω της [σελίδας λήψης](/el/#download). Βεβαιωθείτε ότι το αποθετήριο είναι `zpalmtree/seine`. Επιλέξτε `seine-windows-x86_64.zip` και το ξεχωριστό `SHA256SUMS.txt` της ίδιας έκδοσης. Σημειώστε την έκδοση. Άθροισμα παλιότερης ή νεότερης έκδοσης δεν αποτελεί αναφορά για το ZIP που κατεβάσατε.

![Windows ZIP και SHA256SUMS.txt στα επίσημα αρχεία του seine v0.2.26](/assets/blog/seine-release-assets.png)

Αυτό είναι πραγματικό στιγμιότυπο της λίστας αρχείων v0.2.26. Το αρχείο αθροισμάτων της έκδοσης καλύπτει τα διαθέσιμα συμπιεσμένα αρχεία. Άλλο `SHA256SUMS.txt` μέσα στο ZIP καλύπτει τα εξαγμένα αρχεία. Για τον πρώτο έλεγχο χρησιμοποιήστε το ξεχωριστά ληφθέν αρχείο της έκδοσης. Μη συγχέετε τις λίστες παρά τα ίδια ονόματα.

Χρησιμοποιήστε απευθείας το επίσημο ZIP. Η σύγκριση του αθροίσματός του δεν επαληθεύει μετονομασμένο εκτελέσιμο, επανασυσκευασμένο πακέτο τρίτου ή αρχείο από συνομιλία. Αποθηκεύστε ZIP και άθροισμα μαζί σε εύκολα προσβάσιμο φάκελο και εκτελέστε εκεί τις παρακάτω εντολές.

## Πώς συγκρίνετε το άθροισμα SHA-256;

Ανοίξτε PowerShell στον φάκελο με τα δύο αρχεία. Το [Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) υπολογίζει το SHA-256 του ZIP. Η σύγκριση επιλέγει το ακριβές όνομα του Windows ZIP, απαιτεί μία μόνο αντίστοιχη εγγραφή και σταματά με σφάλμα αν το hash διαφέρει. Διαβάζει αρχεία χωρίς να εκτελεί τον miner ή να αλλάζει την προστασία Windows.

```powershell
$archive = '.\seine-windows-x86_64.zip'
$actual = (Get-FileHash $archive -Algorithm SHA256).Hash
$entries = @(Get-Content .\SHA256SUMS.txt | Where-Object { $_ -match '^([0-9a-fA-F]{64})\s+\*?seine-windows-x86_64\.zip$' })
if ($entries.Count -ne 1) { throw 'Expected exactly one Windows ZIP checksum entry.' }
$expected = ($entries[0] -split '\s+')[0]
if ($actual -ne $expected) { throw 'Checksum mismatch. Do not run this download.' }
'PASS: ZIP matches SHA256SUMS.txt'
```

Το μήνυμα επιτυχίας είναι `PASS: ZIP matches SHA256SUMS.txt`. Αν λείπει αρχείο, ελέγξτε τρέχοντα φάκελο και ονόματα. Αν η εγγραφή αθροίσματος λείπει ή είναι διπλή, κατεβάστε ξανά το αρχικό αρχείο. Σε ασυμφωνία σταματήστε: επιβεβαιώστε έκδοση, κατεβάστε ξανά επίσημο ZIP και άθροισμα και επαναλάβετε τη σύγκριση.

## Τι έδειξε το επαληθευμένο παράδειγμα;

Εκτελέσαμε τη σύγκριση σε Windows PowerShell 5.1 με το επίσημο Windows ZIP v0.2.26. Το υπολογισμένο hash ταίριαξε με το άθροισμα της έκδοσης. Η εικόνα δείχνει την πραγματική έξοδο ως μορφοποιημένη μεταγραφή, όχι ειδοποίηση της Ασφάλειας των Windows. Το [αρχείο κειμένου](/assets/blog/seine-v0.2.26-verification.txt) διατηρεί ολόκληρο το hash και τη λίστα αρχείων.

![Πραγματικό αποτέλεσμα Windows PowerShell για το Windows ZIP του seine v0.2.26](/assets/blog/seine-checksum-result.png)

Η σύγκριση δείχνει αν τα bytes αντιστοιχούν στην παρεχόμενη αναφορά. Δεν πιστοποιεί άθροισμα από ξένη πηγή, δεν αποδεικνύει απουσία κακόβουλου λογισμικού ούτε εξηγεί συγκεκριμένη ανίχνευση. Αν η ειδοποίηση αφορά εξαγμένο εκτελέσιμο, καταγράψτε χωριστά όνομα και ανίχνευση· το hash του ZIP ταυτοποιεί το συμπιεσμένο αρχείο.

## Αν η επαληθευμένη λήψη παραμένει μπλοκαρισμένη;

Κρατήστε το στοιχείο σε καραντίνα όσο διερευνάται ανεπίλυτη ανίχνευση. Συγκεντρώστε έκδοση, URL, όνομα αρχείου, SHA-256 και ακριβές μήνυμα. Προσθέστε έκδοση Windows και αν ο αποκλεισμός έγινε στη λήψη, εξαγωγή ή εκκίνηση. Αυτά κάνουν την αναφορά αναπαραγώγιμη χωρίς αποκάλυψη προσωπικών ρυθμίσεων.

Χρησιμοποιήστε τον [ιχνηλάτη προβλημάτων seine](https://github.com/zpalmtree/seine/issues) για το έργο και την [πύλη υποβολής αρχείων Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission) για πιθανή λανθασμένη ανίχνευση. Ελέγξτε συνημμένα πριν τα στείλετε. Μοιραστείτε το δημόσιο αρχείο έκδοσης ή τα αναγνωριστικά του όταν ζητηθούν, όχι τον φάκελο δεδομένων εξόρυξης. Αφαιρέστε προσωπικές διαδρομές, στοιχεία πορτοφολιού και tokens από εικόνες.

Τα Windows προσφέρουν ενέργειες ανά στοιχείο για ορισμένες ανιχνεύσεις. Εξετάστε την άδεια μόνο αφού ξεκαθαρίσουν προέλευση και ανίχνευση και εμπιστεύεστε το συγκεκριμένο αρχείο· ακολουθήστε τις οδηγίες της καταγεγραμμένης ειδοποίησης. Κρατήστε ενεργή τη γενική προστασία. Σε διαχειριζόμενη συσκευή αποφασίζει ο διαχειριστής.

## Συνεχίστε με το επαληθευμένο Windows ZIP

Μόλις εγκριθεί η χρήση, εξαγάγετε ολόκληρο το ZIP σε εγγράψιμο φάκελο και κρατήστε τις DLL δίπλα στο `seine.exe`. Ο [οδηγός εξόρυξης Windows](/el/blog/mine-blocknet-on-windows/) καλύπτει την πρώτη εκκίνηση και τη διεύθυνση πληρωμής. Για οδηγούς, βιβλιοθήκες ή επιλογή συσκευών, συνεχίστε στον [οδηγό NVIDIA](/el/blog/mine-blocknet-nvidia-gpu/). Είναι ξεχωριστοί έλεγχοι από την επαλήθευση λήψης.
