Если Windows блокирует загрузку seine или распакованный файл исчезает, сначала определите точный файл и предупреждение. Это руководство поможет проверить официальный выпуск, сравнить SHA-256 и собрать полезные сведения для сообщения. В примере используется seine v0.2.26, проверенный 25 октября 2026 года.

## Что проверить, если Windows блокирует майнер?

<Answer>
Перед изменениями запишите текст предупреждения, имя затронутого файла и версию выпуска. Откройте «Безопасность Windows» и найдите обнаружение в журнале защиты. Затем получите архив и контрольную сумму из официального выпуска seine. Сопоставьте точный файл и версию, прежде чем решать, что делать с предупреждением.
</Answer>

Разверните соответствующую запись в [журнале защиты](https://support.microsoft.com/en-us/windows/security/windows-security/protection-history-in-the-windows-security-app). Для просмотра сведений об угрозе Windows может потребовать права администратора. Отметьте, касается ли запись скачанного ZIP, `seine.exe` или DLL. Исчезновение программы и предупреждение браузера могут возникать на разных этапах; сохраняйте имя файла вместе с сообщением.

## Предупреждение SmartScreen или обнаружение антивирусом?

[SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) оценивает скачанные приложения по репутационным сигналам файла и издателя. Сообщение о неизвестном приложении отличается от обнаружения антивирусом с конкретным именем. Запишите фактический текст: слово «майнер» в имени файла не объясняет, какая проверка сработала и почему произошла блокировка.

Microsoft также включает программы для майнинга в [критерии потенциально нежелательных приложений](https://learn.microsoft.com/en-us/defender-xdr/criteria), именно для корпоративных сред. На управляемом рабочем или учебном компьютере уточните политику у администратора. Это категория программ, а не заключение о вашей загрузке. Разберите конкретное предупреждение, не считая любое сообщение о майнере ложным срабатыванием.

## Получите ZIP и контрольную сумму из одного выпуска

Откройте [официальные выпуски seine](https://github.com/zpalmtree/seine/releases) через [страницу загрузки](/ru/#download). Убедитесь, что репозиторий — `zpalmtree/seine`. Выберите `seine-windows-x86_64.zip` и отдельный файл `SHA256SUMS.txt` одного выпуска. Запишите версию. Сумма более нового или старого выпуска не является эталоном для скачанного архива.

![Windows ZIP и SHA256SUMS.txt среди официальных файлов seine v0.2.26](/assets/blog/seine-release-assets.png)

Это настоящий снимок списка файлов v0.2.26. Файл контрольных сумм выпуска относится к скачиваемым архивам. Внутри ZIP есть другой `SHA256SUMS.txt` для распакованных файлов. Для первой проверки используйте отдельно скачанный файл выпуска. Не путайте эти списки, несмотря на одинаковые имена.

Используйте непосредственно официальный архив. Переименованная программа, сторонняя перепаковка или файл из чата не проверяются сравнением суммы официального ZIP. Сохраните ZIP и сумму выпуска вместе в удобной папке и выполняйте следующие команды из неё.

## Как сравнить контрольную сумму SHA-256?

Откройте PowerShell в папке с двумя загрузками. [Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) вычисляет SHA-256 архива. Сравнение выбирает запись с точным именем Windows-архива, требует единственного совпадения и завершается ошибкой при расхождении хеша. Оно читает файлы, не запуская майнер и не меняя защиту Windows.

```powershell
$archive = '.\seine-windows-x86_64.zip'
$actual = (Get-FileHash $archive -Algorithm SHA256).Hash
$entries = @(Get-Content .\SHA256SUMS.txt | Where-Object { $_ -match '^([0-9a-fA-F]{64})\s+\*?seine-windows-x86_64\.zip$' })
if ($entries.Count -ne 1) { throw 'Expected exactly one Windows ZIP checksum entry.' }
$expected = ($entries[0] -split '\s+')[0]
if ($actual -ne $expected) { throw 'Checksum mismatch. Do not run this download.' }
'PASS: ZIP matches SHA256SUMS.txt'
```

Сообщение об успехе — `PASS: ZIP matches SHA256SUMS.txt`. Если файл отсутствует, проверьте текущую папку и имена. При отсутствии или дублировании записи скачайте исходный файл сумм заново. При несовпадении остановитесь: подтвердите версию, повторно скачайте официальный архив и сумму, затем повторите сравнение.

## Что показал проверенный пример?

Мы выполнили сравнение в Windows PowerShell 5.1 для официального Windows ZIP v0.2.26. Вычисленный хеш совпал с суммой выпуска. Изображение показывает настоящий вывод команды как оформленный текстовый протокол, а не уведомление «Безопасности Windows». [Текстовая запись](/assets/blog/seine-v0.2.26-verification.txt) сохраняет полный хеш и список файлов архива.

![Настоящий результат проверки Windows-архива seine v0.2.26 в PowerShell](/assets/blog/seine-checksum-result.png)

Сравнение хешей отвечает, соответствуют ли байты указанному эталону. Оно не удостоверяет сумму из постороннего источника, не доказывает отсутствие вредоносного кода и не объясняет конкретное обнаружение. Если предупреждение касается распакованной программы, отдельно запишите её имя и обнаружение: хеш ZIP идентифицирует архив.

## Что делать, если проверенная загрузка всё ещё блокируется?

Оставьте элемент в карантине, пока невыясненное обнаружение исследуется. Подготовьте версию выпуска, URL, имя затронутого файла, SHA-256 и точный текст предупреждения. Добавьте версию Windows и этап блокировки: загрузка, распаковка или запуск. Эти сведения позволяют воспроизвести проблему без раскрытия личной конфигурации.

Используйте [трекер задач seine](https://github.com/zpalmtree/seine/issues) для сообщения проекту и [портал отправки файлов Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission) при подозрении на ошибочное обнаружение. Проверяйте вложения перед отправкой. По запросу предоставьте публичный файл выпуска или его идентификаторы, а не папку данных майнинга. Уберите личные пути, данные кошелька и токены авторизации со снимков.

Для некоторых обнаружений Windows предлагает действия с отдельным элементом. Рассматривайте разрешение только после выяснения происхождения и обнаружения, если доверяете именно этому файлу; следуйте указаниям записанного предупреждения. Оставьте общесистемную защиту включённой. На управляемом устройстве разрешения определяет администратор.

## Продолжите с проверенным Windows-архивом

Когда файл разрешён к использованию, распакуйте весь ZIP в доступную для записи папку и оставьте комплектные DLL рядом с `seine.exe`. [Руководство по Windows](/ru/blog/mine-blocknet-on-windows/) описывает первый запуск и запрос адреса выплат. По драйверам, библиотекам и выбору устройств переходите к [руководству NVIDIA](/ru/blog/mine-blocknet-nvidia-gpu/). Это отдельные проверки, не связанные с целостностью загрузки.
