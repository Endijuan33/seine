หาก Windows บล็อกการดาวน์โหลด seine หรือไฟล์ที่แตกออกมาหายไป ให้ระบุไฟล์และคำเตือนที่แน่นอนก่อน คู่มือนี้อธิบายวิธีตรวจรุ่นเผยแพร่ทางการ เปรียบเทียบค่าตรวจสอบ SHA-256 และรวบรวมข้อมูลที่มีประโยชน์สำหรับรายงาน ตัวอย่างใช้ seine v0.2.26 ซึ่งตรวจสอบเมื่อวันที่ 25 ตุลาคม ค.ศ. 2026

## ควรตรวจอะไรเมื่อ Windows บล็อกโปรแกรมขุด?

<Answer>
จดข้อความเตือน ชื่อไฟล์ที่ได้รับผลกระทบ และรุ่นเผยแพร่ก่อนเปลี่ยนอะไร เปิดความปลอดภัยของ Windows และดูประวัติการป้องกันเพื่อหาบันทึกการตรวจพบ จากนั้นรับไฟล์บีบอัดและค่าตรวจสอบจากรุ่น seine ทางการ ตรวจให้ตรงทั้งไฟล์และรุ่นก่อนตัดสินใจจัดการการแจ้งเตือน
</Answer>

ขยายรายการที่เกี่ยวข้องใน[ประวัติการป้องกัน](https://support.microsoft.com/en-us/windows/security/windows-security/protection-history-in-the-windows-security-app)เพื่ออ่านรายละเอียด Windows อาจต้องใช้สิทธิ์ผู้ดูแลระบบเพื่อดูรายละเอียดภัยคุกคาม จดว่ารายการนั้นเป็น ZIP ที่ดาวน์โหลด, `seine.exe` หรือ DLL ไฟล์โปรแกรมที่หายไปกับคำเตือนดาวน์โหลดในเบราว์เซอร์อาจเกิดคนละขั้นตอน จึงควรเก็บชื่อไฟล์คู่กับข้อความ

## เป็นคำเตือน SmartScreen หรือการตรวจพบของแอนติไวรัส?

[SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) ประเมินแอปที่ดาวน์โหลดจากสัญญาณความน่าเชื่อถือของไฟล์และผู้เผยแพร่ ข้อความแอปที่ไม่รู้จักต่างจากการตรวจพบของแอนติไวรัสที่มีชื่อเฉพาะ จดข้อความจริง การมีคำว่า miner ในชื่อไฟล์ไม่ได้บอกว่าการตรวจใดเข้ามาจัดการหรือเหตุใดจึงถูกบล็อก

Microsoft ยังระบุซอฟต์แวร์ขุดคริปโตใน[เกณฑ์แอปที่อาจไม่พึงประสงค์](https://learn.microsoft.com/en-us/defender-xdr/criteria) โดยเฉพาะสำหรับสภาพแวดล้อมองค์กร หากเป็นคอมพิวเตอร์ที่ทำงานหรือโรงเรียนจัดการ ให้ถามผู้ดูแลเรื่องนโยบายที่ใช้ นี่คือหมวดหมู่ซอฟต์แวร์ ไม่ใช่คำตัดสินสำหรับไฟล์ที่คุณดาวน์โหลด ให้ตรวจสอบคำเตือนนั้นแทนการคิดว่าทุกคำเตือนโปรแกรมขุดเป็นผลตรวจผิด

## รับ ZIP และค่าตรวจสอบจากรุ่นเดียวกัน

เปิด[รุ่นเผยแพร่ seine ทางการ](https://github.com/zpalmtree/seine/releases)ผ่าน[หน้าดาวน์โหลด](/th/#download) ตรวจว่ารีโพซิทอรีคือ `zpalmtree/seine` เลือก `seine-windows-x86_64.zip` และไฟล์แนบแยก `SHA256SUMS.txt` จากรุ่นเดียวกัน จดหมายเลขรุ่นไว้ ค่าตรวจสอบจากรุ่นใหม่กว่าหรือเก่ากว่าไม่ใช่ค่าอ้างอิงสำหรับ ZIP ที่ดาวน์โหลด

![ZIP ของ Windows และ SHA256SUMS.txt ในไฟล์เผยแพร่ทางการของ seine v0.2.26](/assets/blog/seine-release-assets.png)

นี่คือภาพจับจริงของรายการไฟล์ v0.2.26 ไฟล์ค่าตรวจสอบที่แนบกับรุ่นเผยแพร่ครอบคลุมแพ็กเกจบีบอัดที่ดาวน์โหลดได้ ภายใน ZIP มี `SHA256SUMS.txt` อีกไฟล์สำหรับไฟล์ที่แตกแล้ว ในการตรวจครั้งแรก ให้ใช้ไฟล์แนบที่ดาวน์โหลดแยกมา อย่าสับสนสองรายการนี้แม้ชื่อเหมือนกัน

ใช้ไฟล์บีบอัดทางการโดยตรง การเทียบค่าของ ZIP ทางการไม่ได้ตรวจสอบโปรแกรมที่เปลี่ยนชื่อ แพ็กเกจที่บุคคลอื่นจัดใหม่ หรือไฟล์ที่ส่งมาในแชต บันทึก ZIP และค่าตรวจสอบของรุ่นไว้ด้วยกันในโฟลเดอร์ที่หาได้ง่าย แล้วเรียกใช้คำสั่งต่อไปนี้จากโฟลเดอร์นั้น

## เปรียบเทียบค่าตรวจสอบ SHA-256 อย่างไร?

เปิด PowerShell ในโฟลเดอร์ที่มีสองไฟล์ [Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) จะคำนวณ SHA-256 ของ ZIP การเปรียบเทียบนี้เลือกชื่อแพ็กเกจ Windows ที่ตรงกันทุกตัว ต้องมีรายการตรงกันเพียงรายการเดียว และหยุดพร้อมข้อผิดพลาดหากแฮชต่างกัน คำสั่งอ่านไฟล์โดยไม่เรียกใช้โปรแกรมขุดหรือเปลี่ยนการป้องกันของ Windows

```powershell
$archive = '.\seine-windows-x86_64.zip'
$actual = (Get-FileHash $archive -Algorithm SHA256).Hash
$entries = @(Get-Content .\SHA256SUMS.txt | Where-Object { $_ -match '^([0-9a-fA-F]{64})\s+\*?seine-windows-x86_64\.zip$' })
if ($entries.Count -ne 1) { throw 'Expected exactly one Windows ZIP checksum entry.' }
$expected = ($entries[0] -split '\s+')[0]
if ($actual -ne $expected) { throw 'Checksum mismatch. Do not run this download.' }
'PASS: ZIP matches SHA256SUMS.txt'
```

ข้อความสำเร็จคือ `PASS: ZIP matches SHA256SUMS.txt` ถ้าไม่พบไฟล์ ให้ตรวจโฟลเดอร์ปัจจุบันและชื่อ หากรายการค่าตรวจสอบหายไปหรือซ้ำ ให้ดาวน์โหลดไฟล์แนบต้นฉบับใหม่ หากค่าไม่ตรง ให้หยุด ตรวจรุ่นเผยแพร่ แล้วดาวน์โหลด ZIP ทางการกับค่าตรวจสอบใหม่ก่อนเปรียบเทียบอีกครั้ง

## ตัวอย่างที่ตรวจสอบแล้วให้ผลอย่างไร?

เรารันการเปรียบเทียบใน Windows PowerShell 5.1 กับ ZIP Windows ทางการ v0.2.26 แฮชที่คำนวณได้ตรงกับค่าของรุ่นเผยแพร่ ภาพแสดงผลลัพธ์คำสั่งจริงในรูปแบบบันทึกที่จัดแสดงให้อ่าน ไม่ใช่การแจ้งเตือนจากความปลอดภัยของ Windows [บันทึกข้อความ](/assets/blog/seine-v0.2.26-verification.txt) เก็บแฮชเต็มและรายการไฟล์ใน ZIP

![ผลค่าตรวจสอบจริงจาก Windows PowerShell สำหรับแพ็กเกจ Windows ของ seine v0.2.26](/assets/blog/seine-checksum-result.png)

การเทียบแฮชบอกว่าไบต์ตรงกับค่าอ้างอิงที่ให้มาหรือไม่ ไม่ได้ยืนยันค่าตรวจสอบจากแหล่งอื่น ไม่ได้พิสูจน์ว่าไม่มีมัลแวร์ และไม่ได้อธิบายผลตรวจเฉพาะ หากคำเตือนระบุโปรแกรมที่แตกไฟล์แล้ว ให้บันทึกชื่อและผลตรวจแยกต่างหาก แฮช ZIP ใช้ระบุแพ็กเกจบีบอัด

## หากไฟล์ที่ตรวจแล้วถูกบล็อกต่อไปควรทำอย่างไร?

เก็บรายการนั้นในเขตกักกันระหว่างตรวจสอบผลที่ยังไม่ชัดเจน เตรียมรุ่นเผยแพร่ URL ชื่อไฟล์ SHA-256 และข้อความเตือนตรงตามจริง เพิ่มรุ่น Windows และระบุว่าถูกบล็อกตอนดาวน์โหลด แตกไฟล์ หรือเริ่มโปรแกรม รายละเอียดนี้ทำให้ทำซ้ำปัญหาได้โดยไม่เปิดเผยการตั้งค่าส่วนตัว

ใช้[ระบบแจ้งปัญหาของ seine](https://github.com/zpalmtree/seine/issues)เพื่อรายงานโครงการ และ[พอร์ทัลส่งไฟล์ของ Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission)เมื่อสงสัยว่าตรวจผิด ตรวจไฟล์แนบก่อนส่ง เมื่อได้รับคำขอ ให้แชร์ไฟล์เผยแพร่สาธารณะหรือตัวระบุของไฟล์ ไม่ใช่โฟลเดอร์ข้อมูลขุด ลบพาธส่วนตัว ข้อมูลกระเป๋า และโทเค็นยืนยันตัวตนออกจากภาพ

Windows มีการดำเนินการเฉพาะรายการสำหรับการตรวจพบบางชนิด พิจารณาอนุญาตเฉพาะเมื่อที่มาและผลตรวจได้รับการชี้แจงแล้วและคุณเชื่อถือไฟล์นั้นจริง ๆ โดยทำตามคำแนะนำของการแจ้งเตือนที่บันทึกไว้ เปิดการป้องกันทั้งระบบไว้ บนอุปกรณ์ที่มีผู้ดูแล ผู้ดูแลจะเป็นผู้กำหนดสิ่งที่อนุญาต

## ตั้งค่าต่อด้วย ZIP Windows ที่ตรวจสอบแล้ว

เมื่อไฟล์ได้รับอนุญาตให้ใช้งาน ให้แตก ZIP ทั้งหมดในโฟลเดอร์ที่เขียนได้ และเก็บ DLL ที่ให้มาไว้ข้าง `seine.exe` [คู่มือขุดบน Windows](/th/blog/mine-blocknet-on-windows/) อธิบายการเริ่มครั้งแรกและการกรอกที่อยู่รับเงิน หากมีคำถามเรื่องไดรเวอร์ ไลบรารีรันไทม์ หรือการเลือกอุปกรณ์ ให้ดู[คู่มือตั้งค่า NVIDIA](/th/blog/mine-blocknet-nvidia-gpu/) ซึ่งเป็นการตรวจคนละส่วนกับการตรวจดาวน์โหลด
