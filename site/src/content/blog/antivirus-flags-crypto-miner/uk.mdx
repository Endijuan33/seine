Якщо Windows блокує завантаження seine або розпакований файл зникає, спочатку визначте точний файл і попередження. Цей посібник показує, як перевірити офіційний випуск, порівняти SHA-256 і зібрати корисні відомості для повідомлення. Приклад використовує seine v0.2.26, перевірений 25 жовтня 2026 року.

## Що перевірити, коли Windows блокує майнер?

<Answer>
Перед змінами запишіть текст попередження, назву файлу та версію випуску. Відкрийте «Безпека у Windows» і знайдіть виявлення в журналі захисту. Потім отримайте архів і контрольну суму з офіційного випуску seine. Зіставте точний файл і версію, перш ніж вирішувати, як діяти щодо сповіщення.
</Answer>

Розгорніть відповідний запис у [журналі захисту](https://support.microsoft.com/en-us/windows/security/windows-security/protection-history-in-the-windows-security-app). Windows може вимагати права адміністратора для показу відомостей про загрозу. Зазначте, чи йдеться про завантажений ZIP, `seine.exe` або DLL. Зниклий виконуваний файл і попередження браузера можуть виникати на різних етапах; зберігайте назву разом із повідомленням.

## Попередження SmartScreen чи виявлення антивірусом?

[SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) оцінює завантажені програми за репутаційними сигналами файлу та видавця. Повідомлення про невідому програму відрізняється від іменованого виявлення антивірусом. Запишіть справжній текст: слово «майнер» у назві не пояснює, яка перевірка спрацювала або чому сталася блокада.

Microsoft також відносить програми для майнінгу до [критеріїв потенційно небажаних програм](https://learn.microsoft.com/en-us/defender-xdr/criteria), саме для корпоративних середовищ. На керованому робочому або навчальному комп’ютері запитайте адміністратора про чинну політику. Це категорія програм, а не висновок про ваше завантаження. З’ясуйте конкретне сповіщення, не вважаючи кожне попередження про майнер хибним.

## Отримайте ZIP і суму з одного випуску

Відкрийте [офіційні випуски seine](https://github.com/zpalmtree/seine/releases) через [сторінку завантаження](/uk/#download). Переконайтеся, що репозиторій — `zpalmtree/seine`. Виберіть `seine-windows-x86_64.zip` та окремий `SHA256SUMS.txt` одного випуску. Запишіть версію. Сума старішого або новішого випуску не є еталоном для завантаженого архіву.

![Windows ZIP і SHA256SUMS.txt серед офіційних файлів seine v0.2.26](/assets/blog/seine-release-assets.png)

Це справжній знімок переліку файлів v0.2.26. Файл сум випуску охоплює архіви для завантаження. Усередині ZIP є ще один `SHA256SUMS.txt` для розпакованих файлів. Для першої перевірки використовуйте окремо завантажений файл випуску. Не плутайте списки попри однакові назви.

Використовуйте безпосередньо офіційний архів. Перейменована програма, стороннє перепакування чи файл із чату не перевіряються порівнянням суми офіційного ZIP. Збережіть ZIP і суму разом у зручній папці та виконайте в ній наведені команди.

## Як порівняти контрольну суму SHA-256?

Відкрийте PowerShell у папці з обома завантаженнями. [Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash) обчислює SHA-256 архіву. Порівняння вибирає запис із точною назвою Windows-архіву, вимагає одного збігу та завершується помилкою при відмінному хеші. Воно читає файли без запуску майнера чи зміни захисту Windows.

```powershell
$archive = '.\seine-windows-x86_64.zip'
$actual = (Get-FileHash $archive -Algorithm SHA256).Hash
$entries = @(Get-Content .\SHA256SUMS.txt | Where-Object { $_ -match '^([0-9a-fA-F]{64})\s+\*?seine-windows-x86_64\.zip$' })
if ($entries.Count -ne 1) { throw 'Expected exactly one Windows ZIP checksum entry.' }
$expected = ($entries[0] -split '\s+')[0]
if ($actual -ne $expected) { throw 'Checksum mismatch. Do not run this download.' }
'PASS: ZIP matches SHA256SUMS.txt'
```

Повідомлення про успіх — `PASS: ZIP matches SHA256SUMS.txt`. Якщо файл відсутній, перевірте поточну папку й назви. За відсутнього або дубльованого запису суми завантажте оригінальний файл повторно. Якщо суми різні, зупиніться: перевірте версію, повторно завантажте офіційний архів і суму, а потім порівняйте ще раз.

## Що показав перевірений приклад?

Ми виконали порівняння у Windows PowerShell 5.1 для офіційного Windows ZIP v0.2.26. Обчислений хеш збігся із сумою випуску. Зображення показує справжній вивід команди як оформлений текстовий протокол, а не сповіщення «Безпеки у Windows». [Текстовий запис](/assets/blog/seine-v0.2.26-verification.txt) зберігає повний хеш і перелік файлів архіву.

![Справжній результат перевірки Windows-архіву seine v0.2.26 у PowerShell](/assets/blog/seine-checksum-result.png)

Порівняння хешів показує, чи відповідають байти наданому еталону. Воно не засвідчує суму зі стороннього джерела, не доводить відсутності шкідливого коду й не пояснює конкретного виявлення. Якщо попередження стосується розпакованої програми, окремо запишіть її назву та виявлення; хеш ZIP ідентифікує архів.

## Що робити, якщо перевірене завантаження далі блокується?

Залиште елемент у карантині, поки нез’ясоване виявлення досліджують. Підготуйте версію випуску, URL, назву файлу, SHA-256 і точний текст попередження. Додайте версію Windows та етап блокування: завантаження, розпакування чи запуск. Це дозволяє відтворити проблему без розкриття особистої конфігурації.

Використовуйте [трекер проблем seine](https://github.com/zpalmtree/seine/issues) для повідомлення проєкту та [портал надсилання файлів Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission) за підозри на хибне виявлення. Перевірте вкладення перед надсиланням. На запит надавайте публічний файл випуску або його ідентифікатори, не папку даних майнінгу. Видаліть зі знімків особисті шляхи, відомості гаманця й токени автентифікації.

Для деяких виявлень Windows пропонує дії щодо окремого елемента. Розглядайте дозвіл лише після з’ясування походження та виявлення, коли довіряєте саме цьому файлу; дотримуйтеся інструкцій записаного сповіщення. Залишайте загальносистемний захист увімкненим. На керованому пристрої дозволи визначає адміністратор.

## Продовжіть із перевіреним Windows-архівом

Коли файл дозволено використовувати, розпакуйте весь ZIP у доступну для запису папку та залиште комплектні DLL поряд із `seine.exe`. [Посібник із майнінгу у Windows](/uk/blog/mine-blocknet-on-windows/) описує перший запуск і запит адреси виплат. Щодо драйверів, бібліотек чи вибору пристроїв читайте [посібник NVIDIA](/uk/blog/mine-blocknet-nvidia-gpu/). Це окремі перевірки від перевірки завантаження.
