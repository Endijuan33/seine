mining pool -> مجمع التعدين (short: المجمع)
hashrate -> معدل التجزئة; hash -> تجزئة (hash)
thread (CPU) -> خيط المعالجة / خيوط المعالجة (short: خيط / خيوط)
core (CPU) -> نواة / أنوية المعالج (not النواة الحسابية)
kernel (CPU code path) -> النواة الحسابية (pl. النوى الحسابية), as in ar.json
block -> كتلة; block reward -> مكافأة الكتلة; block time -> زمن الكتلة
share -> حصة; accepted share -> حصة مقبولة
payout -> دفعة (pl. الدفعات)
wallet -> المحفظة; desktop wallet -> محفظة سطح المكتب; command-line wallet -> محفظة سطر الأوامر
seed / recovery phrase -> عبارة الاسترداد
address -> عنوان; shortname -> الاسم المختصر; @name -> @name (unchanged)
Blocknet ID -> Blocknet ID (unchanged)
pay by name -> الدفع بالاسم
payment link -> رابط الدفع
memo -> المذكرة (encrypted memo -> المذكرة المشفرة)
transaction -> معاملة; transaction fee -> رسوم المعاملة
confirmation -> تأكيد
difficulty -> الصعوبة (صعوبة الشبكة)
proof of work -> إثبات العمل (Proof of Work); proof of stake -> إثبات الحصة (Proof of Stake)
memory-hard -> كثيف الذاكرة (memory-hard)
memory bandwidth -> عرض نطاق الذاكرة
huge pages -> الصفحات الكبيرة (huge pages)
node -> عقدة; daemon -> برنامج العقدة (daemon)
solo mining -> التعدين الفردي
rig -> جهاز التعدين
dashboard -> لوحة التحكم (لوحة تحكم seine)
worker name (pool) -> اسم العامل (worker name)
privacy coin -> عملة الخصوصية
private -> خاص / خصوصية (never مجهول الهوية، إخفاء الهوية، لا يمكن تتبع — the checker bans these)
commitment -> التزام (commitment); Pedersen commitment -> التزام Pedersen
range proof -> إثبات النطاق (range proof)

ring signature -> التوقيع الحلقي; ring -> الحلقة; decoy -> مُدخل تمويهي (decoy)
stealth address -> العنوان الخفي (stealth address)
key image -> صورة المفتاح (key image)
view key -> مفتاح العرض (view key); spend key -> مفتاح الإنفاق (spend key)
output -> مُخرَج (output); input -> مُدخل
Dandelion++ -> Dandelion++; stem phase -> مرحلة الساق (stem); fluff phase -> مرحلة الانتشار (fluff)
fair launch -> إطلاق عادل
ASIC -> ASIC; GPU -> بطاقة رسومية (GPU); CPU -> معالج (CPU)
blockchain -> سلسلة الكتل
numbers -> Western digits with comma thousands and point decimals (6,000; 16.8; 49.4 H/s); code, commands and inline code byte-identical
validator / staking / stake -> المدقِّق / التخزين (staking) / الحصة المخزَّنة
designed to resist ASICs -> مصمم لمقاومة أجهزة ASIC
block header -> ترويسة الكتلة; nonce -> nonce (unchanged); salt -> الملح
coinbase -> coinbase (معاملة coinbase); genesis block -> كتلة التكوين (genesis)
blinding factor -> عامل التعمية; pseudo-output -> مُخرَج زائف (pseudo-output)
mempool -> مجمع الذاكرة (mempool); epoch (Dandelion++) -> حقبة; embargo timer -> مؤقت الحظر
change output -> مُخرَج الباقي; view-only wallet -> محفظة للعرض فقط

benchmark -> اختبار الأداء; offline benchmark -> اختبار الأداء دون اتصال

arena (2 GiB Argon2id memory) -> ساحة (ساحة Argon2id بحجم 2 GiB)
backend (seine CPU/GPU backend) -> الواجهة الخلفية (pl. الواجهات الخلفية)
auto-tuning / tuner -> الضبط التلقائي / أداة الضبط
headless -> دون واجهة
genesis block -> كتلة التكوين (genesis); premine -> تعدين مسبق (premine)
fungibility -> قابلية الاستبدال (fungibility)
